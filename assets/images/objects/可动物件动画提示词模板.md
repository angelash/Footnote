## 使用说明

1. **帧数规范**: 每个动画4帧，水平排列成sprite sheet
2. **尺寸规范**: 每帧64x64像素，总图256x64像素
3. **循环播放**: 所有动画设计为无缝循环
4. **帧率建议**: 播放帧率8-12fps

## 文件命名规范

```
{物件类型}_{动画类型}_sheet.webp

示例:
desk_lamp_flicker_sheet.webp
oil_lamp_flame_sheet.webp
candle_burning_sheet.webp
monitor_flicker_sheet.webp
crack_trembling_sheet.webp
rune_glowing_sheet.webp
```
