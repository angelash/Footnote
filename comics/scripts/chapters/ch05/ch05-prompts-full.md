# CH05《稳定结论》分镜与完整提示词（Phase 2）

## 使用说明
- 以 `chXX-scene-analysis.yaml` 为输入
- 每页输出 1 张图（默认 2x2 四格），含中文对白/旁白
- 每页生成 4 张候选图

## 全局风格锚定（每页必须包含）
```
彩色漫画，赛博朋克风格，暗色调配色，霓虹蓝/品红点缀，清晰线条，高质量数字绘画，统一的人物设计，一致的光影处理。
```

## 主角设定（每页必须包含）
```
岑回：20多岁的亚洲男性，黑色短发整齐干练，深邃疲倦但锐利的眼神，穿着灰色维修局工作服，胸口佩戴工号牌，身材中等偏瘦，气质克制沉稳。
```

## 页面列表

## P01
目标：生成一张竖版 9:16 的彩色赛博朋克漫画页，2x2 四格同图，格线清晰；每格都有简体中文旁白/对白气泡且字体清楚可读。

【全局画风】彩色漫画，赛博朋克风格，暗色调配色，霓虹蓝/品红点缀，清晰线条，高质量数字绘画，统一的人物设计，一致的光影处理。
【主角设定】岑回：20多岁的亚洲男性，黑色短发整齐干练，深邃疲倦但锐利的眼神，穿着灰色维修局工作服，胸口佩戴工号牌，身材中等偏瘦，气质克制沉稳。全页人物外形保持一致，不得女性化。
【排版】四格 2x2；文字不要遮挡“稳定”字样与问卷关键句。

第1格（广角）：医疗站外，安静小路；门口一棵树，树干缠保护带，带子绕得很紧；旁白：『医疗站在一条安静的小路上。』
第2格（中景）：岑回走进大厅，淡淡消毒水味的冷光；旁白：『味道很淡，但很“正确”。』
第3格（特写）：候诊区墙上宣传画：一个人坐椅子，背后平滑曲线，曲线上清晰写：『稳定』；旁白：『稳定被印成一条平滑的曲线。』
第4格（对话/中景）：前台把问卷递给岑回；前台对白：『填一下。填完给医生。』

## P02

第1格（特写）：问卷题目密密麻麻：『你是否感到重复？』『你是否对日期不确定？』『你是否出现不必要的警觉？』选项标准化：『从不/很少/偶尔/总是』。
第2格（中景）：岑回坐下填表，动作快、像完成任务；旁白：『字段很多，但都是为了把你塞进一个结论。』
第3格（闪回特写）：冷光闪过一句话：『没有这个字段。』（像记忆里被拒绝的窗口提示）
第4格（特写）：岑回继续勾选：『从不』『偶尔』『很少』；旁白：『他填得很快，像在完成任务。』
