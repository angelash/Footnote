# CH12《双份回执》分镜与完整提示词（Phase 2）

## 使用说明
- 以 `chXX-scene-analysis.yaml` 为输入
- 每页输出 1 张图（默认 2x2 四格），含中文对白/旁白
- 每页生成 4 张候选图

## 全局风格锚定（每页必须包含）
```text
彩色漫画，赛博朋克风格，暗色调配色，霓虹蓝/品红点缀，清晰线条，高质量数字绘画，统一的人物设计，一致的光影处理。
```

## 主角设定（每页必须包含）
```text
岑回：20多岁的亚洲男性，黑色短发整齐干练，深邃疲倦但锐利的眼神，穿着灰色维修局工作服，胸口佩戴工号牌，身材中等偏瘦，气质克制沉稳。（不得女性化）
```

## 配角设定（按需使用）
```text
宋岚：年轻亚洲女性，黑发齐肩或低马尾，神情冷静，常站在走廊阴影里，气质像“差异守护者”。
窗口工作人员：女性，制服整洁，表情中性，讲话像标准流程。
```

## 通用硬性要求（每页必须满足）
```text
竖版 9:16；2x2 四格；每格必须有对白或旁白；对白/旁白文字必须清楚可读；对白框与旁白框分明；不要生成英文。
```
