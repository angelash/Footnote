# CH02《薄墙巷口》分镜与完整提示词（Phase 2）

## 使用说明
- 以 `chXX-scene-analysis.yaml` 为输入
- 每页输出 1 张图（默认 2x2 四格），含中文对白/旁白
- 每页生成 4 张候选图

## 全局风格锚定（每页必须包含）
```
彩色漫画，赛博朋克风格，暗色调配色，霓虹蓝/品红点缀，清晰线条，高质量数字绘画，统一的人物设计，一致的光影处理。
```

## 主角设定（每页必须包含）
```
岑回：20多岁的亚洲男性，黑色短发整齐干练，深邃疲倦但锐利的眼神，穿着灰色维修局工作服，胸口佩戴工号牌，身材中等偏瘦，气质克制沉稳。
```
