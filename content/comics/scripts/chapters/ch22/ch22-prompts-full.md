# CH22《救援》分镜与完整提示词（Phase 2）

## 使用说明
- 以 `chXX-scene-analysis.yaml` 为输入
- 每页输出 1 张图（默认 2x2 四格），含中文对白/旁白
- 每页生成 4 张候选图

## 全局风格锚定（每页必须包含）
```text
彩色漫画，赛博朋克风格，暗色调配色，霓虹蓝/品红点缀，清晰线条，高质量数字绘画，统一的人物设计，一致的光影处理。
```

## 主角设定（每页必须包含）
```text
岑回：20多岁的亚洲男性，黑色短发整齐干练，深邃疲倦但锐利的眼神，穿着灰色维修局工作服，胸口佩戴工号牌，身材中等偏瘦，气质克制沉稳。（不得女性化）
```

## 配角设定（按需使用）
```text
顾临：男性，维修局主管，穿着整洁深色制服，表情稳定克制，站在规则边缘，让别人承担跨线代价。
校准员：现场指挥与解释者。
外勤：两名外勤，执行下探与救援。
老人：背工具包的老人，靠栏杆喘气，脸色很白。
中年人：穿旧工服的中年人。
```

## 通用硬性要求（每页必须满足）
```text
竖版 9:16；2x2 四格；每格必须有对白或旁白；对白/旁白文字必须清楚可读；不要生成英文。
```
