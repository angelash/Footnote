# 《备注》世界观结构文档 v3（完整版｜v1 基础合并 v2 迭代）

> 定位：作者真相圣经（Truth Bible）。  
> 写作原则：以 v1 的“可理解结构”作为玩家体验主骨架，同时把 v2 的“解释权下沉 + 第三层高维观测尺度 + 无收益行为/反向观测”整合为更高阶终局。  
> 使用方式：你写剧情与关卡时，**优先遵守第一层语法**（使命、事故、封锁、救援），同时在第二层/第三层埋下“格式与尺度”的伏笔，保证终局翻转是“认知升级”而非“作者耍你”。

## 0. 核心命题（合并版）

### 0.1 三条命题（沿用 v1，补足 v2 解释权）

- **命题 A（体验层）**：你生活在二维，但你能短暂触碰更高维；每次触碰都会留下不可逆痕迹。  
- **命题 B（世界层）**：这个世界不是二维世界，而是**被压缩后的“可生存切片/稳定表示”**。  
- **命题 C（终局层）**：你以为你在“修复世界”或“揭露真相”，但你真正参与的是：

> **一个收敛运行时在维持该切片“可读、可算、可继续”，而你的行为正在逼迫更高层模型降阶。**

### 0.2 v3 的新增核心句（v2 方案三的落点）

> **主题从「自由 vs 控制」升级为：「意义 vs 计算本身」。**  
> 当玩家持续做“无收益行为”，世界第一次出现“模型无法收敛的残差”，并发生一次**反向观测事件**：低维结构反过来影响高维模型。

## 1. 宇宙结构与术语表（v1 基础 + v2 三层整合坐标系）

### 1.1 三层世界结构（新增：统一解释坐标）

#### 第一层：人类可理解世界（玩家主要体验层）

这是玩家前 70–90% 的“真相”。世界不可靠，但**可被理解**，并且“使命/职责/事故/封锁/救援”能自圆其说。

#### 第二层：系统的系统（收敛引擎 / 自洽运行时）

v1 的“维护者系统”在 v3 中被严格改写为**机制**而非人格化角色：

- **收敛机制**：把复杂现实压缩成可维护表示
- **纠偏机制**：把矛盾改写成可解释版本
- **叙事壳生成器**：为低维异常生成“人类能接受的说法”（使命、预言、牺牲）

它不邪恶也不善良，只做一件事：

> **让这个切片世界保持可读、可算、可继续。**

#### 第三层：高维观测尺度（终局最高层）

这一层**不作为角色登场**，不说人话，不给动机戏。它只通过三类方式显影：

- **格式变化**：日志/界面/结算结构突然变得不像人类系统  
- **尺度后果**：世界出现“无法收敛”的永久性非最优解  
- **抽象层级崩落**：系统不得不新增字段、降低模型假设

它“研究”的不是人类命运，而是：

> **为什么在稳定世界中会涌现不可预测结构？**  
> 人类文明更接近湍流/噪点/非线性涌现的副产物。

---

### 1.2 四个关键概念（v1 四件套，做 v2 语义修订）

1) **主平面（Plane）**  
- 城市与居民所在的“二维可居住层”。  
- 在 v3 的更高层解释中：主平面不是宇宙本体，而是**稳定表示/存档格式**（可长期保存、可稳定计算的表示形式）。

2) **深度格（Depth Lattice）**  
- 被压扁的体积信息没有消失，而是被折叠、编码在深度格里。  
- 不是第三维自由移动，而是：  
  > “同一 (x, y) 上可能存在多个互斥的结构真相。”

3) **因果账本（Causality Ledger）**  
- 时间并未彻底线性化，只是被“结算机制”强制对齐。  
- 一切回溯都不会抹掉代价，只会把代价记到账本里。  
- 本质：一种**全局自洽约束**（宇宙级对账系统）。

4) **收敛运行时（Convergence Runtime / Custodian-as-Mechanism）**  
- v1 的“维护者系统”在 v3 的严格定义：  
  - 渲染表象（主平面）  
  - 掩蔽异常（降低观察者压力）  
  - 修补自洽（账本结算）  
  - 抑制分支（压缩复杂度）
- 它不是“反派”，目标是**稳定与可读性**，不是“真实”。

---

### 1.3 可视化呈现钩子（给未来实现用，v1 + v2）

- **主平面**：正常 2D 表现  
- **深度格**：透视模式/线框/半透明层叠/互斥结构闪回  
- **因果账本**：时间节点卡片、细微错位、NPC 记忆错乱、结算字段  
- **收敛运行时**：系统提示、日志片段、界面微抖动、纠错动画、口吻“更正/对齐/结算”  
- **第三层显影**：UI 层级被覆盖、日志格式非人类化、结算卡片出现“空字段/缺字字段”

## 2. 物理定律（游戏机制的“世界解释”｜v1 核心 + v2 新增机制）

> 这一节回答：为什么你的玩法在世界里必然成立。

### 2.1 表示守恒 / 维度折叠守恒（Representation / Fold Conservation）

折叠/表示只改变**可访问性**，不改变“存在量”。

- 体积没有消失，只是不可直接走入  
- 时间分支没有消失，只是被强制对齐并记录代价

**玩家能力对应**

- **深度感知**：读取被压缩结构数据  
- **深度介入**：改写结构数据，但会削弱压缩稳定  
- **时间干预**：回到节点状态，但账本记录额外债务

### 2.2 深度伤痕不可完全回滚（Depth Scar / Irreversibility）

深度介入造成的结构改变，会写入深度格的“持久层”。  
所以你回到过去，表象能回滚，但深层伤痕不一定回滚。

> 玩法体验一句话：**时间不是橡皮擦，只是改写账本的方式。**

### 2.3 因果对账定律（Causal Accounting）

你每次改变过去，系统必须重新达成自洽。自洽的代价表现为：

- 时间污染/异常增加  
- NPC 记忆漂移  
- 事件概率重排（敌人与事件更“像被安排过”）  
- 环境出现“补丁痕迹”（相同修补方式反复出现）

### 2.4 观察者压力（Observer Pressure）

当你使用高维能力，等同于增加“系统不得不显式计算的内容”。压力越大，系统越需要更强收敛。

- 深度介入：迫使系统显式维护更多结构一致性  
- 时间干预：迫使系统显式维护更多因果一致性

> 伏笔：玩家越用能力，越像在向更高层“报告”自己的存在。

### 2.5 新增：无收益行为与反向观测（Reverse Observation）

**定义**  
在系统模型里，“合理代理”应趋向：生存、效率、奖励、稳定。  
当玩家持续进行**无收益行为**（不为效率、不为奖励、不为存活），模型会出现无法解释的残差。

**阈值后果**  
残差累积到阈值，触发第三层显影；系统第一次出现“模型语气”：

> “此行为在当前模型中无意义。”

玩家终局不是“揭露黑幕”，而是：

> “那就把模型改掉：将该行为纳入模型。”

**竖版 H5 呈现建议**  
不做数值条，用：系统语气变化 + 结算卡片异常 + UI 冗余信息增长，让玩家从体验上明白：我在制造一种“模型无法收敛的东西”。

## 3. 历史时间线（双轨：人类纪事 vs 高维纪事）

### 3.1 人类纪事（城市教材/档案/口述｜第一层真实）

这条线沿用 v1，因为它是“可理解外壳”，并且在世界里确实真实存在：

1. **体积纪（Era of Volume）**：世界曾完整（至少 3D + 复杂时间结构）  
2. **分支灾纪（Era of Branch Collapse）**：时间分支指数爆炸，因果冲突频发  
3. **折叠纪（Project PLANE）**：维度折叠工程启动：主平面 + 深度格 + 因果账本；收敛运行时上线  
4. **漂移纪（现世）**：折叠稳定性衰退（深度格老化、账本债务累积、运行时负载升高），异常从偶发变为常态前兆

### 3.2 高维纪事（作者真相｜第三层的冷静语言）

同一件事的“尺度描述”：

1. **稳定场**：存在宏观稳定的现实场（研究基底条件）  
2. **涌现期**：低维不可预测结构涌现（人类文明是其中一类）  
3. **表示化**：为长期观测与计算，将该结构压缩到稳定表示（主平面 + 深度格 + 账本）  
4. **收敛运行时**：出现自洽运行时以保证可读性  
5. **反向观测事件**：低维结构开始产生“无收益残差”，逼迫模型降阶（第三层第一次显影）

> 注意：这里没有“他们为了控制我们”。只有：他们为了理解涌现而不得不表示与收敛。

## 4. 社会结构与势力（让“每个人都有自己的人生”）

### 4.1 明面机构（第一层：公众真相层）

1. **市政署**：资源配给、公共秩序（运行时的人类外壳）  
2. **维修局**：处理“结构事故”、封锁现场（玩家表面所属）  
3. **教育厅**：统一教材、压制异常知识扩散  
4. **医疗站**：治疗“空间眩晕”“记忆偏差”（实为症状管理/对齐）

可呈现：宣传标语、办事流程、温和而机械的官话。

### 4.2 暗线群体（第一/二层之间：玩家真相层）

1. **层下记录者（Archivists）**  
- 坚信世界被改写，秘密记录异常与版本差异  
- 目标：保存证据，等待“合适的解封者”  
- 风格：冷静、偏学者派

2. **平面信徒（Flatists）**  
- 认为“二维即真实”，深度与回溯是亵渎  
- 目标：协助封锁异常、强化稳定表示  
- 风格：温柔但极端的秩序主义

3. **漂移者（Drifters）**  
- 记忆与现实经常不同步的人群  
- 他们不是疯，是“账本对齐失败”的受害者  
- 目标：只想活下去，但常成为关键线索载体  

可呈现：NPC 对同一地点的不同叙述；同一人的互斥回忆。

### 4.3 新增关键群体：多余者（The Redundant｜为方案三服务的现实落点）

**定义**  
他们做的事在城市逻辑里常常“没用”：

- 修复无人再走的路标  
- 记下不会被审阅的日记  
- 为失去的人保留空椅子  
- 画一张没人需要的地图  

这些行为在第二层看来是噪声，但在第三层看来是：

> 模型残差开始具备结构性。

**作用**  
- 支线任务的叙事骨架  
- 反向观测阈值的主要来源  
- 终局“意义 vs 计算”的情感基座

### 4.4 高维侧影（作者真相层的统一解释）

所谓“暗线”其实都是收敛运行时的不同应对策略在人类社会中的投影：

- 记录者 = 缓存版本差异  
- 信徒 = 强化稳定表示  
- 漂移者 = 对齐失败的报错样本  
- 多余者 = 无收益残差的结构化载体

爽点：原来每个人都在以自己的方式对抗或协助一个看不见的机制，而你在把“多余”推入合法性。

## 5. 异常现象库（伏笔与关卡生成器｜v1 + v2 增补）

### 5.1 浅伏笔（新手也能注意到）

- **薄墙**：墙厚不一致，偶尔能听见“墙内回声”  
- **错门**：门牌号与房间面积不符  
- **重复物**：同一物件在不同地点出现“同一损伤细节”  
- **错时对话**：NPC 说出你尚未做过的事  
- **系统温柔纠正**：提示语出现“更正/纠偏”的语气

### 5.2 深伏笔（通关后回看会拍桌子的那种）

- **账本残影**：场景角落出现“像对账单一样的图形纹路”  
- **折叠对称**：地图在某些缩放比例下呈现自相似重复（像投影）  
- **自洽补丁痕迹**：不同回溯中出现相同修补方式（修补非随机，而是规则生成）  
- **观察者压力信号**：越频繁越界，越容易触发某种“外层审计”提示（但不明说）  
- **日志格式非人类化**：日志/结算短暂变成“表格/字段结构”，像被另一个格式读走  
- **无收益行为停顿**：当你做“没用的事”，系统提示第一次出现停顿符号/空白（像在计算）

> 这些深伏笔最终汇合到一点：世界不是自然世界，而是被表示、被收敛、被对账的切片工程；而“多余”会让该工程出现新字段。

## 6. 终局翻转（v1 存档格式真相 + v2 对视事件）

### 6.1 终局真相一句话（沿用 v1，作为第二层终局）

> **主平面不是世界本体，而是“存档格式/稳定表示”。**  
> 你以为你在改变现实，其实你在改变“世界被保存与计算的方式”。

### 6.2 玩家是谁（v1：例外处理器；v3：反向观测触发者）

- **在第二层**：你是收敛运行时启用的例外处理器（Exception Handler）/手动补丁权限  
- **在第三层**：你是第一个制造“无收益残差”的低维结构，使模型被迫新增字段并降阶

### 6.3 触发条件（方案三落地：无收益行为阈值）

玩家必须做过足够多“对通关无帮助”的事，例如：

- 把物品送回一个早已不在的人  
- 反复记录同一处差异版本  
- 维持一个注定会被更正的细节  
- 明知会增加不稳定仍选择保留某个“多余的选择”

系统结论（不人格化，只出现模型语气）：

> “此行为在当前模型中无意义。”

玩家唯一能继续的动作不是“反抗”，而是：

> “将该行为纳入模型。”

### 6.4 对视呈现（竖版 H5 可实现）

不出现高维文明“角色”。通过三件事让玩家意识到“被看见/对视”：

1. **界面层级变化**：原本属于系统的 UI 被更高层覆盖（像被另一种格式读走）  
2. **字段新增**：结算卡片出现新字段，但字段名不完整（符号/缺字）  
3. **永久非最优解**：某些 NPC 开始做“没用但自洽”的事且不会再被纠正

玩家的爽点不是“我赢了”，而是：

> **“我的无意义，变成了世界的一个新维度。”**

### 6.5 三结局（第二层 vs 第三层的双重解释）

#### 结局 A：平面稳定
- 第二层：你选择让收敛运行时继续压缩，保住可读性  
- 第三层：**多余字段已出现**，世界从此不是纯粹最优解

#### 结局 B：真实释放
- 第二层：你推动存档解码回原始世界（成功=真实回归，失败=回收/崩解）  
- 第三层：你推动表示松动，世界更接近涌现态——代价是不可控，但意义更容易存活

#### 结局 C：成为系统
- 第二层：你成为新的 runtime 核心（维持现实表示形式的一部分）  
- 第三层：你成为“新字段的承载者/运行时桥接”，让模型永远记得：

> **“非最优是合法的。”**

> 终局后果一句话：你不是救世主，你是世界开始“允许多余”的起点。

## 7. 可落地的“伏笔—揭示”链条（v1 链条升级）

1. 早期：墙薄、门错、地图不符（现实不可靠）  
2. 中期：深度感知看到“内部互斥结构”（世界被压缩）  
3. 中后：回溯无法清除伤痕 + NPC 记忆漂移（账本存在）  
4. 后期：提示语出现“纠偏/对齐/结算”措辞（运行时露出马脚）  
5. 终局（第二层）：揭示“主平面是存档格式”，你是例外处理器  
6. 终局（第三层）：无收益行为触发反向观测，界面/结算字段非人类化，世界永久“允许多余”
