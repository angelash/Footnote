# Zone脚本包 v1（第3章 C3）

## 本章新增交互与UI约定（竖版H5可实现）

* 深度视野（长按）下，部分异常点会出现一个小按钮：**【介入】**
* 点击【介入】必弹  **确认浮层** （防误触）：
  * 标题：`深度介入（写入）`
  * 文案：`将改写结构，并留下永久伤痕。`
  * 选项：`按住确认（1秒） / 取消`
* 屏幕顶部可用一个很小的“裂纹图标”表示 **结构负担** （不标数字，只变化形态）：
  * 初始：完整
  * 介入一次：出现细裂
  * 再介入：裂纹增多（玩家直观知道“用多了会坏”）

隐藏结算（作者用）：

* 深度介入：`P += 2~3`（观察者压力上升）
* 若介入行为在系统模型里“无可结算收益”，也可给 `R += 1`（残差结构化）

## C3-Z1｜维修局：例外许可签发｜生活→伦理压力（解锁深度介入）

 **目标时长** ：10–12分钟

 **类型** ：生活/剧情/教学

 **出场** ：顾临、岑回

### 1）玩家目标

* 领取【深度介入许可】
* 明确规则：能不介入就不介入（但你会很快被逼到必须选择）

### 2）场景与交互点

* 顾临办公室外走廊（纵向）
* 交互点：
  1. **办公室门** （进入触发对话）
  2. **许可文件夹** （阅读/签署）
  3. **“例外条款”标签** （长按看细节）
  4. **出门任务单**

### 3）流程脚本

1. 进入办公室 → 顾临开场
2. 点击许可文件夹 → 弹出“许可卡片预览”（可滑动）
3. 玩家必须选择：**“签署 / 暂不签署”**
   * 暂不签署：顾临不会骂你，只说一句“你可以按流程走……但那样很多事只会变成记录。”然后仍给你任务单（为了主线推进，最终仍会让玩家拿到许可，但语气不同）
4. 签署后：系统弹教学浮层（1次）
   * “深度视野下点击【介入】进行写入（慎用）”

### 4）对话脚本（顾临）

**顾临开场（温柔但压强）**

* “你已经看见了。看见本身就够危险。”
* “今天开始你可以写入——但别把它当能力。”
* “这是债，不是奖赏。”

**玩家选项（3选1）**

1. “为什么要给我这个？”
2. “如果有人需要救呢？”
3. “我不想碰。”

**顾临回应（短、像流程）**

* 对1：“异常密度超阈值。需要例外处理。”
* 对2：“救援优先，但代价记在你身上。”
* 对3：“这反而说明你适合拿着它。”

> 注意：顾临的“好”与“可怕”来自同一个点：他把人当作系统负担管理对象。

### 5）可收集物

**卡片S：深度介入许可（一次/有限）**

* 内容（不要数字化太露骨）：
  * 权限：写入深度格（局部）
  * 警告：`写入会增加解释成本`
  * 条款：`造成的结构伤痕不可完全回滚`
  * 末尾极淡：`结算方式：待定`

> “结算方式：待定”是非常关键的深层伏笔语法（为F11/F21链条服务）

### 6）伏笔投放

* 第二层“收敛/结算/解释成本”的口吻显著增强
* 为后续“无法结算/空字段闪现”做语法铺垫

### 7）结算

* 玩家可见结算卡：
  * “许可已签发。”
  * “提醒：慎用。”
* 隐藏结算：
  * `FLAG_DEPTH_INTERVENTION_UNLOCKED = true`
  * `R += 0`, `P += 0`

## C3-Z2｜不存在的房间（可进入）｜结构异常（第一次介入 + 救援）

 **目标时长** ：12–18分钟（本章核心高潮）

 **类型** ：结构异常/伦理选择/多解法

 **出场** ：岑回、被困者“陈匠”（可改名）、顾临远程（可选）

### 1）玩家目标

* 抵达“门影”处
* 救出被困者（系统记录里**不存在**的人）

### 2）场景与交互点

* 边缘断口走廊（纵向，分三段）
* 交互点：
  1. **门影轮廓** （深度视野下可见）
  2. **维护通道盖板** （2D绕行解法入口）
  3. **【介入】热点** （深度视野下出现在门影边缘）
  4. **被困者位置点** （进入后）
  5. **撤离点**

### 3）多解法设计（必须清晰、手机友好）

这里给玩家两个“都能成功但代价不同”的解法：

#### 解法A：流程绕行（2D）

* 玩家打开维护通道盖板 → 走一段窄通道 → 从“记录里存在的入口”进入内部
* 代价：
  * 时间更长（体验上更累）
  * 会留下“表层破损”（盖板被撬开，后续NPC会注意到）
  * **系统可记录** （结算上“可归档”）

#### 解法B：深度介入（写入）

* 长按深度视野 → 点击【介入】→ 直接“改写结构通路”进入
* 代价：
  * **结构伤痕** （区域永久不稳定）
  * **观察者压力P上升**
  * 系统记录出现“无法完整归档”的怪味（为方案三服务）

> 实现上：你只需要做两条路径动画，玩法成本低，但叙事深度很高。

### 4）流程脚本（通用）

1. 玩家到门影处 → 系统提示：`对象：不存在。建议忽略。`
2. 玩家能听到里面传来“敲击声/呼喊”（不写伤情细节）
3. 玩家选择解法A或B
4. 进入内部空间（短对话）→ 带人撤离
5. 出门时系统弹结算卡（差异化）

### 5）被困者“陈匠”对话（短但要一针见血）

* “你看得到这里？”
* “我只是来把那盏灯点起来……它以前照过人。”
* “他们说这里不存在。可不存在的地方，也会冷。”

玩家选项（简短）：

1. “跟我走。”
2. “你为什么要来？”
3. “你叫什么？”

陈匠回应：

* “名字不重要，重要的是别让它被抹掉。”（这句很关键：他是“多余者先驱”）

### 6）系统记录差异（方案三必须出现的“刺点”）

* 若走解法A（2D绕行）：
  * 结算卡：`救援已登记。`
* 若走解法B（介入）：
  * 结算卡：`救援：无法归档。`
  * 并出现一次很短的“空字段闪现”（F11前奏加强）

> 注意：不要写“无收益”，先用“无法归档/无法结算”这种更冷的词，后面才升级到F21那句核弹。

### 7）可收集物

**卡片T：救援记录-01（分支版本）**

* A版（绕行）：
  * “救援：已登记”
  * “现场：表层破损（盖板）”
* B版（介入）：
  * “救援：无法归档”
  * “现场：结构伤痕（深度写入）”
  * 末尾出现：`字段：——`（空字段，给未来回收）

 **卡片U：旧灯芯（陈匠交给你）** （非奖励型）

* 文案：
  * “一截旧灯芯。”
  * “点亮它的人已经不在记录里。”

### 8）伏笔投放

* “不存在的人/不存在的房间”第一次与“多余行为”绑定
* **F11 空字段**持续加深（但仍不强迫玩家注意）
* 方案三：系统开始承认“某些事无法被它的模型记录”

### 9）结算

* 玩家可见结算卡（差异化，如上）
* 隐藏结算建议：
  * 若用介入：`P += 3`，`R += 1`（因为对系统来说“不可归档救援”是模型残差），`FLAG_HALL_SCAR = 1`
  * 若绕行：`P += 0`，`R += 0`，`FLAG_SURFACE_DAMAGE = true`

## C3-Z3｜档案巷：宋岚的版本库｜生活→真相密度提升

 **目标时长** ：10–12分钟

 **类型** ：生活/信息系统/无收益记录

 **出场** ：宋岚

### 1）玩家目标

* 获得“版本库”地图卡组（滑动对比）
* 完成一次“记录差异”动作（无奖励）

### 2）场景与交互点

* 版本库（像小档案室，纵向滚动）
* 交互点：
  1. **地图墙（可滑动对比三张版本）**
  2. **差异标注台**
  3. **宋岚对话点**

### 3）流程脚本

1. 宋岚看到你（若救出陈匠，台词变化）
2. 玩家滑动对比三张地图版本（差异非常小，但能看到“门影区域”被删改）
3. 玩家在标注台点选一个差异点 → 提交
4. 宋岚给一句评语（不是奖励）

### 4）对话脚本（宋岚）

若玩家完成了C3-Z2救援（不管A/B），宋岚都会提“记录不一致”：

* “听说你从‘不存在’里带出来一个人。”
* “版本库里没有这条记录。”
* “这才是最危险的：不是异常，是 **无法对齐的差异** 。”

玩家选项：

1. “你想要我做什么？”
2. “我只是救人。”
3. “如果他们把它抹掉呢？”

宋岚回应（短）：

* “那就让抹掉变得更难。”
* “你把差异留在更多地方。”

### 5）可收集物

**卡片V：被更正的地图-03（版本库三联）**

* 三张卡可滑动：V1/V2/V3
* 其中“门影区域”在不同版本里呈现为：
  * V1：有一个小空白
  * V2：空白被涂抹
  * V3：空白位置被写成“墙”

**卡片W：差异提交回执**

* 文案：
  * “差异已保存。”
  * “奖励：无。”（冷冷一句，让玩家慢慢习惯）

### 6）伏笔投放

* **F12（表示/版本差异）**强推进
* **F11（字段/空白）**可在提交回执末尾闪一下“字段：——”

### 7）结算

* 玩家可见结算卡：
  * “差异已保存。”
* 隐藏结算：
  * `R += 1`
  * `FLAG_VERSION_DIFF_SUBMITTED = true`

## C3-Z4｜栖蓝：空椅子｜生活（强无收益 + 终局情感锚）

 **目标时长** ：8–12分钟

 **类型** ：生活/无收益（强）

 **出场** ：栖蓝

（可选：若玩家救了陈匠，他可以以“远处路过一眼”出现，增加人味，不用长对话）

### 1）玩家目标

* 帮栖蓝“安放/整理”一把空椅子
* 让玩家做一件**完全不帮助通关**但很难拒绝的事

### 2）场景与交互点

* 小院/街角（纵向）
* 交互点：
  1. **空椅子**
  2. **擦拭布**
  3. **椅脚松动点** （可修）
  4. **旁边的小灯座** （可点亮；若有旧灯芯可触发更完整）

### 3）流程脚本

1. 栖蓝请求：
   * “把椅子擦干净，摆正，别让它歪。”
2. 玩家进行三步交互：擦 → 扶正 → 修椅脚
3. 若玩家有卡片U旧灯芯：
   * 可选“点亮小灯”动作（仍然 **不给奖励** ，但画面会暖一下）
4. 完成后栖蓝只说一句“谢谢”，不煽情

### 4）栖蓝对话（克制但扎心）

* “他以前坐这儿。”
* “现在没人坐了。”
* “但空着也得摆好。”
* “不然像是我先把他抹掉。”

玩家选项：

1. “他是谁？”
2. “这有用吗？”
3. “我帮你。”

栖蓝回应：

* 对2：“没用。但我需要它在。”（这是方案三的灵魂句）

### 5）可收集物

**卡片X：空椅记录-01**

* 文案：
  * “椅子已摆正。”
  * “结算：无可用收益。”

（注意：这里可以第一次让玩家看到“无可用收益”不是羞辱，而是一种反抗。）

### 6）伏笔投放

* 这是未来 **F23（非最优被保存）** 的核心锚点之一
* 也是后期“对视后世界出现多余选择”的情感爆点来源

### 7）结算

* 玩家可见结算卡：
  * “无可用收益。”
* 隐藏结算：
  * `R += 2`
  * `FLAG_EMPTY_CHAIR_SET = true`
  * 若点亮小灯：`FLAG_LAMP_LIT = true`（仅作回收用，不给奖励）

## C3-Z5｜诊疗台：病例卡1｜因果微颤（为账本线做铺垫）

 **目标时长** ：8–10分钟

 **类型** ：生活/信息/轻压迫

 **出场** ：许澄

### 1）玩家目标

* 获得第一张“病例卡”（编号体系露出但不解释）
* 让许澄对你的“越界后状态”做一次温柔警告（不恐吓）

### 2）交互点

1. **问诊台**
2. **症状清单（点击选择）**
3. **病例卡领取点**

### 3）流程脚本

* 症状清单三项勾选（玩家可选）：
  1. “重复感”
  2. “日期不确定”
  3. “无法解释的空白记忆”
* 不管怎么选，许澄都会给一句“别过度解释”的安抚
* 领取病例卡（可收集）

### 4）许澄对话（专业+一点点系统语法）

* “你最近有没有觉得，解释变得更费力？”
* “别逼自己把每件事都说清。”
* “有些东西被写进来，就很难擦掉。”

> “写进来/擦掉”是对深度介入的隐喻回声，也为终局“表示格式”铺路。

### 5）可收集物

**卡片Y：病例卡-01**

* 字段：
  * 编号：`MC-□□-17`（留空块，通关后回收为对账序列感）
  * 结论：`建议：休息 / 降低观察刺激`
  * 末尾极淡：`对齐：建议`（不执行，只建议）

### 6）伏笔投放

* **F14（编号/对账序列）**开始可被玩家收集
* “写入/擦除”隐喻强化

### 7）结算

* 玩家可见结算卡：
  * “你得到了一张看似普通的病例卡。”
* 隐藏：`FLAG_MED_CARD_01 = true`

## C3-Z7｜边缘断口：断裂走廊｜结构异常（永久后果展示）

 **目标时长** ：10–14分钟

 **类型** ：结构异常/后果/可选再介入

 **出场** ：岑回

### 1）玩家目标

* 通过断裂走廊抵达下一处巡检点
* 第一次直观感受：

  **你之前的选择，让路变了**

### 2）场景与交互点

* 走廊三段
* 交互点：
  1. **裂缝地面** （深度视野下能看见“骨架断口”）
  2. **不稳定踏板** （踩上去会“轻微回弹送回”，不算失败）
  3. **可选【介入】热点** （可以“加固一段”，但代价大）
  4. **终点门**

### 3）玩法结构（两解法）

#### 解法A：只读通过（推荐）

* 玩家长按深度视野识别“稳定骨架路径”
* 慢一点，但不新增伤痕

#### 解法B：再介入加固（诱惑）

* 玩家可在一处断口点击【介入】→“加固”一段
* 代价：
  * 顶部裂纹图标明显加重
  * 结算卡出现“结构负担：上升”
  * 隐藏 `P += 2`，并设置更重的后续异常旗标（给第4章/第5章增加一些环境扰动）

> 这就是你要的体验：玩家会犹豫，“我能做，但我最好别做”。

### 4）文本提示

* 岑回内心（短）：
  * “路变了。”
  * “是我写的，还是它自己裂的？”

系统提示（冷一点）：

* “建议：避免进一步写入。”

### 5）可收集物

**卡片AA：断裂样本-01**

* 内容：
  * “骨架断口已记录。”
  * “自洽修补：未执行。”（埋“补丁/自洽”语法）

若玩家选择介入：卡片末尾追加一行

* “写入：已执行（不可回滚）”

### 6）伏笔投放

* 强化“深度伤痕不可回滚”体验
* 为后续时间系统做心理预埋：
  > 以后你再回到过去，也未必洗得掉这些裂纹。
  >

### 7）结算

* 玩家可见结算卡：
  * 若解法A：“你绕过了伤痕。”
