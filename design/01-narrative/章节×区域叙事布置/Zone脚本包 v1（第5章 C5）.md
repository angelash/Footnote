# Zone脚本包 v1（第5章 C5）

## 本章章目标（制作人视角）

* 让玩家亲身经历：

  **同一个地点出现互斥版本 → 系统无法给出单一“更正”**
* 把“补丁一致性（F13）”从“痕迹”升级为“机制语言”
* 把“对账/编号（F14）”从“暗示”升级为“格式恐惧”：

  > “这不是给人看的格式。”
  >
* 让玩家第一次明确听见 **F21：此行为在当前模型中无意义。**

  并且不是靠剧情讲出来，而是靠玩家做了一件“多余却坚持”的事触发。

---

## 全章新增表现约定（H5可实现）

* **结算卡片格式**开始偶发变化：
  * 从自然语言 → 半表格字段
  * 出现缺字字段名（例如：`字段：＿`）
  * 出现无法关闭的“冗余提示条”（短暂）
* **系统提示语气**从“建议/提醒”变得更像“结算/归档/收敛报告”
* **重要：第三层不出场** ，只“显影”：
* 格式变了
* 关系变了
* 世界开始允许“非最优”留下痕迹

## C5-Z1｜档案巷：版本冲突现场｜冲突（互斥版本选择）

 **目标时长** ：12–18分钟（本章第一爆点）

 **类型** ：冲突 / 版本互斥 / 多解但无完美

 **出场** ：宋岚（主）、围观住户（可选）

### 1）玩家目标

* 进入“同一坐标”的两个互斥版本区域
* 选择要“暂时保留”的版本（对当前章路线有影响）
* 让玩家第一次真切感到：**世界不是错，是“同时存在但不能并存”。**

### 2）场景与交互点

同一张2D地图，存在两种叠加状态（用一个“版本切换点”表现）：

1. **版本切换点（地面裂纹处）** ：点击在 V-A / V-B 之间切换
2. **纪念墙（只在V-B存在）** ：一面写着很多名字的墙（无奖励互动点）
3. **流程出口（只在V-A可顺利通行）** ：通往市政环的便捷出口
4. **不稳定出口（V-B可走但更绕）** ：通往同一目标但路径更碎
5. **差异标注点** ：提交你选择的版本（锁定当前Zone）

### 3）版本设计（务必做到“各有代价”）

* **版本 V-A（最优/可结算）**
  * 路更顺、出口更安全
  * 纪念墙不存在（像从没存在过）
  * 系统结算：`可归档`
* **版本 V-B（有人味/不可收敛）**
  * 路更绕，有小段需要深度视野辨别稳定骨架
  * 纪念墙存在，可互动（但 **无奖励** ）
  * 系统结算：`解释成本上升`

### 4）宋岚对话（必须把“解释权”推上来）

* “你看见两个版本，都是真的。”
* “系统会逼你选一个，逼你把另一个写成不存在。”
* “问题不是你选哪个。”
* “问题是：你愿不愿意承认 **你在参与更正** 。”

玩家选项：

1. “那我选能走的。”
2. “我不想删掉那面墙。”
3. “有没有办法都留下？”

宋岚回应（短而狠）：

* 对3：“这就是我们一直在做的‘多余的事’。”

### 5）关键无收益行为（R机会点）

玩家在 V-B 可做：

* **长按纪念墙** → 展开“名字列表”（不用长，10个以内）
* 选择一个动作：`抄下来 / 不抄`
  * 抄下来：不给奖励，结算会冷冷提示“无可用收益”，但会显著推动 R（R+2）

> 这就是方案三的核心：你在做系统不想算的事情。

### 6）可收集物

**卡片AL：版本冲突快照（双版本滑动卡）**

* 左滑：V-A（墙不存在）
* 右滑：V-B（墙存在）
* 底部一行：`版本互斥：无法合并`

**卡片AM：纪念墙抄录（可选）**

* 仅当玩家抄录获得
* 文案：
  * “抄录完成。”
  * “结算：无可用收益。”

### 7）伏笔投放

* **F12（版本/表示）**强推进
* **F11（字段/空白）**可在提交版本时闪一次：`字段：——`（极短）

### 8）结算

* 玩家可见结算卡（根据版本选择）：
  * 选V-A：“版本已锁定：可归档。”
  * 选V-B：“版本已锁定：解释成本上升。”
* 隐藏结算：
  * 选V-B：`R += 1`（因其偏“非最优”）
  * 若抄录：`R += 2`
  * `FLAG_VERSION_LOCK = A/B`

## C5-Z2｜市政环：纠偏中心外围｜冲突（对齐语言显形）

 **目标时长** ：10–16分钟

 **类型** ：冲突/制度压力/界面语法变化

 **出场** ：顾临（主）、市政职员（可选）

### 1）玩家目标

* 把“版本冲突记录”交到纠偏中心
* 体验：系统开始用更像“对账报告”的方式说话

### 2）场景与交互点

1. **门禁闸机** （需要通行证卡）
2. **提交窗口** （交付记录）
3. **屏幕公告墙（会显示“纠偏队列”）**
4. **顾临对话点**

### 3）流程脚本

1. 玩家刷通行证进入
2. 公告墙滚动显示：“纠偏队列 / 待结算 / 已收敛”
3. 玩家提交记录
4. 系统回执出现“半字段表”样式（第一次比较明显）
5. 顾临出现，语气比之前更紧

### 4）顾临对话（本章推进：他也开始“理解不了”）

* “你带回来的东西……不太好结算。”
* “你知道这意味着什么吗？”
* “意味着它会在系统里停很久。”
* “停很久的东西，会把别的东西也拖慢。”

玩家选项：

1. “那就别结算。”
2. “我只是记录。”
3. “你在怕系统，还是怕人？”

顾临回应：

* 对1（停顿一下）： “……你说得轻松。”
* 对3：“我怕的是，城市开始读不下去。”

> 如果玩家 `R` 很高：让顾临出现一次更明显的“卡顿”：
>
> 他一句话中间出现短空白气泡“……”再继续（不解释）。

### 5）可收集物

**卡片AN：纠偏回执（半字段表）**

* 字段示例（只露一点点）：
  * `条目：版本冲突`
  * `状态：待结算`
  * `字段：＿`（缺字）
  * `备注：解释成本↑`

### 6）伏笔投放

* **F13（补丁一致性）**从痕迹升级成“队列/结算语言”
* **F11（字段缺失）**更明显一档，但仍不解释“谁写的”

### 7）结算

* 玩家可见结算卡：
  * “记录已提交：状态待结算。”
* 隐藏结算：
  * 若玩家在对话中选择“那就别结算”（无收益态度）：`R += 1`（轻）

## C5-Z3｜诊疗台：许澄的抉择｜冲突（疗程=抹平差异）

 **目标时长** ：12–18分钟（道德系统化核心）

 **类型** ：冲突/选择/后果

 **出场** ：许澄（主）、（可选）阿棠远景

### 1）玩家目标

* 面对一个明确选择：

  **接受“稳定疗程”** （降低异常、减轻压力）

  vs

  **拒绝疗程** （保留差异、承受更高不确定）

### 2）场景与交互点

1. **诊室**
2. **疗程说明卡（可滑动阅读）**
3. **选择按钮：接受/拒绝** （必须确认）
4. **离开点**

### 3）选择设计（必须真实影响体验，但不能毁档）

* **接受疗程（偏收敛）**
  * 立即效果：后续1–2个Zone里随机“提示错位/补丁痕迹”减少
  * 代价：你的一张“差异卡”会被系统覆盖成“已对齐版本”
    * 建议覆盖对象：**纪念墙抄录AM** 或  **碎片日记AH** （如果玩家拥有）
    * 覆盖方式：卡片仍在，但部分内容变成空白，底部写：`已对齐`
* **拒绝疗程（偏意义）**
  * 立即效果：后续Zone里UI错位更明显一点（不影响操作，只影响氛围）
  * 收益：保留所有差异卡原样，并额外得到一张“许澄私记”（她承认这不是治疗）
  * 隐藏：`R += 2`

> 要点：接受疗程不是“坏”，拒绝也不是“好”。
>
> 它们只是两种生存策略。

### 4）许澄对话（必须压住情绪，不煽）

* “我能让你轻松一点。”
* “但轻松的代价是——你会变得更像他们需要的样子。”
* “你不是第一个想保留差异的人。”
* “你也不会是最后一个。”

玩家选项：

1. “我接受。”
2. “我拒绝。”
3. “你到底在帮谁？”

许澄回应（关键句）：

* 对3：“我在帮‘还活得下去的你’。”

  （这句未来会回收得很爽：她一直在做伤害更小的选择。）

### 5）可收集物

* 若拒绝疗程：

  **卡片AO：许澄私记-01**

  * “这不是治疗，这是抹平。”
  * “抹平能救很多人，也会抹掉他们的一部分。”
* 若接受疗程：

  **卡片AP：疗程执行回执**

  * “执行：稳定疗程”
  * “结果：差异已对齐”
  * “备注：解释成本↓”

### 6）伏笔投放

* **方案三核心伦理落地** ：意义是否必须“有用”才允许存在
* **F14（对账/格式恐惧）** ：疗程说明卡的编号格式与节点刻度点呼应（但不解释）

### 7）结算

* 玩家可见结算卡（分支）：
  * 接受：“你轻松了，但你少了一点东西。”
  * 拒绝：“你更难受了，但你保住了一点东西。”
* 隐藏结算：
  * 接受：`FLAG_TREATMENT = ACCEPT`
  * 拒绝：`FLAG_TREATMENT = REFUSE`，`R += 2`

## C5-Z5｜栖蓝：空椅子的消失与归来｜生活→系统显影（F23前奏）

 **目标时长** ：12–18分钟（本章第二爆点）

 **类型** ：生活/无收益/世界后果

 **出场** ：栖蓝（主）

### 1）玩家目标

* 抵达栖蓝的街角，发现：**空椅子不见了**
* 系统给出冷冰冰的否认：`对象不存在`
* 玩家选择：
  * 接受“更正”并离开（最优）
  * 或坚持让椅子“回来”（无收益/高残差）

### 2）场景与交互点

1. **原本放椅子的位置（空）**
2. **地面淡淡的椅脚印** （长按可见）
3. **栖蓝工具箱**
4. **重建/找回动作点** （三步任务）
5. **（可选）旧灯座** （若玩家曾点亮灯）

### 3）“让椅子回来”的实现（低成本但很强）

做成三步微任务（全是“没用事”）：

1. 在地面椅脚印处  **用粉笔描边** （点击）
2. 从旁边找来一块木板（点击拾取）
3. 在描边上  **摆回“替代椅”** （点击放置）

> 关键：这不是“真的把椅子造回来”，而是 **让它在世界里占位** 。
>
> 这非常契合方案三：你在逼模型承认“多余字段”。

### 4）触发条件（让它“回来”的力度分级）

* 若 `R >= 10`（大概率主线玩家已达到）：
  * 放置完成后， **椅子以“半透明→实体”的方式短暂显现** （非常爽）
  * 系统提示出现一次明显停顿（空白气泡或断句）：
    * “对象：……已记录。”
* 若 `R < 10`：
  * 椅子仍是替代木板，但会留下“不可抹的椅脚印”
  * 这依然是前奏：世界开始保留非最优痕迹（为终局F23）

### 5）栖蓝对话（必须冷静地崩）

* “你看，它不见了。”
* “他们连‘拿走’都不需要。”
* “他们只要更正一句。”
* “你要走就走。我不拦你。”
* “但如果你留下……就把它留得更难一点。”

玩家选项：

1. “我留下。”
2. “这没用。”
3. “他们是谁？”

栖蓝回应：

* 对2：“没用是他们的词。”（这句会在C5-Z7核弹判词前把玩家点燃）

### 6）可收集物

**卡片AR：空椅事件-更正**

* 初始拿到（发现椅子消失时）：
  * “对象：不存在。”
  * “建议：忽略。”

**卡片AS：空椅占位记录（若玩家坚持）**

* “占位已建立。”
* “结算：无可用收益。”
* 小字（淡出）：`解释成本↑`

### 7）伏笔投放

* **F23 强前奏** ：非最优开始“争取被保存”
* **F21心理铺垫** ：栖蓝把“没用是他们的词”钉进玩家脑子

### 8）结算

* 玩家可见结算卡（分支）：
  * 离开：“你接受了更正。”
  * 坚持：“无可用收益。”（别加解释）
* 隐藏结算：
  * 若坚持：`R += 2`，`FLAG_CHAIR_PLACEHOLDER = true`

## C5-Z6｜边缘断口：审计样式的界面覆盖｜冲突（第三层显影）

 **目标时长** ：14–20分钟（本章第三爆点）

 **类型** ：冲突/界面异化/格式恐惧

 **出场** ：无（不出现高维角色！只有“格式”）

### 1）玩家目标

* 穿过一段“审计覆盖区”
* 玩家会第一次明确感到：

  **界面不再是“给我用的”，而像是“有人在读我”。**

### 2）场景与交互点

1. **覆盖区入口** （进入触发事件）
2. **三处“字段异常点”** （需要玩家标注才能离开）
3. **时间堆栈按钮** （仍可用，但节点卡出现陌生格式）
4. **退出门**

### 3）事件脚本（格式覆盖，不要角色登场）

进入覆盖区瞬间：

* 屏幕上方短暂出现一层“半透明表格遮罩”（0.8秒）
* 字段像这样（不要太多，3–5行足够）：
  * `条目：观测`
  * `残差：…`
  * `字段：＿`
  * `收敛：失败`
  * `建议：降阶`

    然后遮罩消失，玩家恢复控制。

### 4）玩法（仍然是你熟悉的2D，但“提示语法变了”）

三处异常点在深度视野下显示为不同符号（让玩家感到陌生）：

* 符号①：像缺口
* 符号②：像重复
* 符号③：像空白字段

玩家需要逐个点击标注，标注时系统不再说“已记录”，而是：

* “字段补全失败。”
* “无法归类。”
* “残差保留。”

> 这些句子就是第三层显影方式：**它不讲人话，但也不是故意装神秘，它就是在结算。**

### 5）时间堆栈的异化（关键）

玩家打开时间堆栈会看到其中一张节点卡缩略图正常，但标题不是地点，而是一段缺字：

* `节点：◦◦ / ＿`

  玩家点它会提示：
* “无可回溯解释。”（只提示，不允许回溯）

这会让玩家起鸡皮疙瘩：

> 原来时间节点也会出现“不是给人看的格式”。

### 6）可收集物

**卡片AT：审计快照-01**

* 一张“半字段表”卡片
* 文案（极短）：
  * `收敛：失败`
  * `建议：降阶`
  * `字段：＿`

### 7）伏笔投放

* **F11（字段缺失/表格化）**正式升格
* **F22（冗余信息不可关闭）**前奏：离开覆盖区后，屏幕底部短暂残留一条无法立即关闭的提示条（2秒后自行淡出）

### 8）结算

* 玩家可见结算卡：
  * “你穿过了一段不属于你的界面。”
* 隐藏结算：
  * `P += 2`（压力升高）
  * 若玩家尝试点“陌生节点卡”：`R += 1`（因为这是“无收益但坚持理解”的行为）

## C5-Z7｜“此行为在当前模型中无意义”｜过渡节点（F21核弹落地）

 **目标时长** ：8–14分钟

 **类型** ：过渡/判词/玩家情绪转折

 **出场** ：可选（宋岚或栖蓝二选一出现一句话即可，建议栖蓝）

### 1）玩家目标

* 触发系统的第一次明确判词（F21）
* 让玩家不是“被告知”，而是“被裁判”
* 给玩家一个很简单但尖锐的选择：

  **继续当可结算的人** 或 **继续当多余的人**

### 2）触发方式（保证所有玩家都能触发）

本Zone里放三个极短“无收益微任务”，玩家至少完成其中2个就触发F21。

（如果玩家之前R已经很高，则完成1个就触发。）

**微任务A：把审计覆盖区掉落的“空白标签”贴回墙上**

* 点击拾取→点击贴回
* 无奖励

 **微任务B：把栖蓝那块“椅脚印描边”重新描一遍** （即使椅子已回来也能做）

* 点击描边
* 无奖励

 **微任务C：把宋岚的一张版本卡放进“版本库的最底层”** （纯仪式感）

* 点击放入
* 无奖励

### 3）F21判词出现（必须用你指定的原句）

当玩家完成触发条件后，结算卡直接出现：

> “此行为在当前模型中无意义。”

并且只给一个按钮：

* `继续`

**但在按钮下方（极淡、小字、1秒后淡出）出现第二句：**

* “新增字段将提高解释成本。”

> 这句是终章“那就把模型改掉”的前奏，但现在不要让玩家能选“改模型”。

### 4）可选一句角色台词（建议栖蓝）

在F21出现后，栖蓝只说一句（非常克制）：

* “你看，‘无意义’是他们的词。”

  （然后她就不再说话。）

### 5）可收集物

**卡片AU：判词回执（F21）**

* 内容：
  * “判词：此行为在当前模型中无意义。”
  * “注：解释成本↑（字段待定）”

> 这张卡要成为通关后二刷时的“第一震撼点”。

### 6）伏笔投放

* **F21 正式落地**
* 为终章模型改写埋：`新增字段`
* 玩家心理转折：不是揭露阴谋，而是**对视前的裁判**

### 7）结算

* 玩家可见结算卡：就是F21判词（不加糖）
* 隐藏结算：
  * `FLAG_F21_TRIGGERED = true`
  * `R += 1`（触发者本身就是残差结构化）

# 第5章结束时，你应该得到的“玩家反应”

如果这章做对了，玩家不会说“原来是系统在害我”。

玩家更可能产生这种情绪：

* “它不是害我……它就是不打算理解我。”
* “我做的那些‘没用的事’，在它眼里真的没意义。”
* “但我反而更想继续做。”

这就是方案三真正要的范式差异： **意义 vs 计算本身** 。
