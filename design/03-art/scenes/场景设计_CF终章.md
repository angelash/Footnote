# 《备注》场景设计 - CF 终章

> **章节主题**："你想让世界变成什么样？"  
> **目标时长**：1.5-2小时  
> **Zone数量**：5个（含3结局分支）  
> **区域**：收敛核心 + 三结局场景  
> **核心事件**：三结局选择与伏笔全回收

### 结局解锁条件
```
结局A（平面稳定）:
- 默认可选
- 条件: 无特殊要求

结局B（真实释放）:
- 条件: R ≥ 6 且 完成版本保留任务
- 需要: 在C5选择保留纪念墙

结局C（成为系统）:
- 条件: R ≥ 10
- 需要: 完成全部无收益行为
- 隐藏: P ≥ 8 时解锁特殊变体
```

### 顾临与宋岚对话
```
（两人对立）

顾临: "你已经走到这里了。"
宋岚: "你做的每一件事，都在这里。"
顾临: "是时候选择了。"

【三选项说明浮现】

顾临 (指向A门):
"继续收敛。城市会恢复可读。"
"代价是...那些你记录的东西，会被格式化。"

宋岚 (指向B门):
"松动表示。让真实的东西回来。"
"代价是...可读性会下降，有些人会迷路。"

（C门自动显现，如果条件满足）
系统声音 (指向C门):
"成为新的字段承载者。"
"代价是...你自己。"
```

世界恢复了可读性。

顾临把你升为高级例外处理器。

世界变得简洁，
