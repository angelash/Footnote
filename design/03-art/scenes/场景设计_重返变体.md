# 《备注》场景设计 - 重返变体（Revisit Variants）

> **说明**：重返变体是玩家在获得新能力后回到旧场景时的变化版本  
> **总数量**：12个重返变体  
> **解锁条件**：获得深度感知/深度介入/时间干预后自动解锁  
> **核心体验**：同一场景，不同视角，揭示隐藏层

---

## 📌 重返变体设计原则

### 变体触发机制
```
触发条件:
1. 玩家获得新能力（深度感知/深度介入/时间干预）
2. 玩家主动返回已完成的Zone
3. 系统检测能力等级 → 加载对应变体

变体层级:
- V1: 深度感知变体（只看不动）
- V2: 深度介入变体（可改变结构）
- V3: 时间干预变体（可回溯）
```

### 视觉变化规则
```
深度感知激活时:
- 场景增加"深层信息叠加层"
- 隐藏文字/符号显现
- 颜色偏移（增加蓝紫色调）

深度介入激活时:
- 场景增加"可交互结构标记"
- 伤痕/裂缝可见
- 部分物体可移动/改变

时间干预激活时:
- 场景增加"时间线叠影"
- 过去/现在/潜在状态同时显示
- 时间节点标记
```

## 🎯 重返设计要点

### 必须遵循的原则
```
1. 重返不是必须的
   - 玩家可以不重返任何场景
   - 主线不依赖重返内容
   - 但重返能补全伏笔和理解

2. 重返有代价
   - 深度介入会留下伤痕
   - 时间干预会增加污染
   - 过度重返会影响W值

3. 重返有奖励
   - 隐藏卡片/档案
   - 伏笔理解加深
   - R机会点

4. 重返影响结局
   - 某些重返选择影响结局条件
   - 重返次数计入最终统计
```
