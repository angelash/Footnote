## 📌 风格定位

```
赛博-东方极简 · 系统感 · 深色调 · 荧光强调 · 克制表达 · 信息层次
```

### 视觉哲学

> 视觉是叙事的延伸，而非装饰。  
> 每一个视觉元素都应该服务于世界观的表达："被压缩的表示"、"收敛运行时的存在感"、"人类可读性与系统真相的张力"。

## 1. 色彩系统

### 1.1 主色板

#### 背景色系

| 名称 | 色值 | RGB | 用途 |
|------|------|-----|------|
| **深空黑** | `#0A0E17` | 10,14,23 | 最深背景 |
| **夜幕蓝** | `#141B2D` | 20,27,45 | 面板背景 |
| **暮色靛** | `#1E2940` | 30,41,64 | 卡片背景 |
| **边界灰** | `#2A3A5A` | 42,58,90 | 分隔线、边框 |

#### 强调色系

| 名称 | 色值 | RGB | 用途 |
|------|------|-----|------|
| **量子青** | `#00F5D4` | 0,245,212 | 主强调、可交互 |
| **琥珀光** | `#FFD166` | 255,209,102 | 警告、重要 |
| **脉冲红** | `#FF6B6B` | 255,107,107 | 危险、错误 |
| **稳定绿** | `#4ECB71` | 78,203,113 | 成功、确认 |
| **收敛紫** | `#A855F7` | 168,85,247 | 系统、高维 |

#### 特殊状态色

| 状态 | 色值 | 用途 |
|------|------|------|
| **正常** | `#00F5D4` | 系统正常运行 |
| **警戒** | `#FFD166` | 观察者压力上升 |
| **纠偏** | `#FF9F43` | 系统正在纠偏 |
| **临界** | `#FF6B6B` | 世界不稳定 |
| **显影** | `#A855F7` | 第三层显影 |

### 1.2 色彩使用原则

```
深色主导 (85%)
├── 背景: 深空黑/夜幕蓝
├── 面板: 暮色靛
└── 内容: 边界灰

荧光点缀 (15%)
├── 交互元素: 量子青
├── 警告信息: 琥珀光
├── 系统元素: 收敛紫
└── 状态指示: 对应状态色

禁止:
× 大面积白色
× 饱和度过高的背景
× 同时使用3种以上强调色
```

## 2. 视觉层次

### 2.1 层次结构

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│  Layer 5: 系统覆盖层 (异常/第三层显影)                       │
│  ─────────────────────────────────────────────────────────  │
│  Layer 4: UI层 (对话框、菜单、HUD)                          │
│  ─────────────────────────────────────────────────────────  │
│  Layer 3: 特效层 (能力效果、转场)                           │
│  ─────────────────────────────────────────────────────────  │
│  Layer 2: 前景层 (角色、可交互物体)                         │
│  ─────────────────────────────────────────────────────────  │
│  Layer 1: 中景层 (场景元素、装饰)                           │
│  ─────────────────────────────────────────────────────────  │
│  Layer 0: 背景层 (背景图、远景)                             │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 深度感知视觉层

```
正常状态:
┌─────────────────┐
│ ████████████████ │  实体层 (正常可见)
│ ██ 场景内容 ████ │
│ ████████████████ │
└─────────────────┘

深度感知激活:
┌─────────────────┐
│ ░░░░░░░░░░░░░░░░ │  实体层 (半透明)
│ ┌─┐ ┌─┐ ┌───┐   │
│ │ │ │ │ │   │   │  线框层 (隐藏结构)
│ └─┘ └─┘ └───┘   │
│ ░░░░░░░░░░░░░░░░ │
└─────────────────┘

视觉表现:
- 实体层透明度降至40%
- 叠加青色线框层
- 隐藏结构以发光线框显示
- 边缘添加扫描线效果
```

## 3. 资源规格

### 3.1 背景资源

| 属性 | 规格 | 说明 |
|------|------|------|
| **尺寸** | 750×1334 ~ 750×3000 | 根据Zone高度 |
| **格式** | SVG (首选) / PNG | SVG可缩放 |
| **颜色** | 深色调为主 | 符合色彩系统 |
| **复杂度** | 中等 | 不抢角色注意力 |

#### 背景分层

```yaml
background_layers:
  - layer: sky
    depth: 0
    parallax: 0.2
    
  - layer: far_buildings
    depth: 1
    parallax: 0.4
    
  - layer: mid_structures
    depth: 2
    parallax: 0.6
    
  - layer: ground
    depth: 3
    parallax: 1.0
```

### 3.2 角色资源

#### 立绘规格

| 属性 | 规格 |
|------|------|
| **高度** | 500-600px |
| **格式** | SVG |
| **表情** | 基础4种 (中立/喜/忧/惊) |
| **风格** | 干净线条、简化细节 |

#### 头像规格

| 属性 | 规格 |
|------|------|
| **尺寸** | 128×128px |
| **格式** | SVG |
| **背景** | 透明或深色 |
| **边框** | 可选2px圆角 |

#### 角色设计要点

```
1. 剪影识别度高
   - 每个角色有独特轮廓
   - 缩小后仍可辨认

2. 色彩标识
   - 每个角色有专属色彩
   - 岑回: 蓝灰
   - 顾临: 深蓝金边
   - 栖蓝: 青绿
   - ...

3. 服装设计
   - 体现身份和性格
   - 简洁但有特征
   - 避免过度装饰
```

## 5. 场景设计规范

### 5.1 六大区域视觉风格

#### 居住环

```
氛围: 温暖中带疏离
色调: 暖灰 + 少量暖光
元素: 旧楼、走廊、小店
光源: 路灯、店铺灯光
特征: 生活痕迹、但空旷
```

#### 市政环

```
氛围: 秩序、冷静、压迫
色调: 冷蓝灰 + 金属质感
元素: 办公楼、档案柜、标准化
光源: 冷白日光灯
特征: 对称、重复、标准化
```

#### 档案巷

```
氛围: 怀旧、神秘、层叠
色调: 褐色 + 暗黄
元素: 纸堆、旧地图、版本号
光源: 昏暗台灯
特征: 时间痕迹、版本叠加
```

#### 诊疗台

```
氛围: 洁净、不安、边界
色调: 白+蓝 (但不刺眼)
元素: 医疗设备、病例卡
光源: 均匀柔光
特征: 过度整洁带来的不适
```

#### 礼堂街

```
氛围: 神秘、仪式、隐喻
色调: 深紫红 + 金
元素: 祭台、符号、祷文
光源: 烛光、神秘光晕
特征: 宗教感但非具体宗教
```

#### 边缘断口

```
氛围: 危险、异常、真相
色调: 深黑 + 荧光裂隙
元素: 断裂、扭曲、不存在的空间
光源: 异常光源、裂隙发光
特征: 结构异常可视化
```

## 6. 特效设计

### 6.1 能力特效

#### 深度感知

```
激活过程 (0.5s):
1. 屏幕边缘渐暗
2. 主体色调偏青
3. 扫描线从上到下
4. 线框层渐入

持续状态:
- 边缘暗角保持
- 轻微噪点覆盖
- 线框层持续显示
- 隐藏内容发光
```

#### 深度介入

```
介入过程 (1-2s):
1. 目标高亮
2. 拖拽轨迹发光
3. 结构变形动画
4. 伤痕创建动画
5. 涟漪扩散效果

伤痕持续显示:
- 裂缝纹理
- 边缘发光 (低强度)
- 偶尔闪烁
```

#### 时间干预

```
回溯过程 (2s):
1. 画面开始回放倒转
2. 颜色偏移加剧
3. 时间线UI突出
4. 闪白
5. 新状态淡入

污染效果:
- 画面边缘色差
- 偶尔的帧错位
- 微妙的重影
```

### 6.2 UI特效

| 效果 | 用途 | 实现 |
|------|------|------|
| **呼吸光** | 可交互提示 | opacity动画 |
| **脉冲** | 重要提示 | scale+opacity |
| **扫描线** | 系统感 | 线性渐变动画 |
| **故障** | 异常状态 | 随机位移+色差 |
| **淡入淡出** | 通用转场 | opacity |

## 7. 资源命名规范

### 7.1 文件命名

```
格式: {类型}_{对象}_{变体}.{扩展名}

示例:
背景: bg_c0z1.svg, bg_shop_morning.svg
角色: char_cenhui_idle.svg, char_gulin_happy.svg
头像: portrait_qilan_neutral.svg
图标: icon_ability_perception.svg
特效: fx_depth_perception.svg
UI:   ui_panel_dialogue.svg
```

### 7.2 图层命名 (SVG/PSD)

```
规范:
- 使用英文小写
- 下划线分隔
- 说明功能/内容

示例:
background_base
building_far
building_near
character_layer
foreground_elements
lighting_effects
```
