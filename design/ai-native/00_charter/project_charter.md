## 1. 项目目标（MVP）

### 1.1 核心目标

| 目标 | 可量化标准 | 验收方法 |
|------|-----------|---------|
| **完成10-12小时叙事体验** | 7章×45分钟平均 ≈ 5-6小时主线 + 变体 | 全流程计时测试 |
| **三结局全部可达成** | 结局A/B/C独立触发条件完整 | E2E测试覆盖 |
| **H5竖版可运行** | 750×1334基准分辨率正常显示 | 设备兼容测试 |
| **微信小游戏上线** | 通过微信审核 | 平台审核通过 |

### 1.2 体验目标

> **核心体验 (One-liner)**:  
> 你生活在一个二维世界，但你能短暂触碰更高维度——代价是：世界会记住你做过的一切。

| 体验指标 | 目标值 | 测量方法 |
|---------|-------|---------|
| 首次游玩完成率 | ≥40% | 分析埋点 |
| 章节留存率 | C1→C2 ≥60% | 存档统计 |
| 多结局达成率 | ≥20%玩家达成2+结局 | 存档统计 |
| NPS评分 | ≥50 | 玩家调研 |

### 1.3 质量目标

| 指标 | 目标值 | 验收条件 |
|------|-------|---------|
| 首屏加载 | <3s (4G网络) | Lighthouse测试 |
| 运行帧率 | ≥60fps | 性能监控 |
| 单场景内存 | <100MB | Chrome DevTools |
| Blocker缺陷 | 0 | QA验收 |
| Critical缺陷 | ≤3 | QA验收 |

## 2. 项目范围

### 2.1 In-Scope（必须交付）

#### 内容范围
- **章节**: 序章(C0) + 5章(C1-C5) + 终章(CF) = 7章
- **Zone**: 45个主线 + 12个重返变体 = 57个
- **对白**: ~15,000字（主线）+ ~5,000字（支线）
- **卡片**: 8套卡片系统数据
- **角色**: 8个核心角色完整人生线

#### 系统范围
- **叙事系统**: 对白/事件/条件解析
- **能力系统**: 深度感知/深度介入/时间干预
- **计数器系统**: R/P/W隐藏计数
- **存档系统**: IndexedDB多槽位
- **UI系统**: 对话/卡片/菜单/暂停

#### 平台范围
- 微信小游戏
- 移动端浏览器（iOS Safari / Android Chrome）
- PC浏览器（Chrome / Firefox / Edge）

### 2.2 Out-of-Scope（明确不做）

| 功能 | 原因 | 替代方案 |
|------|------|---------|
| 多人在线 | 单人叙事体验 | 无 |
| 实时语音 | 技术复杂度 | 无 |
| 内购商店 | 一次性买断 | 赞助入口 |
| 成就系统扩展 | MVP范围控制 | 基础成就即可 |
| 多语言版本 | 首发仅中文 | 后续迭代 |
| 跨设备云存档 | 技术复杂度 | 本地存档 |

### 2.3 Scope Freeze（范围锁定）

以下内容**已完成**，不再接受重大变更：

| 已锁定内容 | 位置 | 锁定日期 |
|-----------|------|---------|
| 世界观三层结构 | `design/01-narrative/世界观完整版 v3.md` | 2024-12 |
| 8核心角色设定 | `design/01-narrative/角色人生线档案 v2.md` | 2024-12 |
| 20+伏笔系统 | `design/01-narrative/伏笔索引 v2.md` | 2024-12 |
| 章节Zone骨架 | `design/01-narrative/区域骨架.md` | 2024-12 |
| 核心玩法三能力 | `design/02-system/核心玩法系统设计.md` | 2024-12 |

## 4. 禁区（Forbidden）

### 4.1 技术禁区

| 禁止行为 | 原因 | 替代方案 |
|---------|------|---------|
| 硬编码对白文本 | 维护困难 | YAML数据文件 |
| 直接操作DOM | Phaser架构 | Phaser API |
| 使用var | 代码规范 | const/let |
| 忽略TypeScript错误 | 类型安全 | 修复或as断言 |
| 引入新npm依赖（未经CR） | 包体控制 | CR流程审批 |

| 改变三结局框架 | 已锁定 |

## 6. 风险边界

### 6.1 技术风险

| 风险 | 等级 | 触发条件 | 应对措施 |
|------|------|---------|---------|
| H5性能不足 | Medium | 帧率<30fps | 降级渲染/分级加载 |
| 存档丢失 | High | IndexedDB清空 | 导出备份功能 |
| 包体过大 | Medium | >10MB | 资源压缩/分包 |
| 兼容性问题 | Medium | 某平台白屏 | 降级方案 |

### 6.2 内容风险

| 风险 | 等级 | 触发条件 | 应对措施 |
|------|------|---------|---------|
| 对白量超标 | Low | >25000字 | 精简/分期 |
| 伏笔遗漏 | Medium | 回收失败 | 追踪表管理 |
| 叙事Bug | Medium | 逻辑矛盾 | 测试覆盖 |

### 6.3 资源风险

| 风险 | 等级 | 触发条件 | 应对措施 |
|------|------|---------|---------|
| 美术资源延期 | Medium | 进度<50% | AI生图加速 |
| 音频缺失 | Low | 关键音效缺 | 素材库替代 |
