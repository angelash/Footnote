## 1. 视觉风格定义

### 1.1 整体风格

| 属性 | 定义 |
|------|------|
| **主风格** | 2D像素风 / 简约矢量风 |
| **色调** | 深色主调 + 荧光强调色 |
| **氛围** | 压抑神秘、偶有温暖 |
| **参考** | Hyper Light Drifter, Kentucky Route Zero, Inside |

### 1.2 配色体系

| 色彩类型 | 用途 | 色值参考 |
|---------|------|---------|
| **背景基色** | 场景底色 | `#1a1a2e`, `#16213e` |
| **前景主色** | 角色/物件 | `#e94560`, `#0f3460` |
| **强调色** | 交互/能力 | `#00F5D4`, `#ff00ff` |
| **文字色** | UI文本 | `#ffffff`, `#a0a0a0` |
| **警示色** | 危险/伤痕 | `#ff4444`, `#ffaa00` |

### 1.3 能力效果配色

| 能力 | 主色 | 辅色 | 效果描述 |
|------|------|------|---------|
| 深度感知 | 青色 `#00F5D4` | 蓝色 `#0077ff` | 透视/X射线效果 |
| 深度介入 | 品红 `#ff00ff` | 紫色 `#8800ff` | 扭曲/裂痕效果 |
| 时间干预 | 橙色 `#ffaa00` | 红色 `#ff4444` | 倒流/污染效果 |

## 3. 输出规格

### 3.1 图像规格表

| 类型 | 尺寸 | 格式 | 命名规则 | 锚点 |
|------|------|------|---------|------|
| **背景** | 750×1334 | PNG/SVG | `bg_{area}_{name}` | 中心 |
| **角色立绘** | 512×512 | PNG | `char_{name}_{state}` | 底部中心 |
| **角色精灵** | 128×192 | PNG | `sprite_{name}_{dir}_{frame}` | 底部中心 |
| **头像** | 128×128 | PNG | `portrait_{name}_{emotion}` | 中心 |
| **物件** | 64×64~256×256 | PNG | `obj_{category}_{name}` | 底部中心 |
| **UI图标** | 32×32 / 64×64 | PNG/SVG | `icon_{name}` | 中心 |
| **卡片图** | 200×280 | PNG | `card_{type}_{id}` | 中心 |
| **特效帧** | 128×128~256×256 | PNG | `fx_{name}_{frame}` | 中心 |

### 3.2 命名规则详解

```
格式: {类型}_{分类}_{名称}_{变体}.{扩展名}

类型前缀:
- bg_      背景
- char_    角色
- sprite_  精灵图
- portrait_ 头像
- obj_     物件
- icon_    图标
- card_    卡片
- fx_      特效

分类:
- 背景: residential, municipal, archive, clinic, chapel, core
- 角色: player, cenhui, gulin, songlan, xuchen, atang, muping, qilan, chenjiang
- 物件: furniture, prop, interact
- 特效: depth, time, scar

变体:
- 方向: n, s, e, w, ne, nw, se, sw
- 帧数: 01, 02, 03...
- 状态: idle, walk, talk, active
- 情绪: neutral, happy, sad, angry, surprised
```

### 3.3 校验脚本

```bash
# 命名校验命令
npm run validate:assets

# 校验规则
# 1. 文件名全小写 + 下划线
# 2. 符合前缀规则
# 3. 尺寸符合规格
# 4. 格式符合要求
```

## 4. 生成规范

### 4.1 AI 生图约束

| 约束类型 | 具体要求 |
|---------|---------|
| **风格一致性** | 必须使用统一的 LoRA/风格提示词 |
| **色彩范围** | 限制在定义的配色体系内 |
| **尺寸标准** | 按规格表输出，不得随意缩放 |
| **命名规范** | 按命名规则命名，入库前校验 |
| **后处理** | 统一进行锐化/降噪/调色 |

### 4.2 风格一致性检查点

| 检查项 | 标准 | 工具 |
|-------|------|------|
| 色彩范围 | 主要色值在定义范围内 | 色彩分析脚本 |
| 边缘处理 | 统一的线条粗细 | 人工检查 |
| 光影风格 | 统一的打光方向 | 人工检查 |
| 透明度 | PNG带正确Alpha | 脚本校验 |

### 4.3 白盒资源标准

开发阶段使用白盒资源，需满足：

| 属性 | 要求 |
|------|------|
| **颜色** | 功能色区分（红=危险，绿=安全，蓝=交互） |
| **形状** | 简单几何形（矩形/圆形/三角形） |
| **文字** | 必须有类型标注文字 |
| **锚点** | 与最终资源一致 |

## 5. 音频规范

### 5.1 BGM 规格

| 属性 | 规格 |
|------|------|
| **格式** | MP3 / OGG |
| **采样率** | 44.1kHz |
| **比特率** | 128-192kbps |
| **时长** | 60-180秒（可循环） |
| **命名** | `bgm_{area}_{mood}.mp3` |

### 5.2 SFX 规格

| 属性 | 规格 |
|------|------|
| **格式** | MP3 / WAV |
| **采样率** | 44.1kHz |
| **比特率** | 128kbps+ |
| **时长** | 0.1-3秒 |
| **命名** | `sfx_{category}_{action}.mp3` |

### 5.3 音频分类

| 类别 | 前缀 | 示例 |
|------|------|------|
| UI交互 | `sfx_ui_` | `sfx_ui_click`, `sfx_ui_hover` |
| 角色 | `sfx_char_` | `sfx_char_footstep` |
| 环境 | `sfx_env_` | `sfx_env_door`, `sfx_env_wind` |
| 能力 | `sfx_ability_` | `sfx_ability_depth_activate` |
| 系统 | `sfx_sys_` | `sfx_sys_save`, `sfx_sys_alert` |

### 5.4 BGM 场景映射

| 区域 | BGM | 情绪 |
|------|-----|------|
| 居住环 | `bgm_residential_calm` | 平静、日常 |
| 市政环 | `bgm_municipal_official` | 秩序、压抑 |
| 档案巷 | `bgm_archive_mystery` | 神秘、探索 |
| 诊疗台 | `bgm_clinic_tense` | 紧张、不安 |
| 礼堂街 | `bgm_chapel_sacred` | 庄严、仪式 |
| 核心区 | `bgm_core_finale` | 紧迫、史诗 |

## 8. 资产入库流程

### 8.1 流程图

```
创作/生成 → 命名规范化 → 尺寸校验 → 格式检查 → 入库
                │
                ↓
        校验失败 → 返工修改
```

### 8.2 入库检查清单

- [ ] 文件名符合命名规则
- [ ] 尺寸符合规格表
- [ ] 格式正确（PNG/SVG/MP3/OGG）
- [ ] 透明度正确（PNG）
- [ ] 色彩在允许范围内
- [ ] 锚点设置正确
- [ ] 通过自动校验脚本

## 9. 禁止事项

### 9.1 视觉禁区

| 禁止行为 | 原因 |
|---------|------|
| 使用未授权素材 | 版权风险 |
| 随意改变配色体系 | 风格一致性 |
| 不按规格输出 | 集成问题 |
| 跳过命名规范 | 管理困难 |
| 不做风格校验 | 一致性问题 |

### 9.2 音频禁区

| 禁止行为 | 原因 |
|---------|------|
| 使用未授权音乐 | 版权风险 |
| 音量不统一 | 体验问题 |
| 格式不规范 | 兼容问题 |
| 缺少淡入淡出 | 听感突兀 |
