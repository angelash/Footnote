## 1. 体验目标

### 1.1 核心体验 (One-liner)

> **你生活在一个二维世界，但你能短暂触碰更高维度——代价是：世界会记住你做过的一切。**

### 1.2 体验层次

| 层级 | 阶段 | 玩家感受 | 设计目标 |
|------|------|---------|---------|
| **表层** | C0-C1 | "这个世界有点奇怪" | 建立好奇心 |
| **中层** | C2-C4 | "我的行为有不可逆的后果" | 代价感与紧张感 |
| **深层** | C5-CF | "原来世界的本质是这样" | 认知升级震撼 |

### 1.3 独特卖点 (USP)

| USP | 描述 | 竞品差异点 |
|-----|------|-----------|
| 维度折叠叙事 | 二维世界隐藏"深度格"结构 | 非传统多线叙事 |
| 不可逆后果系统 | 每次能力使用留下永久伤痕 | 非存档读档式体验 |
| 无收益行为价值 | "多余"行为推动终局 | 反游戏化设计 |
| 三层真相揭示 | 认知升级而非剧情反转 | 智识层面的满足 |

## 2. 世界观摘要（≤2页）

### 2.1 三层世界结构

| 层级 | 名称 | 玩家认知阶段 | 核心关键词 |
|------|------|-------------|-----------|
| **L1** | 人类可理解层 | C0-C2 | 使命、修复、灾害 |
| **L2** | 收敛运行时层 | C3-C5 | 对齐、结算、收敛 |
| **L3** | 高维观测尺度 | 终章 | 格式、字段、降阶 |

### 2.2 四大核心概念

| 概念 | 玩家理解 | 系统真相 |
|------|---------|---------|
| **主平面** | 二维世界 | 稳定表示/存档格式 |
| **深度格** | 被折叠的第三维 | 互斥结构的叠加态 |
| **因果账本** | 时间管理系统 | 全局自洽约束 |
| **收敛运行时** | 维护者系统 | 可读性保持机制 |

### 2.3 核心主题

> **从「自由 vs 控制」升级为「意义 vs 计算本身」**

终局不是揭露阴谋，而是：玩家的"无收益行为"在系统模型中创造了无法收敛的残差，迫使更高层模型降阶。

### 2.4 历史时间线（人类纪事）

1. **体积纪**：世界曾完整（至少3D+复杂时间结构）
2. **分支灾纪**：时间分支爆炸，因果冲突频发
3. **折叠纪**：维度折叠工程启动（Project PLANE）
4. **漂移纪（现世）**：折叠稳定性衰退，异常常态化

## 4. 系统清单

### 4.1 核心系统表

| 系统名 | 职责 | 输入 | 输出 | AI可改域 |
|--------|------|------|------|---------|
| **叙事系统** | 对白/事件/条件解析 | YAML数据 | 对话流/事件触发 | 对白文本 |
| **能力系统** | 三能力处理 | 玩家操作 | 世界状态变化 | 效果描述 |
| **计数器系统** | R/P/W追踪 | 玩家行为 | 计数器值/系统反馈 | 反馈文本 |
| **卡片系统** | 收集/查看/触发 | 触发条件 | 卡片数据 | 卡片文本 |
| **存档系统** | 进度/状态持久化 | 游戏状态 | IndexedDB | ❌ |
| **UI系统** | 界面展示/交互 | 用户操作 | 视觉反馈 | 提示文本 |
| **音频系统** | BGM/SFX播放 | 事件触发 | 音频播放 | ❌ |

### 4.2 三种能力

| 能力 | 解锁章节 | 操作方式 | 核心体验 | 代价 |
|------|---------|---------|---------|------|
| **深度感知** | C2-Z1 | 长按屏幕 | "看见而不能改变" | P轻微增加 |
| **深度介入** | C3-Z1 | 拖拽操作 | "改变留下伤痕" | 永久伤痕+P增加 |
| **时间干预** | C4-Z2 | 卡片UI | "回溯洗不净" | 污染+P大增 |

### 4.3 隐藏计数器

| 计数器 | 定义 | 累积方式 | 阈值效果 |
|--------|------|---------|---------|
| **R** (无收益残差) | 无奖励行为累积 | 每次"多余"行为+1 | R≥3 系统语气停顿 |
| **P** (观察者压力) | 高维能力使用累积 | 能力使用增加 | 影响系统反馈强度 |
| **W** (世界可读性) | 综合稳定度 | R↑P↑则W↓ | W过低触发终局 |

### 4.4 R值阈值表

| R值 | 系统表现 |
|-----|---------|
| R ≥ 3 | 系统语气出现轻微停顿 |
| R ≥ 6 | 首次出现判定句 |
| R ≥ 10 | 终局"模型改写"路径开启 |

## 6. 三结局框架

### 6.1 结局总览

| 结局 | 名称 | 触发条件 | 主题 |
|------|------|---------|------|
| **A** | 平面稳定 | 低R值，配合收敛 | 继续收敛，保住可读性 |
| **B** | 真实释放 | 高R值，特定选择 | 表示松动，涌现回归 |
| **C** | 成为系统 | R≥10，最终对话 | 玩家成为新字段承载者 |

### 6.2 结局触发逻辑

```
if (R < 3) {
  // 结局 A 方向
} else if (R >= 10 && finalChoiceC) {
  // 结局 C
} else if (R >= 6 && finalChoiceB) {
  // 结局 B
} else {
  // 根据其他变量细分
}
```
