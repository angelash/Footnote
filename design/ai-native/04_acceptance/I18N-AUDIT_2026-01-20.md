## I18n 系统状态

### 实现位置与接口

- **I18n 管理器**：`game/src/systems/i18n/I18nManager.ts`
  - `i18n.t(key, params?)`：普通翻译 + `{param}`/`{{param}}` 插值
  - `i18n.tp(key, count, params?)`：复数形式
  - `i18n.tc(key, context, params?)`：上下文形式
  - `i18n.setLocale(locale)`：切换语言，写入 `localStorage('footnote_locale')`，并触发 `GameEvent.LOCALE_CHANGED`
  - 内置翻译：`BUILT_IN_TRANSLATIONS`（核心 UI 文本直接硬编码在 TS 中）

### 翻译资源加载现状

- **本地化加载器**：`game/src/data/locales/index.ts`
  - 能动态加载 `src/data/locales/{locale}/dialogues/{chapter}.yaml`、`cards.yaml`、`ui.yaml`
  - 加载后写入命名空间：`dialogues.{chapter}`、`cards`、`ui_ext`
  - **实际引用情况**：经全库扫描，`loadAllTranslations/preloadCurrentLocaleTranslations/switchLocaleWithTranslations` 等函数 **无调用方**（目前翻译文件不参与运行时）

## 问题清单（缺陷分级）

### P0（阻断级：国际化不可用）

- **P0-01：I18nManager 未在主 UI 中落地使用**
  - **证据**：全库扫描 `game/src/**/*.ts`，除 `I18nManager.ts` 外未发现 `i18n.t(...)` / `t(...)` / `ui.*` key 的使用
  - **影响**：语言切换与翻译体系对玩家不可见；所有 UI 文本无法按语言输出
  - **涉及文件示例**（大量硬编码中文）：
    - `game/src/scenes/MenuScene.ts`（“开始游戏/继续游戏/设置/选择存档/没有找到存档…”等）
    - `game/src/systems/ui/PauseMenu.ts`（“暂停/继续游戏/游戏设置/保存进度…”等）
    - `game/index.html`（加载屏“正在加载…”）

- **P0-02：本地化资源加载器未被调用（翻译文件不参与运行时）**
  - **证据**：`game/src/data/locales/index.ts` 的 `loadAllTranslations/switchLocaleWithTranslations` 无调用方
  - **影响**：`src/data/locales/*` 中的翻译文件即使完善，也不会进入 `i18n` 翻译 Map

- **P0-03：叙事对话/卡片文本链路未本地化**
  - **证据**：`game/src/data/NarrativeDataLoader.ts`、`game/src/systems/narrative/NarrativeEngine.ts` 的对话/卡片字段使用 **直接文本**（`text/title/content`），来自 `src/data/dialogues` 与 `src/data/cards` 的 YAML
  - **影响**：即使 UI 完成 i18n，核心内容仍只能输出中文

### P1（严重级：切换语言后体验不可控）

- **P1-01：LOCALE_CHANGED 事件缺少 UI 订阅/重绘机制**
  - `GameEvent.LOCALE_CHANGED` 目前主要在 `I18nManager` 发出；未见 UI 层统一订阅与刷新文本的实现

- **P1-02：语言切换入口缺失**
  - 菜单/暂停设置里未提供语言选项（方案附录中建议存在语言切换 UI）

### P2（一般级：文本长度/布局风险）

- **P2-01：按钮/标签普遍无 wordWrap/自适应**
  - `MenuScene` 主按钮（240px 固定宽）与 `PauseMenu` 按钮（450px 固定宽）均未对 label 做换行/缩放处理
  - `DialogueUI` 选项按钮文字未设置 `wordWrap`（英文本选项较长时易溢出）
  - `InventoryUI` 顶部 tab（90px 宽）若改为英文可能溢出

- **P2-02：硬编码单位/时间表达**
  - 例如 `MenuScene` 中“`${hours}小时${minutes}分钟`”“`游玩:`”等，需进入 i18n 与 locale format 体系

### P3（轻微/规范级）

- **P3-01：`<html lang>` 固定为 `zh-CN`**
  - 见 `game/index.html`；对可访问性/输入法/屏幕阅读器语言识别不友好

- **P3-02：字体栈对日文/繁中不够明确**
  - 当前主要使用 `Noto Sans SC`（见 `game/index.html`、`game/src/config/game.config.ts`、`game/src/config/ui.config.ts`）
  - 建议补充 `Noto Sans TC/JP` 或统一 `Noto Sans CJK`/多字体 fallback 栈，避免 glyph fallback 造成风格割裂

## 建议行动（按优先级）

### P0（本迭代必须）

- **A1：UI 文本全面接入 i18n**
  - 将 `MenuScene/PauseMenu/InventoryUI/CardUI/ToastManager/PreloadScene/index.html` 等用户可见字符串替换为 `i18n.t('...')`
  - 建议统一 key 空间：内置（`common/menu/settings/...`）+ 扩展（`ui_ext...`）二者择一并收敛

- **A2：启动流程加载翻译资源**
  - 在 `BootScene/PreloadScene` 或 `main.ts` 启动阶段调用 `preloadCurrentLocaleTranslations()`（并按章节懒加载 `loadChapterOnDemand`）
  - 让 `src/data/locales/*` 成为“真实数据源”，否则翻译文件永远不会被使用

- **A3：叙事内容本地化方案落地**
  - 需要做一次架构决策：对话/卡片字段存 “文本” 还是存 “key”
  - 推荐：对话/卡片 YAML 存 key（如 `dialogue.C0Z1_opening.line_01`），由 `i18n` 渲染最终文本；或按 locale 分文件加载并在 `NarrativeDataLoader` 层做映射

### P1（首发前应完成）

- **B1：语言切换入口 + 切换后全局重绘**
  - 在设置面板增加语言选项（枚举 `SupportedLocale`）
  - 建立 UI 组件的 locale-change 订阅与文本重绘（避免切换语言后仍显示旧文本）

### P2（回归与体验优化）

- **C1：文本长度适配专项**
  - 按钮 label 增加 `wordWrap` 或 “自动缩放到最大宽度”策略
  - `DialogueUI` 选项按钮文字增加 `wordWrap: { width: buttonWidth - padding }`
  - `InventoryUI` tab 改为更宽/自适应，或采用缩写策略（英文下尤需）

- **C2：字体栈与 lang 属性**
  - `index.html` 字体建议：`'Noto Sans SC', 'Noto Sans TC', 'Noto Sans JP', sans-serif`
  - `document.documentElement.lang` 随 `i18n.getLocale()` 更新（或首屏根据检测语言设置）
