# Milestone Acceptance Checklist v1.0

> **用途**: 里程碑节点的完整验收
> **执行频率**: 每个里程碑结束时
> **审批者**: L0 制作委员会 + L1 总监层

---

## 1. 里程碑定义

### M1: 基础可运行（MVP）

**目标**: 实现核心叙事闭环

#### 功能验收
- [ ] 游戏可启动到主菜单
- [ ] 新游戏可进入序章
- [ ] 完成 10-15 个事件链
- [ ] 至少 1 个关键选择
- [ ] 基础对话系统可用
- [ ] 基础存档系统可用
- [ ] 结局或返回菜单

#### 技术验收
- [ ] TypeScript 编译通过
- [ ] ESLint 无错误
- [ ] 单元测试通过
- [ ] Schema 校验通过
- [ ] 冒烟测试通过

#### 质量验收
- [ ] 无 Blocker 缺陷
- [ ] Critical 缺陷 ≤ 2
- [ ] 帧率 ≥ 30FPS
- [ ] 启动时间 < 5s

---

### M2: 叙事系统可用

**目标**: 完成 ch02 内容，UI 正式版

#### 功能验收
- [ ] C0-C2 章节内容完整
- [ ] 存档系统 v2（多槽位）
- [ ] UI 正式版（非占位）
- [ ] 卡片收集系统完整
- [ ] 伏笔系统基础功能

#### 技术验收
- [ ] 自动化回归测试覆盖
- [ ] 内容校验器完善
- [ ] 版本兼容机制

#### 质量验收
- [ ] 无 Blocker 缺陷
- [ ] Critical 缺陷 = 0
- [ ] 回归测试通过率 ≥ 95%

---

### M3: 核心玩法闭环

**目标**: 能力系统集成，多结局分支

#### 功能验收
- [ ] 深度感知能力可用
- [ ] 深度介入能力可用
- [ ] 时间干预能力可用
- [ ] R/P/W 计数器反馈
- [ ] 多结局分支初步实现
- [ ] C0-C3 章节完整

#### 技术验收
- [ ] 能力系统单元测试
- [ ] 计数器逻辑测试
- [ ] 性能优化基础

#### 质量验收
- [ ] 无 Blocker/Critical 缺陷
- [ ] Major 缺陷 ≤ 5
- [ ] 回归测试通过率 ≥ 98%

---

### M4: 全流程可玩

**目标**: 所有章节完成，美术资源替换

#### 功能验收
- [ ] 所有章节（C0-CF）完整
- [ ] 所有 45 个主线 Zone
- [ ] 12 个重返变体
- [ ] 三结局可达成
- [ ] 伏笔完整回收

#### 技术验收
- [ ] 资源加载优化
- [ ] 内存管理优化
- [ ] 异常监控完善

#### 质量验收
- [ ] 无 Blocker/Critical/Major 缺陷
- [ ] Minor 缺陷 ≤ 10
- [ ] 性能达标（60FPS）

---

### M5: 内测就绪

**目标**: 准备发布

#### 功能验收
- [ ] 所有功能稳定
- [ ] 用户体验优化完成
- [ ] 新手引导完善

#### 技术验收
- [ ] 生产环境配置
- [ ] 监控告警配置
- [ ] 备份恢复测试

#### 质量验收
- [ ] 无任何已知缺陷（或已有应对方案）
- [ ] 全流程测试通过
- [ ] 性能压力测试通过

## 2. 验收流程

```
┌────────────┐
│  功能冻结   │ ← 代码提交截止
└─────┬──────┘
      │
      ▼
┌────────────┐
│  全量测试   │ ← L2 QA组长组织
└─────┬──────┘
      │
      ▼
┌────────────┐
│  缺陷修复   │ ← 仅修复 Critical 以上
└─────┬──────┘
      │
      ▼
┌────────────┐
│  回归测试   │
└─────┬──────┘
      │
      ▼
┌────────────┐
│  验收评审   │ ← L0 + L1 总监
└─────┬──────┘
      │ 通过
      ▼
┌────────────┐
│  里程碑关闭 │
└────────────┘
```
