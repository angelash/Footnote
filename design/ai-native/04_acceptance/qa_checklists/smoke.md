# Smoke Test Checklist v1.0

> **用途**: 核心功能快速验证
> **执行频率**: 每日构建 / 重大变更后
> **执行者**: L3 测试执行 / E2E 自动化
> **时长**: 约 15-30 分钟

---

## 1. 核心路径（≤30条）

### 1.1 启动与菜单（5条）
- [ ] 游戏启动到 Logo 画面
- [ ] Logo 画面过渡到主菜单
- [ ] 主菜单显示完整（新游戏/继续/设置）
- [ ] "新游戏"按钮可点击
- [ ] "设置"按钮可进入设置界面

### 1.2 游戏进入（5条）
- [ ] 新游戏进入序章（C0）
- [ ] 序章加载完成无报错
- [ ] 首个 Zone 正常显示
- [ ] 场景元素加载正常
- [ ] 背景音乐正常播放

### 1.3 对话系统（5条）
- [ ] 对话框正常弹出
- [ ] 对话文字正常显示
- [ ] 打字机效果正常
- [ ] 点击/空格可推进对话
- [ ] 对话结束后正常关闭

### 1.4 选择系统（5条）
- [ ] 选择界面正常显示
- [ ] 选项按钮可点击
- [ ] 选择后跳转正确
- [ ] 选择结果影响后续剧情
- [ ] 选择记录正确保存

### 1.5 卡片系统（3条）
- [ ] 获得卡片有提示
- [ ] 背包可打开查看
- [ ] 卡片详情可查看

### 1.6 存档系统（4条）
- [ ] 自动存档正常触发
- [ ] 手动存档可执行
- [ ] 读档可恢复进度
- [ ] 存档槽位显示正确

### 1.7 Zone 切换（3条）
- [ ] Zone 切换有过渡
- [ ] 切换后场景正确加载
- [ ] 切换后状态正确保持

## 2. 快速回归项（重点关注）

每次冒烟测试必须重点验证：

| 优先级 | 功能 | 说明 |
|--------|------|------|
| P0 | 游戏启动 | 必须能启动 |
| P0 | 新游戏 | 必须能开始新游戏 |
| P0 | 对话推进 | 必须能推进对话 |
| P0 | 存档读档 | 必须能保存/恢复进度 |
| P1 | 选择分支 | 选择必须能正确跳转 |
| P1 | 卡片收集 | 卡片必须能正常获得 |

## 4. 失败处理

### 4.1 阻断条件
以下任一项失败，**冒烟不通过**，阻断后续测试：
- 启动与菜单（任一项）
- 游戏进入（任一项）
- 对话系统（核心3项）
- 存档系统（读档项）

### 4.2 缺陷分类
| 失败类别 | 缺陷级别 |
|----------|----------|
| 启动失败 | Blocker |
| 崩溃/黑屏 | Blocker |
| 主流程卡死 | Blocker |
| 功能不可用 | Critical |
| 功能异常 | Major |
| 显示异常 | Minor |
