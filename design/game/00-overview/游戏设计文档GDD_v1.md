## 1. 产品概述

### 1.1 基础信息

| 项目 | 内容 |
|------|------|
| **游戏名称** | 《备注 / Footnote》 |
| **类型** | 叙事驱动2D策略冒险 |
| **平台** | H5移动端（竖版） |
| **目标分辨率** | 750×1334px（iPhone 8基准） |
| **游戏时长** | 10-12小时（首周目） |
| **付费模式** | 一次性买断 / 免费+可选赞助 |
| **目标上线** | 2025 Q2 |
| **开发引擎** | Phaser 3 + TypeScript |
| **目标平台** | 微信小游戏 / 移动端浏览器 / PC浏览器 |

### 1.2 核心体验（One-liner）

> **你生活在一个二维世界，但你能短暂触碰更高维度——代价是：世界会记住你做过的一切。**

### 1.3 独特卖点（USP）

| USP | 描述 | 竞品差异 |
|-----|------|----------|
| **维度折叠叙事** | 二维世界下隐藏的"深度格"结构 | 非传统多线叙事 |
| **不可逆后果系统** | 每次能力使用都留下永久伤痕 | 非存档读档式体验 |
| **无收益行为价值** | 系统无法理解的"多余"行为推动终局 | 反游戏化设计 |
| **三层真相揭示** | 从人类视角到系统视角到观测尺度 | 认知升级而非剧情反转 |
| **竖版深度交互** | 专为移动端设计的深度感知UI | 非简单移植 |

### 1.4 核心循环

```
┌─────────────────────────────────────────────────────────┐
│                     核心游戏循环                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│    探索Zone → 发现异常 → 使用能力 → 承担后果 → 推进叙事   │
│        ↑                                      │         │
│        │         收集卡片/伏笔触发             │         │
│        └──────────────────────────────────────┘         │
│                                                         │
│    [深层循环] 无收益行为累积 → R值提升 → 系统显影        │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 1.5 目标用户画像

| 用户类型 | 特征 | 占比 |
|----------|------|------|
| **核心用户** | 叙事游戏爱好者（Her Story/Return of the Obra Dinn） | 40% |
| **次核心用户** | 独立游戏玩家（重体验轻操作） | 30% |
| **泛用户** | 视觉小说/AVG爱好者 | 20% |
| **边缘用户** | 哲学/科幻题材爱好者 | 10% |

## 2. 世界观摘要

> 完整版本：`design/世界观完整版 v3.md`

### 2.1 三层世界结构

| 层级 | 名称 | 玩家认知阶段 | 核心关键词 |
|------|------|--------------|------------|
| **L1** | 人类可理解层 | 序章-C2 | 使命、修复、灾害 |
| **L2** | 收敛运行时层 | C3-C5 | 对齐、结算、收敛 |
| **L3** | 高维观测尺度 | 终章 | 格式、字段、降阶 |

### 2.2 四大核心概念

| 概念 | 玩家理解 | 系统真相 |
|------|----------|----------|
| **主平面** | 二维世界 | 稳定表示/存档格式 |
| **深度格** | 被折叠的第三维 | 互斥结构的叠加态 |
| **因果账本** | 时间管理系统 | 全局自洽约束 |
| **收敛运行时** | 维护者系统 | 可读性保持机制 |

### 2.3 核心主题

> **从「自由 vs 控制」升级为「意义 vs 计算本身」**

终局不是揭露阴谋，而是：玩家的"无收益行为"在系统模型中创造了无法收敛的残差，迫使更高层模型降阶。

### 4.3 伏笔系统

> 完整版本：`design/伏笔索引 v2.md`

游戏包含 **20+ 伏笔**，每个伏笔遵循：

```
首次投放 → 加深 → 误读 → 回收
```

**关键伏笔**：

| 编号 | 名称 | 投放 | 回收 |
|------|------|------|------|
| F01 | 薄墙回声 | C0-Z3 | C2-Z2 |
| F06 | 身份卡日期更正 | C0-Z1 | CF |
| F11 | 字段空白闪现 | C2-Z2 | C5-CF |
| F21 | "此行为无意义" | C5-Z7 | CF |
| F23 | 非最优被保存 | C3-Z4 | CF-Z4 |

### 4.4 三结局

| 结局 | 触发条件 | 世界状态 | 岑回命运 |
|------|----------|----------|----------|
| **A：平面稳定** | R<6, 稳定选择 | 继续收敛，多余字段存在 | 成为稳定工具 |
| **B：真实释放** | 中等R, 平衡选择 | 表示松动，涌现回归 | 自由但记忆碎片化 |
| **C：成为系统** | R≥10, 无收益选择 | 模型降阶 | 成为字段承载者 |

## 5. 核心玩法

> 完整版本：`design/核心玩法系统设计.md`

### 5.1 三种能力

| 能力 | 解锁章节 | 操作方式 | 效果 | 代价 |
|------|----------|----------|------|------|
| **深度感知** | C2 | 长按屏幕 | 看见隐藏结构 | P轻微增加 |
| **深度介入** | C3 | 拖拽操作 | 改变结构 | 永久伤痕 + P增加 |
| **时间干预** | C4 | 时间卡片UI | 回溯节点 | 污染增加 + P大增 |

### 5.2 隐藏计数器

| 计数器 | 全称 | 增长方式 | 阈值效果 |
|--------|------|----------|----------|
| **R** | 无收益残差 | 无奖励行为 | ≥3：语气停顿 / ≥6：判定句 / ≥10：模型改写 |
| **P** | 观察者压力 | 使用高维能力 | 影响系统纠偏强度 |
| **W** | 世界可读性 | 综合稳定度 | 影响结局走向 |

### 5.3 互动类型

| 类型 | 操作 | 反馈 |
|------|------|------|
| **对话** | 点击NPC | 对话框 + 选项 |
| **检视** | 点击物品 | 描述 + 可能获得卡片 |
| **深度感知** | 长按 | 透视效果 + 隐藏信息 |
| **深度介入** | 拖拽 | 结构变化 + 伤痕动画 |
| **时间干预** | 卡片操作 | 回溯 + 污染效果 |
| **移动** | WASD/方向键 | 角色移动 + y轴深度排序 |
