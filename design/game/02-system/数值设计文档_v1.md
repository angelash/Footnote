## 📌 设计理念

### 核心原则

1. **不外显数值**：玩家不应看到具体数字，通过叙事和表现感知变化
2. **后果驱动**：数值变化必须带来明确的游戏体验变化
3. **无最优解**：不存在"刷数值"或"攒资源"的最优策略
4. **叙事一致**：数值逻辑与世界观设定保持一致

### 数值哲学

> 这不是一个关于"变强"的游戏，而是关于"选择与后果"的游戏。  
> 每个数值都是玩家行为在世界中留下的痕迹。

## 1. 核心计数器详细设计

### 1.1 R值（无收益残差 / Residual）

#### 设计意图

R值代表玩家进行"系统无法解释"的行为的累积。在世界观中，收敛运行时假设所有代理都趋向效率和奖励，当玩家持续做"无意义"的事，会产生模型无法收敛的残差。

#### 数值范围

```
R ∈ [0, 15]
初始值: 0
上限: 15（超过15视为15）
```

#### 增长规则

| 行为类型 | R值增量 | 触发条件 | 示例 |
|----------|---------|----------|------|
| **轻微无收益** | +1 | 选择无奖励选项 | C0-Z2 点没人点的菜 |
| **中等无收益** | +2 | 完成无奖励任务 | C2-Z4 扶正无人走的路标 |
| **强无收益** | +2~3 | 坚持被否定的行为 | C4-Z6 贴没人看的地图 |
| **关键无收益** | +3 | 终章关键选择 | CF-Z2 救不存在的人 |

#### 衰减规则

```
无衰减
设计理由：无收益行为的"残差"是永久的，这是世界观核心
```

#### 阈值效果详表

| R值区间 | 系统状态 | 表现细节 |
|---------|----------|----------|
| **0-2** | 完全正常 | 系统按预设运行 |
| **3-4** | 微妙停顿 | 系统提示偶尔延迟0.5s |
| **5** | 轻微异常 | NPC对话出现"......"停顿 |
| **6-7** | 判定前奏 | 结算卡出现"无可用收益"字样 |
| **8-9** | 明确判定 | F21"此行为无意义"弱版出现 |
| **10-12** | 模型困惑 | 系统语气出现"无法归类"表述 |
| **13-15** | 模型改写 | 终局C路线开启，F21完整版触发 |

#### R值机会点分布

| 章节 | R值机会 | 最大可获得 | 累计可达 |
|------|---------|------------|----------|
| C0 | 1处 | +1 | 1 |
| C1 | 2处 | +2 | 3 |
| C2 | 3处 | +4 | 7 |
| C3 | 3处 | +5 | 12 |
| C4 | 4处 | +6 | 18 → cap at 15 |
| C5 | 3处 | +5 | - |
| CF | 2处 | +5 | - |

**设计平衡**：
- 全收集R值远超阈值，确保玩家不需要"刷"
- C2-C3是R值主要积累期
- 终章选择可以大幅影响最终R值

### 1.2 P值（观察者压力 / Pressure）

#### 设计意图

P值代表玩家使用高维能力造成的"系统计算负担"。在世界观中，每次使用能力都迫使收敛运行时显式处理更多内容，增加观察者压力。

#### 数值范围

```
P ∈ [0.0, 20.0]
初始值: 0.0
上限: 20.0（软上限，超过后效果不再增强）
精度: 0.1
```

#### 增长规则

##### 深度感知

| 使用时长 | P值增量 | 说明 |
|----------|---------|------|
| < 3秒 | +0.0 | 短暂查看无代价 |
| 3-10秒 | +0.1 | 轻微压力 |
| 10-20秒 | +0.2 | 中等压力 |
| 20-30秒 | +0.3 | 明显压力 |
| > 30秒 | +0.5 | 持续观察高压力 |

##### 深度介入

| 介入规模 | P值增量 | 判定依据 |
|----------|---------|----------|
| 小型调整 | +0.5 | 单个对象微调 |
| 中型改变 | +1.0 | 单个对象大改/多对象微调 |
| 大型重构 | +2.0 | 区域性结构变化 |
| 关键介入 | +3.0 | 剧情关键结构变化 |

##### 时间干预

| 回溯距离 | P值增量 | 游戏时间参考 |
|----------|---------|--------------|
| < 5分钟 | +1.0 | 当前Zone内 |
| 5-15分钟 | +2.0 | 1-2个Zone |
| 15-30分钟 | +3.0 | 3-4个Zone |
| 30-60分钟 | +4.0 | 跨章节 |
| > 60分钟 | +5.0 | 大跨度回溯 |

#### 衰减规则

```
P值无主动衰减
但可通过特定叙事选择"释放压力"：
- 接受许澄的"稳定疗程"：P -= 2.0（但R值归零）
- 选择特定对话选项：P -= 0.5
```

#### 阈值效果详表

| P值区间 | 纠偏强度 | 表现细节 |
|---------|----------|----------|
| **0-3** | 无 | 系统正常运行 |
| **4-6** | 轻微 | NPC对话略显机械化（口癖增加） |
| **7-9** | 中度 | 环境出现"补丁痕迹"（重复纹理） |
| **10-12** | 强烈 | 系统提示语气变"对账"风格 |
| **13-15** | 严重 | 对话选项减少、NPC记忆漂移 |
| **16-20** | 极端 | 系统主动"纠正"玩家行为 |

### 1.3 W值（世界可读性 / World Readability）

#### 设计意图

W值是派生值，代表世界的整体稳定程度。它综合了R和P的影响，加上特定事件修正。

#### 计算公式

```
W = max(0, 100 - (R × 3) - (P × 2) - EventModifier)

其中:
- R × 3: 无收益残差的权重
- P × 2: 观察者压力的权重
- EventModifier: 累计事件修正值
```

#### 事件修正值

| 事件类型 | 修正值 | 触发条件 |
|----------|--------|----------|
| 大型深度介入 | -5 | 大型重构类介入 |
| 长距时间回溯 | -8 | > 30分钟回溯 |
| 结构性决策A | -3 | 选择"不稳定"选项 |
| 结构性决策B | -5 | 选择"释放"选项 |
| 关键伏笔触发 | -2 | F11/F21/F23触发 |

#### W值模拟示例

```
场景: 中度使用能力 + 部分无收益行为

R = 6（中等无收益）
P = 8.0（中度使用能力）
EventModifier = 10（2次大型介入）

W = 100 - (6 × 3) - (8 × 2) - 10
W = 100 - 18 - 16 - 10
W = 56

→ 处于"中度不稳"区间
```

#### 阈值效果详表

| W值区间 | 世界状态 | 视觉表现 | 叙事影响 |
|---------|----------|----------|----------|
| **80-100** | 稳定 | 正常画面 | 系统"满意" |
| **60-79** | 轻微不稳 | 偶尔画面微抖 | 系统"关注" |
| **40-59** | 中度不稳 | 色彩轻微偏移 | 系统"警告" |
| **20-39** | 严重不稳 | 明显视觉失真 | 系统"干预" |
| **0-19** | 临界状态 | 第三层格式覆盖 | 终局显影 |

## 2. 结局判定系统

### 2.1 结局分支逻辑

```
                    ┌─────────────┐
                    │  进入终章    │
                    └──────┬──────┘
                           │
              ┌────────────┼────────────┐
              │            │            │
              ▼            ▼            ▼
        ┌─────────┐  ┌─────────┐  ┌─────────┐
        │ R < 6   │  │ 6≤R<10  │  │ R ≥ 10  │
        │ W > 60  │  │ 40<W≤60 │  │ W ≤ 40  │
        └────┬────┘  └────┬────┘  └────┬────┘
             │            │            │
             ▼            ▼            ▼
        关键选择A     关键选择B     关键选择C
             │            │            │
             ▼            ▼            ▼
    ┌────────────┐ ┌────────────┐ ┌────────────┐
    │ 结局A:     │ │ 结局B:     │ │ 结局C:     │
    │ 平面稳定   │ │ 真实释放   │ │ 成为系统   │
    └────────────┘ └────────────┘ └────────────┘
```

### 2.2 结局详细条件

#### 结局A：平面稳定

| 条件 | 阈值 | 权重 |
|------|------|------|
| R值 | < 6 | 必须 |
| W值 | > 60 | 必须 |
| CF-Z2选择 | 选择"稳定"选项 | 必须 |
| 特定伏笔 | F21未完整触发 | 建议 |

#### 结局B：真实释放

| 条件 | 阈值 | 权重 |
|------|------|------|
| R值 | 6-9 | 必须 |
| W值 | 40-60 | 必须 |
| CF-Z2选择 | 选择"释放"选项 | 必须 |
| 特定伏笔 | F11已深化 | 建议 |

#### 结局C：成为系统

| 条件 | 阈值 | 权重 |
|------|------|------|
| R值 | ≥ 10 | 必须 |
| W值 | ≤ 40 | 必须 |
| CF-Z2选择 | 选择"承载"选项 | 必须 |
| 特定伏笔 | F21完整触发 | 必须 |
| 栖蓝支线 | 高亲密度 | 建议 |

### 2.3 边界情况处理

| 情况 | 处理方式 |
|------|----------|
| R=6, W=60 | 偏向结局B，根据关键选择最终确定 |
| 条件交叉 | 优先R值 > 关键选择 > W值 |
| 未满足任何条件 | 默认结局A（最"安全"的结局） |

## 5. 难度调节设计

### 5.1 难度影响因素

| 因素 | 影响范围 | 调节方式 |
|------|----------|----------|
| **P值** | 系统纠偏强度 | 高P = 更强纠偏 = 更难 |
| **能力限制** | 介入/回溯次数 | 可调整单Zone限制 |
| **提示系统** | 目标指引 | 可开关提示 |
| **自动存档** | 容错空间 | 更频繁存档 = 更易 |

### 5.2 隐性难度等级

本游戏不设明确难度选项，但通过玩家行为自然形成难度分层：

| 玩法风格 | 等级 | 特点 |
|----------|------|------|
| **收敛派** | 简单 | 少用能力，按流程走，系统友好 |
| **探索派** | 中等 | 适度使用能力，平衡探索与效率 |
| **多余派** | 困难 | 大量无收益行为，高P值，系统敌对 |

### 5.3 辅助功能

| 功能 | 默认 | 说明 |
|------|------|------|
| 目标提示 | 开 | 显示下一步建议 |
| 交互高亮 | 开 | 高亮可交互对象 |
| 对话回看 | 开 | 可查看历史对话 |
| 跳过动画 | 关 | 二周目可开启 |
| 自动存档 | 开 | Zone切换时自动存档 |
