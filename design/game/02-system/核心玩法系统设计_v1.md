## 1. 核心游戏循环

### 1.1 主循环定义

```
┌────────────────────────────────────────────────────────────────────────┐
│                         核心游戏循环                                    │
├────────────────────────────────────────────────────────────────────────┤
│                                                                        │
│    ┌──────────┐                                                        │
│    │ 进入Zone │                                                        │
│    └────┬─────┘                                                        │
│         │                                                              │
│         ▼                                                              │
│    ┌──────────┐     ┌──────────┐     ┌──────────┐     ┌──────────┐   │
│    │  探索    │────→│ 发现异常 │────→│ 决策使用 │────→│ 承担后果 │   │
│    │  环境    │     │  /线索   │     │   能力   │     │  /奖励   │   │
│    └──────────┘     └──────────┘     └──────────┘     └────┬─────┘   │
│         ▲                                                   │          │
│         │                   反馈                            │          │
│         └───────────────────────────────────────────────────┘          │
│                                                                        │
│    [元循环] 累积行为 → 计数器变化 → 系统反馈变化 → 结局走向             │
│                                                                        │
└────────────────────────────────────────────────────────────────────────┘
```

### 1.2 单次游玩节奏

| 阶段 | 时长 | 玩家行为 | 情绪曲线 |
|------|------|----------|----------|
| **进入Zone** | 10-20s | 观察环境、读取背景 | 期待 |
| **探索阶段** | 2-4min | 移动、对话、检视 | 好奇 |
| **发现阶段** | 1-2min | 发现异常/线索 | 紧张 |
| **决策阶段** | 30s-2min | 使用能力/选择 | 犹豫 |
| **后果阶段** | 30s-1min | 观察变化、收集反馈 | 满足/后悔 |
| **转场** | 10-20s | Zone切换 | 期待下一步 |

**单Zone总时长**：5-10分钟（H5碎片化友好）

### 1.3 章节节奏

| 章节 | Zone数 | 能力 | 情绪基调 | 叙事密度 |
|------|--------|------|----------|----------|
| **C0** | 4 | 无 | 平静→微妙不安 | 低 |
| **C1** | 6 | 无 | 困惑→好奇 | 中 |
| **C2** | 7 | 深度感知 | 震撼→理解 | 高 |
| **C3** | 7 | 深度介入 | 冲动→后悔 | 高 |
| **C4** | 8 | 时间干预 | 希望→失落 | 很高 |
| **C5** | 7 | 全部 | 困惑→觉醒 | 很高 |

## 2. 移动与交互系统

### 2.1 移动系统

#### 基础移动

| 属性 | 数值 | 说明 |
|------|------|------|
| 移动方式 | WASD/方向键 | 八方向移动 |
| 移动速度 | 150px/s | 基础速度 |
| 斜向修正 | ÷√2 | 保持速度一致 |
| 碰撞检测 | 矩形碰撞体 | 32×32px |

#### 深度排序（Y-Sort）

```typescript
// 每帧更新
player.setDepth(player.y);
objects.forEach(obj => {
  if (!obj.hasExplicitDepth) {
    obj.setDepth(obj.y);
  }
});
```

| 规则 | 说明 |
|------|------|
| 默认深度 | `depth = y` |
| 显式深度 | YAML配置覆盖默认值 |
| 前景层 | `depth = 9999` |
| 背景层 | `depth = -1` |

### 2.2 交互系统

#### 交互类型

| 类型 | 触发方式 | 视觉反馈 | 行为 |
|------|----------|----------|------|
| **NPC对话** | 点击NPC | 高亮光圈 | 打开对话框 |
| **物品检视** | 点击物品 | 高亮边框 | 显示描述/获得卡片 |
| **门/传送点** | 点击/靠近 | 发光效果 | Zone切换 |
| **隐藏触发点** | 深度感知后可见 | 透视效果 | 触发事件 |

#### 交互优先级

```
1. 对话进行中 → 阻止所有其他交互
2. UI面板打开 → 阻止游戏内交互
3. 能力使用中 → 阻止移动和普通交互
4. 普通状态 → 按距离选择最近可交互对象
```

#### 交互距离

| 类型 | 距离阈值 | 说明 |
|------|----------|------|
| NPC对话 | 80px | 靠近后可点击 |
| 物品检视 | 60px | 需要更近 |
| 自动触发 | 40px | 进入即触发 |

### 2.3 交互反馈设计

| 状态 | 视觉反馈 | 音效 |
|------|----------|------|
| 可交互（远） | 淡色图标 | 无 |
| 可交互（近） | 高亮 + 提示文字 | sfx_interact_hint |
| 交互中 | 选中动画 | sfx_interact |
| 交互完成 | 完成动画 | sfx_complete |

## 3. 能力系统

### 3.1 能力总览

| 能力 | 解锁 | 操作 | 核心体验 | 代价 |
|------|------|------|----------|------|
| **深度感知** | C2-Z1 | 长按屏幕 | "看见而不能改变" | P轻微增加 |
| **深度介入** | C3-Z1 | 拖拽操作 | "改变留下伤痕" | 永久伤痕 + P增加 |
| **时间干预** | C4-Z2 | 卡片UI | "回溯洗不净" | 污染 + P大增 |

### 3.2 深度感知（Depth Perception）

#### 基础机制

```
触发条件: 长按屏幕 > 0.5秒
持续条件: 保持长按
退出条件: 松开手指 / 受到干扰事件
```

#### 视觉效果

| 阶段 | 时间 | 效果 |
|------|------|------|
| 蓄力 | 0-0.5s | 画面边缘微微变暗 |
| 激活 | 0.5s | 透视效果渐入 + 音效 |
| 持续 | 0.5s+ | 线框叠加 + 隐藏信息显现 |
| 退出 | 松开 | 效果渐出 (0.3s) |

#### 能看到的内容

| 类型 | 描述 | 示例 |
|------|------|------|
| 结构真相 | 墙内空腔、折叠空间 | F01薄墙回声 |
| 隐藏物品 | 被覆盖的物体 | 旧地图、密室入口 |
| NPC状态 | 内心状态可视化 | 阿棠的"漂移程度" |
| 系统痕迹 | 纠偏/修补痕迹 | 更正版本号 |

#### P值影响

| 使用时长 | P值增加 |
|----------|---------|
| < 5秒 | +0 |
| 5-15秒 | +0.1 |
| 15-30秒 | +0.2 |
| > 30秒 | +0.3 |

### 3.3 深度介入（Depth Intervention）

#### 基础机制

```
前置条件: 已解锁深度介入 + 可介入目标存在
触发条件: 选中目标 → 拖拽操作
执行条件: 完成拖拽手势
后果: 结构永久改变 + 伤痕动画
```

#### 可介入目标

| 目标类型 | 介入效果 | 伤痕表现 |
|----------|----------|----------|
| 折叠空间 | 展开/压缩 | 裂缝纹理 |
| 隐藏通道 | 打开/关闭 | 边缘毛刺 |
| 结构异常 | 稳定/释放 | 扭曲感 |
| NPC状态 | 微调对齐程度 | 记忆碎片化 |

#### 操作流程

```
1. 深度感知中发现可介入目标（发光标记）
2. 点击选中目标
3. 出现介入UI（方向提示）
4. 拖拽到目标位置
5. 释放 → 触发介入
6. 播放伤痕动画 + 音效
7. 世界状态更新
```

#### P值和伤痕影响

| 介入类型 | P值增加 | 伤痕等级 |
|----------|---------|----------|
| 小型调整 | +0.5 | 轻微（1周内可回溯修复） |
| 中型改变 | +1.0 | 中等（永久可见但不影响功能） |
| 大型重构 | +2.0 | 严重（永久影响区域状态） |

### 3.4 时间干预（Time Intervention）

#### 基础机制

```
前置条件: 已解锁时间干预 + 存在可回溯节点
界面: 时间卡片UI（竖版适配）
操作: 选择节点 → 确认回溯
后果: 状态回滚 + 污染增加 + 伤痕保留
```

## 4. 隐藏计数器系统

### 4.1 R值（无收益残差）

#### 定义
**R (Residual)**: 玩家进行"无收益行为"的累积值。系统模型无法解释这些行为，产生残差。

#### 增长方式

| 行为类型 | R值增加 | 示例 |
|----------|---------|------|
| 无奖励选择 | +1 | 点"没人点的菜" |
| 帮助无关NPC | +1~2 | 扶正无人走的路标 |
| 保留无意义物品 | +1 | 为不在的人保留椅子 |
| 选择低效路线 | +1 | 绕路陪伴NPC |
| 坚持被否定行为 | +2 | 反复做被系统"无效"的事 |

#### 阈值效果

| R值 | 系统表现 | 叙事效果 |
|-----|----------|----------|
| 0-2 | 正常 | 无 |
| 3-5 | 语气停顿 | 系统提示偶尔出现微小延迟 |
| 6-9 | 判定句出现 | "此行为无可用收益" 开始出现 |
| 10+ | 模型改写 | 终局C路线开启、F21完整触发 |

### 4.2 P值（观察者压力）

#### 定义
**P (Pressure)**: 玩家使用高维能力造成的"观察者压力"。压力越大，系统纠偏越强。

#### 增长方式

| 行为 | P值增加 |
|------|---------|
| 深度感知（短时） | +0~0.1 |
| 深度感知（长时） | +0.1~0.3 |
| 深度介入（小型） | +0.5 |
| 深度介入（大型） | +1.0~2.0 |
| 时间干预（短距） | +1.0 |
| 时间干预（长距） | +3.0~5.0 |

#### 阈值效果

| P值 | 系统表现 | 游戏影响 |
|-----|----------|----------|
| 0-3 | 正常 | 无 |
| 4-6 | 轻微纠偏 | NPC对话略显机械 |
| 7-10 | 中度纠偏 | 环境出现补丁痕迹、选项减少 |
| 11-15 | 强烈纠偏 | 系统语气变"对账"风格 |
| 16+ | 极端压力 | 可能触发系统主动"修复"玩家行为 |

### 4.3 W值（世界可读性）

#### 定义
**W (World Readability)**: 世界的综合稳定度。由R和P的组合影响计算得出。

#### 计算公式

```
W = max(0, 100 - (R × 3 + P × 2) - 异常事件修正)

异常事件修正:
- 每次大型介入: -5
- 每次长距回溯: -8
- 结构性决策: -3~-10
```

#### 阈值效果

| W值 | 世界状态 | 视觉表现 |
|-----|----------|----------|
| 80-100 | 稳定 | 正常画面 |
| 60-79 | 轻微不稳 | 偶尔画面抖动 |
| 40-59 | 中度不稳 | 色彩偏移、UI元素异常 |
| 20-39 | 严重不稳 | 明显失真、系统提示频繁 |
| 0-19 | 临界状态 | 终局第三层显影 |

### 4.4 结局走向影响

| R值 | W值 | 主导结局 |
|-----|-----|----------|
| < 6 | > 60 | A：平面稳定 |
| 6-9 | 40-60 | B：真实释放 |
| ≥ 10 | < 40 | C：成为系统 |

**注意**：结局不完全由计数器决定，还需要特定关键选择。

## 5. 叙事系统

### 5.1 对话系统

#### 对话结构

```yaml
dialogue:
  id: GULIN_C1_01
  speaker: 顾临
  portrait: char_gulin_portrait_neutral
  lines:
    - text: "记录就好。"
      auto: false
    - text: "别把主观当事实。"
      auto: true
      delay: 800
  options:
    - text: "但我确实看到了..."
      next: GULIN_C1_01_A
      flag: questioned_gulin
    - text: "明白了。"
      next: null
```

#### 对话触发条件

| 条件类型 | 示例 |
|----------|------|
| 位置触发 | 进入特定区域 |
| 交互触发 | 点击NPC |
| 状态触发 | R/P/W达到阈值 |
| 伏笔触发 | 特定伏笔激活 |
| 时间触发 | 游戏内时间 |

#### 对话分支设计

```
         ┌─── 选项A ──→ 分支A ──→ 收敛点
主对话 ──┤
         └─── 选项B ──→ 分支B ──→ 收敛点
                             ↓
                        下一段对话
```

**设计原则**：
- 分支影响**体验和细节**，不影响主线推进
- 重要分支影响**计数器**和**伏笔状态**
- 避免死胡同，所有分支最终收敛

### 5.3 伏笔追踪系统

#### 伏笔状态机

```
┌──────────┐    触发条件    ┌──────────┐
│  未投放   │ ────────────→ │  已投放   │
└──────────┘               └────┬─────┘
                                │ 加深条件
                                ▼
┌──────────┐    回收条件    ┌──────────┐
│  已回收   │ ←──────────── │  已加深   │
└──────────┘               └──────────┘
```

#### 伏笔数据结构

```typescript
interface IForeshadow {
  id: string;           // F01-F26
  name: string;         // 伏笔名称
  state: 'hidden' | 'planted' | 'deepened' | 'recalled';
  plantedAt?: string;   // 投放Zone
  deepenedAt?: string[];// 加深Zone列表
  recalledAt?: string;  // 回收Zone
  relatedCards?: string[];// 关联卡片
```

### 5.4 Zone管理系统

#### Zone状态

| 状态 | 说明 | 视觉表现 |
|------|------|----------|
| locked | 未解锁 | 地图上显示灰色/锁图标 |
| unlocked | 已解锁未进入 | 地图上显示可进入 |
| visited | 已访问 | 地图上显示已探索标记 |
| completed | 已完成主要内容 | 地图上显示完成标记 |
| changed | 状态已改变（重返变体） | 特殊标记 |

#### Zone切换流程

```
1. 触发切换（点击传送点/地图选择）
2. 检查前置条件
3. 保存当前状态到时间节点
4. 播放转场动画
5. 加载目标Zone配置
6. 初始化Zone对象
7. 触发进入事件
8. 恢复玩家控制
```

## 8. 性能考量

### 8.1 资源管理

| 策略 | 说明 |
|------|------|
| **Zone级加载** | 只加载当前Zone + 相邻Zone资源 |
| **对象池** | 复用频繁创建/销毁的对象 |
| **懒加载对话** | 对话数据按需加载 |
| **图片压缩** | SVG优先，PNG使用WebP |

### 8.2 内存预算

| 类别 | 预算 |
|------|------|
| 当前Zone资源 | 30MB |
| 预加载资源 | 20MB |
| 音频缓冲 | 20MB |
| 游戏逻辑 | 10MB |
| UI系统 | 10MB |
| 预留 | 10MB |
| **总计** | **100MB** |

### 8.3 帧率优化

| 场景 | 目标帧率 | 策略 |
|------|----------|------|
| 普通游玩 | 60fps | 标准渲染 |
| 深度感知 | 30fps | 降低特效复杂度 |
| 对话中 | 30fps | 减少更新频率 |
| 菜单/暂停 | 15fps | 最小化更新 |
