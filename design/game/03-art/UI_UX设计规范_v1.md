## 📌 设计原则

### 核心理念

1. **沉浸优先**：UI应该是故事的一部分，而非覆盖层
2. **克制表达**：少即是多，信息密度要低
3. **叙事一致**：UI风格与世界观保持统一（收敛运行时的"系统感"）
4. **移动原生**：为竖屏单手操作优化

### 设计关键词

```
极简 · 克制 · 系统感 · 深色主调 · 荧光强调 · 信息分层
```

## 7. 动效规范

### 7.1 动效原则

1. **目的性**：动效服务于信息传达，不是装饰
2. **一致性**：相同类型操作使用相同动效
3. **性能优先**：优先使用CSS动画，避免复杂计算

### 7.2 缓动函数

| 类型 | 函数 | 用途 |
|------|------|------|
| **标准** | `ease-out` | 大部分UI动效 |
| **弹性** | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 按钮点击 |
| **平滑** | `ease-in-out` | 页面切换 |
| **系统感** | `steps(10)` | 系统状态变化 |

### 7.3 时长规范

| 类型 | 时长 | 用途 |
|------|------|------|
| **即时** | 100ms | 悬停反馈 |
| **快速** | 200ms | 按钮点击 |
| **标准** | 300ms | 面板展开 |
| **中等** | 500ms | 页面切换 |
| **缓慢** | 800ms | 深度感知激活 |

### 7.4 关键动效

#### 深度感知激活

```
0ms    → 画面边缘开始变暗
200ms  → 透视网格开始渐入
500ms  → 完全激活，隐藏内容显现
```

#### 对话框进入

```
0ms    → 从底部滑入
200ms  → 到达目标位置
300ms  → 内容开始打字机效果
```

#### Zone切换

```
0ms    → 画面开始淡出
300ms  → 完全黑屏
500ms  → 新场景淡入
800ms  → 完全显示
```
