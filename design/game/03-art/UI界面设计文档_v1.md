## 1. 标题界面 (UI-001)

### 1.1 布局结构

```
┌─────────────────────────────────────┐  750×1334
│                                     │
│             [60px 顶部留白]          │
│                                     │
│         ╔═══════════════╗           │
│         ║               ║           │
│         ║   G A M E     ║  ← Logo   │
│         ║    L O G O    ║    400×200
│         ║               ║           │
│         ╚═══════════════╝           │
│                                     │
│              备  注                  │  ← 中文标题 48px
│            Footnote                 │  ← 英文副标题 24px
│                                     │
│           ─────────────             │  ← 分隔线动画
│                                     │
│                                     │
│         ┌───────────────┐           │
│         │   开始游戏    │           │  ← 主按钮 280×64
│         └───────────────┘           │
│                                     │
│         ┌───────────────┐           │
│         │   继续游戏    │           │  ← 次按钮（有存档时显示）
│         └───────────────┘           │
│                                     │
│                                     │
│      [设置]           [制作组]       │  ← 底部图标 48×48
│                                     │
│          v1.0.0 © 2025             │  ← 版本号 16px
│             [40px 底部留白]          │
└─────────────────────────────────────┘
```

### 1.2 元素规格

| 元素 | 尺寸 | 位置(x,y) | 样式 |
|------|------|-----------|------|
| Logo | 400×200 | 居中, y=180 | SVG动画，呼吸效果 |
| 中文标题 | 自适应 | 居中, y=420 | 思源黑体 Bold 48px #FFFFFF |
| 英文副标题 | 自适应 | 居中, y=480 | Source Code Pro 24px #6B7A8F |
| 分隔线 | 200×2 | 居中, y=530 | #00F5D4 渐变，左右流动动画 |
| 开始按钮 | 280×64 | 居中, y=620 | 主按钮样式 |
| 继续按钮 | 280×64 | 居中, y=700 | 次按钮样式 |
| 设置图标 | 48×48 | x=120, y=1200 | 图标按钮样式 |
| 制作组图标 | 48×48 | x=582, y=1200 | 图标按钮样式 |
| 版本号 | 自适应 | 居中, y=1280 | 16px #6B7A8F |

### 1.3 交互状态

| 状态 | 效果 |
|------|------|
| 进入页面 | Logo淡入(0.8s) → 标题滑入(0.3s) → 按钮依次淡入(0.2s间隔) |
| 按钮悬停 | 边框发光，文字变亮 |
| 按钮按下 | 缩小0.95，颜色加深 |
| 无存档 | "继续游戏"按钮隐藏或置灰 |

### 1.4 背景设计

```
层级:
1. 底层: #0A0E17 纯色
2. 中层: 深度网格线（极淡，alpha 0.05）
3. 顶层: 缓慢漂浮的粒子（5-8个，alpha 0.1-0.3）

动效:
- 粒子缓慢漂移，周期10-20秒
- 偶尔有"系统更正"闪烁效果（alpha 0.02-0.05）
```
