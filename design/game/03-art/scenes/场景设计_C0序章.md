# 《备注》场景设计 - C0 序章

> **章节主题**："一切都正常"  
> **目标时长**：0.5小时  
> **Zone数量**：4个  
> **区域**：居住环  
> **解锁能力**：无

---

## 📌 章节氛围总述

### 视觉基调
```
主色调: 暖灰 + 微黄灯光
氛围词: 日常、安静、略显单调
光源: 室内灯光为主，偏暖
特征: 整洁但缺乏个性，隐藏不安
```

### 叙事目标
- 让玩家先把它当成普通2D叙事冒险
- 埋下"现实不可靠"的浅伏笔
- 教会基础操作：移动、交互、长按查看
