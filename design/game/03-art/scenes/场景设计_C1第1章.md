# 《备注》场景设计 - C1 第1章

> **章节主题**："这个地图哪里不对"  
> **目标时长**：1.5小时  
> **Zone数量**：6个  
> **区域**：市政环 + 档案巷  
> **解锁能力**：无（为C2准备）

---

## 📌 章节氛围总述

### 视觉基调
```
主色调: 冷蓝+金属灰 (市政) / 褐色+米黄 (档案)
氛围词: 秩序、流程、旧纸、密集
光源: 日光灯(市政) / 台灯+窗光(档案)
特征: 开始出现"版本差异"视觉暗示
```

### 叙事目标
- 让玩家第一次看见"地图不一致"
- 建立宋岚作为"差异守护者"的形象
- 为第2章的"深度感知"做铺垫
