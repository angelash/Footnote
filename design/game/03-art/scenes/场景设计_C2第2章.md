# 《备注》场景设计 - C2 第2章

> **章节主题**："看见不该看的"  
> **目标时长**：2小时  
> **Zone数量**：7个  
> **区域**：市政环 + 档案巷 + 诊疗台  
> **解锁能力**：深度感知（只读）

---

## 📌 章节氛围总述

### 视觉基调
```
主色调: 冷蓝(市政) + 白绿(诊疗) + 深度波纹叠加
氛围词: 揭示、压力、授权、边界
光源: 日光灯 + 深度视野特效
特征: 首次出现"深度视野"视觉层
```

### 新增视觉元素
```
深度视野激活时:
- 全屏覆盖淡青色滤镜
- 边缘出现网格线(深度格)
- 异常点显示斜线纹/闪烁
- 按住时持续，松开恢复
```

### 深度视野教学设计

#### 三台位对比
```
普通视野:
┌───────┐ ┌───────┐ ┌───────┐
│ ▣ ▣  │ │ ▣ ▣  │ │ ▣ ▣  │  ← 都看起来正常
│       │ │       │ │       │
│正常   │ │正常   │ │正常   │
└───────┘ └───────┘ └───────┘

深度视野(长按):
┌───────┐ ┌───────┐ ┌───────┐
│ ▣═▣  │ │ ○ ○  │ │ / /  │  ← 显示真实结构
│ ║ ║  │ │(空腔) │ │(断裂) │
│完整   │ │扭曲   │ │缺口   │
└───────┘ └───────┘ └───────┘
  台位A     台位B     台位C
```

### 顾临授权对话
```
顾临: "从今天开始，你会看到一些...不该被讨论的东西。"
顾临: "看见就记录。别动。"

【玩家选项】
① "为什么是我？"
② "看见之后呢？"
③ "我准备好了。"

顾临: "城市不需要你证明自己，只需要你别让事情更复杂。"
```

### 交互流程
```
1. 顾临对话 → 解释深度感知
2. 系统弹出教学浮层
3. 玩家依次到A/B/C台位
4. 长按进入深度视野 → 看到不同结构
5. 点击异常点 → 生成标注
6. 全部标注后 → 授权终端解锁
7. 领取授权 → 获得卡片
```
