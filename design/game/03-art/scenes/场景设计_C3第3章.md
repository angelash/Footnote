# 《备注》场景设计 - C3 第3章

> **章节主题**："能不介入就别介入"  
> **目标时长**：2.5小时  
> **Zone数量**：7个  
> **区域**：市政环 + 边缘断口 + 礼堂街  
> **解锁能力**：深度介入（写入）

---

## 📌 章节氛围总述

### 视觉基调
```
主色调: 冷蓝(市政) + 紫金(礼堂) + 伤痕红
氛围词: 伦理、抉择、代价、介入
光源: 日光灯 + 深度波纹 + 伤痕光晕
特征: 首次出现"结构伤痕"永久标记
```

### 新增视觉元素
```
深度介入时:
- 【介入】按钮出现在异常点
- 确认浮层："将留下永久伤痕"
- 伤痕效果: 红色裂纹，永久保留
- 屏幕顶部"裂纹图标"变化
```

### 结构负担UI
```
┌───────────────────────────────────┐
│  屏幕顶部右侧:                    │
│                                   │
│  初始:    ○ (完整)               │
│  介入1次: ◔ (细裂)               │
│  介入2次: ◑ (更多裂纹)            │
│  介入多次: ◕ (严重裂纹)           │
│                                   │
│  不标数字，只变化形态             │
└───────────────────────────────────┘
```

### 多解法设计

#### 解法A：流程绕行（2D）
```
路径:
1. 打开维护通道盖板
2. 走窄通道（较长动画）
3. 从"记录里存在的入口"进入

代价:
- 时间更长（体验累）
- 盖板被撬开（后续NPC注意到）
- 系统可记录（可归档）

结算卡:
"救援已登记。"
"现场：表层破损（盖板）"
```

#### 解法B：深度介入（写入）
```
路径:
1. 深度视野看到门影轮廓
2. 点击【介入】按钮
3. 确认浮层 → 按住1秒
4. 直接进入

代价:
- 结构伤痕（永久）
- 观察者压力 P+3
- "无法完整归档"

结算卡:
"救援：无法归档。"
"现场：结构伤痕（深度写入）"
"字段：——"  ← 空字段闪现
```
