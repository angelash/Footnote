### 时间干预教学流程
```
1. 顾临对话：给"最后权限"但强调代价

2. 系统弹教学浮层:
   "点击右侧【时间堆栈】查看节点。"
   "回溯将增加解释成本。"
   "深度伤痕不会抹去。"

3. 演示事件:
   - 点击桌面 → 螺丝滚落桌下
   
4. 玩家打开时间堆栈:
   - 看到节点卡"刚才·螺丝未掉落"
   - 按住确认回溯

5. 回溯后:
   - 螺丝回到桌面
   - 桌角留下极淡"擦痕"（补丁痕迹）
```

### 顾临对话
```
顾临: "你会想用它纠正错误。"
顾临: "别。"
顾临: "你能做的，只是把错误搬到别处。"

【玩家选项】
① "那给我它有什么意义？"
② "如果我救得了人呢？"
③ "我只会在必要时用。"

【顾临回应】
对①: "意义不是系统给的。" ← 方案三伏笔
对②: "救援优先，但账会变厚。"
对③: "希望你说到做到。"
```
