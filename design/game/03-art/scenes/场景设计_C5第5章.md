# 《备注》场景设计 - C5 第5章

> **章节主题**："版本互斥，无法合并"  
> **目标时长**：2.5小时  
> **Zone数量**：7个  
> **区域**：档案巷 + 市政环 + 边缘断口  
> **核心事件**：F21"此行为在当前模型中无意义"首次明确出现

---

## 📌 章节氛围总述

### 视觉基调
```
主色调: 冲突蓝紫 + 格式化灰
氛围词: 互斥、冲突、格式恐惧、判词
光源: 不稳定光源 + 字段闪烁
特征: 结算卡格式开始变化
```

### 结算卡格式变化
```
本章开始，结算卡从自然语言变为半表格字段:

之前的结算卡:
┌─────────────────────┐
│ "救援已完成。"      │
└─────────────────────┘

本章的结算卡:
┌─────────────────────┐
│ 条目：版本冲突       │
│ 状态：待结算         │
│ 字段：＿            │ ← 缺字
│ 备注：解释成本↑      │
└─────────────────────┘
```
