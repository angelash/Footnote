## 1. 概述

### 1.1 重返变体定义

**重返变体（Revisit Variant）** 是玩家在获得新能力后重新访问已完成Zone时出现的变化版本。

核心体验：
- **同一场景，不同视角** - 用新能力揭示隐藏层
- **伤痕保留** - 深度介入的伤痕不随回溯消失
- **时间线污染** - 时间干预留下的"补丁痕迹"
- **NPC记忆漂移** - 对话内容随世界状态变化

### 1.2 数量与时长

| 指标 | 数值 |
|------|------|
| 总数量 | 12个 |
| 预计总时长 | 3-4小时 |
| 单个平均时长 | 15-20分钟 |
| 内容分级 | B级（标准体验） |

### 1.3 设计原则

```
1. 重返是可选的
   - 主线不依赖重返内容
   - 但重返能补全伏笔和深化理解

2. 重返有代价
   - 深度介入留下永久伤痕
   - 时间干预增加污染值
   - 过度重返影响W值

3. 重返有奖励
   - 隐藏卡片/档案收集
   - 伏笔理解加深
   - R值累积机会

4. 重返影响结局
   - 某些选择影响结局条件
   - 重返次数计入最终统计
```

## 2. 触发机制总览

### 2.1 全局触发条件

| 条件类型 | 描述 | 检测方式 |
|----------|------|----------|
| **能力解锁** | 获得深度感知/介入/时间干预 | `worldState.abilities[]` |
| **原Zone完成** | 已通过原版Zone | `worldState.zones[].completed` |
| **主动返回** | 玩家选择重访 | 地图界面点击 |
| **计数器阈值** | R/P/W达到特定值 | `worldState.counters` |

### 2.2 变体层级

| 层级 | 能力要求 | 核心特征 | P值消耗 |
|------|----------|----------|---------|
| **V1** | 深度感知 | 只看不动，揭示隐藏信息 | +0.5/次 |
| **V2** | 深度介入 | 可改变结构，留下伤痕 | +1.0/次 |
| **V3** | 时间干预 | 可回溯，产生污染 | +2.0-5.0/次 |

### 2.3 解锁条件矩阵

| 变体ID | 原Zone | V1解锁 | V2解锁 | V3解锁 | 特殊条件 |
|--------|--------|--------|--------|--------|----------|
| RV-01 | C0-Z1 | C2后 | C3后 | - | - |
| RV-02 | C0-Z2 | C2后 | C3后 | - | - |
| RV-03 | C0-Z3 | C2后 | - | C4后 | - |
| RV-04 | C1-Z1 | C2后 | C3后 | - | - |
| RV-05 | C1-Z3 | C2后 | C3后 | - | - |
| RV-06 | C2-Z2 | 自动 | C3后 | C4后 | - |
| RV-07 | C2-Z7 | - | C3后 | C4后 | 需完成C3-Z2 |
| RV-08 | C3-Z1 | - | - | 自动 | - |
| RV-09 | C3-Z4 | 自动 | - | - | R≥3 揭示更多 |
| RV-10 | C4-Z1 | - | 自动 | - | - |
| RV-11 | C4-Z3 | 自动 | 自动 | 自动 | - |
| RV-12 | C5-Z5 | - | - | 自动 | 需见过陈匠 |

### RV-01 | 宿舍走廊重返

#### 基本信息

| 属性 | 值 |
|------|-----|
| **原Zone** | C0-Z1 宿舍走廊 |
| **变体类型** | 深度感知 + 深度介入 |
| **位置** | 居住环 |
| **预计时长** | 15分钟 |
| **关联伏笔** | F04（阿棠的漂移原因） |

#### 触发条件

```yaml
trigger:
  required:
    - ability: depth_perception  # 或 depth_intervention
    - zone_completed: C0-Z1
  optional:
    - R >= 2  # 解锁额外对话
```

#### 与原Zone差异对比

| 元素 | 原版 | 深度感知版 | 深度介入版 |
|------|------|------------|------------|
| **主色调** | 暖黄 | 暖黄+蓝紫叠加 | 暖黄+结构线 |
| **公告板** | 普通公告 | +隐藏涂鸦显现 | +可撕下纸条 |
| **地面** | 普通地砖 | +脚印痕迹可见 | +地砖可移动 |
| **交互** | 基础 | 查看隐藏 | 改变环境 |

#### 隐藏内容

**深度感知可见：**
```
隐藏涂鸦（公告板背面）:
"我们曾在这里"
"——在成为不存在之前"

脚印痕迹（地面）:
- 指向一个消失的房间入口
- 该入口在普通视野中是墙面
- 长按可显示："这里曾经有门"
```

**深度介入可触发：**
```
可移动地砖（地面）:
- 移动后露出旧钥匙
- 获得卡片：《失主未知的钥匙》
- 留下永久伤痕：地砖裂缝

可撕纸条（公告板）:
- 撕下后发现背面文字
- 内容暗示阿棠的前身
- 伤痕：纸条撕裂痕迹永久保留
```

#### 伤痕/污染视觉表现

| 行为 | 伤痕类型 | 视觉效果 | 持久性 |
|------|----------|----------|--------|
| 移动地砖 | 结构伤痕 | 裂缝纹理叠加 | 永久 |
| 撕下纸条 | 物品伤痕 | 撕裂边缘残留 | 永久 |
| 多次感知 | 压力痕迹 | 蓝紫色残影 | 本次访问 |

#### 特殊事件

| 事件ID | 触发条件 | 内容 | R/P影响 |
|--------|----------|------|---------|
| RV01-E1 | 发现隐藏涂鸦 | 岑回独白："这是谁写的？" | R+1（无奖励记录） |
| RV01-E2 | 获得钥匙 | 系统提示："无法确定归属" | - |
| RV01-E3 | R≥3时 | 涂鸦显示更多内容 | - |

#### 收集品

| 物品 | 获取方式 | 类型 | 备注 |
|------|----------|------|------|
| 《失主未知的钥匙》 | 深度介入移动地砖 | 物品卡 | 终章可用 |
| 《消失的门牌》 | 深度感知+照相 | 档案卡 | 补全F04 |

```yaml
    - ability: depth_perception

```

#### 与原Zone差异对比

| 元素 | 原版 | 深度感知版 | 深度介入版 |
|------|------|------------|------------|
| **招牌** | "早餐小店" | +旧招牌叠影 | +可还原旧招牌 |

| **氛围** | 日常 | 时间叠影感 | 可改变历史 |

#### 隐藏内容

**深度感知可见：**
```
旧招牌叠影:
"张记老面馆"
- 店主换了三次，但墙记得第一任
- 长按显示："这个名字...为什么眼熟？"

旧照片轮廓（柜台）:
- 照片中有两个人
- 一个是年轻的店主
- 另一个面容被涂抹
- 暗示：被"优化"掉的人

消失的菜品（菜单）:
- "老张特制面" - 已标记为"不存在"
- 点击显示："该菜品已从记录中移除"
```

**深度介入可触发：**
```
还原旧招牌:
- 消耗P值，将招牌暂时恢复
- 店主会说："...等等，这名字..."
- 伤痕：招牌出现双重叠影

恢复旧菜单:
- 将"老张特制面"加回菜单
- 可以点餐（无收益行为）
- 系统提示："此订单无法结算"
- R+2
```

#### 伤痕/污染视觉表现

| 行为 | 伤痕类型 | 视觉效果 | 持久性 |
|------|----------|----------|--------|
| 还原招牌 | 版本冲突 | 新旧招牌叠影 | 永久 |
| 恢复菜单 | 数据残留 | 菜单项闪烁 | 永久 |
| 点不存在的菜 | 因果异常 | 桌上空碗残影 | 本次访问 |

#### 特殊事件

| 事件ID | 触发条件 | 内容 | R/P影响 |
|--------|----------|------|---------|
| RV02-E1 | 发现旧照片 | 店主："那张照片...我不记得了" | - |
| RV02-E2 | 点"不存在的菜" | 系统："无收益行为已记录" | R+2 |
| RV02-E3 | 已见过栖蓝 | 照片中被涂抹的人像似栖蓝 | R+1 |

#### 收集品

| 物品 | 获取方式 | 类型 | 备注 |
|------|----------|------|------|
| 《被涂抹的合影》 | 深度感知拍照 | 档案卡 | 关联F08 |
| 《老张特制面食谱》 | 点不存在的菜后店主给予 | 物品卡 | 无实际用途（无收益） |

### RV-03 | 薄墙巷口重返

#### 基本信息

| 属性 | 值 |
|------|-----|
| **原Zone** | C0-Z3 薄墙巷口 |
| **变体类型** | 深度感知 + 时间干预 |
| **位置** | 居住环/边缘 |
| **预计时长** | 20分钟 |
| **关联伏笔** | F01（薄墙回声）、F03（宋岚的记录使命） |

#### 触发条件

```yaml
trigger:
  v1_unlock:
    - ability: depth_perception
    - zone_completed: C0-Z3
  v3_unlock:
    - ability: time_intervention
    - zone_completed: C0-Z3
```

#### 与原Zone差异对比

| 元素 | 原版 | 深度感知版 | 时间干预版 |
|------|------|------------|------------|
| **薄墙** | 普通墙面 | 边界裂缝可见 | 三态同时显示 |
| **声音** | 回声提示 | 回声来源可视 | 时间线上的声音叠加 |
| **空间** | 封闭 | 墙后空间轮廓 | 可选择进入哪个时态的空间 |
| **交互** | 听回声 | 查看边界 | 回溯选择 |

#### 时间线节点

```
时间线结构:
─────●─────●─────●───→
     T1    T2    NOW

T1 - 薄墙完整:
- 墙体结构稳定
- 回声微弱
- 空间密封

T2 - 薄墙开裂:
- 墙体出现裂缝
- 可从裂缝窥视
- 发现隐藏通道

NOW - 薄墙有补丁:
- 裂缝被修补
- 补丁痕迹明显
- 空间状态不确定
```

#### 时间回溯效果

| 回溯目标 | 场景变化 | 可获取内容 | 代价 |
|----------|----------|------------|------|
| **回溯到T1** | 墙体恢复完整 | 发现墙体建造时间标记 | P+3，污染+1 |
| **回溯到T2** | 裂缝状态恢复 | 从裂缝发现宋岚的藏书 | P+2，污染+1 |
| **不回溯** | 保持现状 | 获得"观察者"标记 | - |

#### 伤痕/污染视觉表现

| 行为 | 伤痕类型 | 视觉效果 | 持久性 |
|------|----------|----------|--------|
| 回溯到T1 | 时间污染 | 墙面出现时间涟漪 | 永久 |
| 回溯到T2 | 版本叠加 | 裂缝与补丁同时可见 | 永久 |
| 从裂缝取物 | 因果矛盾 | 物品带有时间残影 | 物品属性 |

#### 特殊事件

| 事件ID | 触发条件 | 内容 | R/P影响 |
|--------|----------|------|---------|
| RV03-E1 | 首次回溯 | 系统："回溯不会抹除观察记录" | P+3 |
| RV03-E2 | 发现藏书 | 宋岚的记录本，内容为版本差异日志 | - |
| RV03-E3 | 回溯后再回溯 | 系统出现卡顿："...重复操作..." | P+2 |

#### 收集品

| 物品 | 获取方式 | 类型 | 备注 |
|------|----------|------|------|
| 《薄墙建造日志》 | 回溯到T1 | 档案卡 | 揭示建造目的 |
| 《宋岚的版本差异记录》 | 回溯到T2从裂缝取出 | 档案卡 | 关联F03 |
| 《补丁材料成分表》 | 深度感知分析补丁 | 档案卡 | 暗示收敛机制 |
