## 📌 音频哲学

### 核心理念

1. **沉浸优先**：音频是世界的一部分，不是背景装饰
2. **叙事服务**：每个音效都应该强化叙事体验
3. **克制表达**：宁缺毋滥，静默也是设计
4. **系统感**：音频风格体现"收敛运行时"的存在

### 音频关键词

```
氛围电子 · 极简主义 · 空间感 · 系统音 · 东方元素 · 克制
```

## 1. BGM设计

### 1.1 音乐风格定义

| 属性 | 描述 |
|------|------|
| **基调** | 氛围电子 (Ambient Electronic) |
| **节奏** | 慢至中等 (60-90 BPM) |
| **和声** | 小调为主，偶尔开放和弦 |
| **质感** | 合成器铺垫 + 微妙旋律 + 空间混响 |
| **情绪** | 神秘、忧郁、不安但不恐怖 |

### 1.2 BGM列表

| ID | 名称 | 用途 | 情绪 | 时长 |
|----|------|------|------|------|
| `bgm_title` | 标题曲 | 主菜单 | 神秘、期待 | 2:30 |
| `bgm_prologue` | 序章曲 | C0 | 平静、微妙不安 | 3:00 |
| `bgm_archive` | 档案曲 | 档案巷 | 怀旧、神秘 | 3:30 |
| `bgm_drifter` | 漂流曲 | 栖蓝相关 | 温暖、孤独 | 3:00 |
| `bgm_depth_perception` | 深度感知曲 | 能力使用 | 紧张、发现 | 2:00 |
| `bgm_anomaly` | 异常曲 | 结构异常区 | 不安、危机 | 3:00 |
| `bgm_finale` | 终章曲 | CF | 史诗、决绝 | 4:00 |
| `bgm_ending` | 结局曲 | 结局 | 释然、余韵 | 3:00 |

### 1.3 章节BGM配置

| 章节 | 主BGM | 特殊场景BGM |
|------|-------|-------------|
| C0 | bgm_prologue | - |
| C1 | bgm_prologue | bgm_archive (档案巷) |
| C2 | bgm_archive | bgm_depth_perception (能力教学) |
| C3 | bgm_anomaly | bgm_drifter (栖蓝Zone) |
| C4 | bgm_anomaly | bgm_depth_perception (时间Zone) |
| C5 | bgm_anomaly | bgm_finale (C5后半) |
| CF | bgm_finale | bgm_ending (结局) |

### 1.4 BGM过渡规范

| 过渡类型 | 时长 | 方式 |
|----------|------|------|
| **Zone切换** | 2s | 交叉淡化 |
| **状态变化** | 1s | 淡出→淡入 |
| **紧急事件** | 0.5s | 快速切换 |
| **能力激活** | 0.3s | 叠加→替换 |

```yaml
# BGM过渡配置
bgm_transitions:
  zone_change:
    fade_out: 1000ms
    fade_in: 1000ms
    overlap: 500ms
    
  state_change:
    fade_out: 500ms
    fade_in: 500ms
    
  emergency:
    cut: true
    fade_in: 300ms
```

### 2.3 动态环境音

```yaml
# 根据游戏状态调整环境音
dynamic_ambience:
  # P值影响
  pressure_modulation:
    P_0_5:
      filter: none
      volume: 100%
    P_6_10:
      filter: lowpass_80%
      volume: 110%
      add_layer: subtle_hum
    P_11_plus:
      filter: lowpass_60%
      volume: 120%
      add_layer: distortion_crackle
      
  # W值影响
  stability_modulation:
    W_80_plus:
      effect: none
    W_40_79:
      effect: occasional_glitch
      frequency: 30s
    W_under_40:
      effect: frequent_glitch
      frequency: 10s
```

### 3.2 UI音效规范

| 属性 | 规范 |
|------|------|
| **时长** | 50-300ms |
| **音量** | BGM的30-50% |
| **频率** | 高频为主（清脆） |
| **风格** | 科技感、克制 |

### 3.3 UI音效使用原则

```
✓ 应该有音效的操作:
- 按钮点击
- 面板开关
- 卡片获得
- 重要确认

✗ 不应有音效的操作:
- 普通移动
- 持续滚动（仅偶尔）
- 对话文字（仅开始/结束）
- 背景切换

⚠ 特殊处理:
- 快速连续操作: 音效节流（间隔100ms）
- 同时触发多个: 只播放优先级最高的
```

### 4.4 能力音效详细设计

#### 深度感知音效设计

```
激活音效 (sfx_depth_perception_activate):
┌────────────────────────────────────────────┐
│  0ms     100ms    200ms    300ms    500ms  │
│  │        │        │        │        │     │
│  ├──低频共鸣开始────────────────────────────│
│  │        ├──扫描音渐入──────────────────│  │
│  │        │        ├──高频泛音────────│  │  │
│  │        │        │        ├──稳定持续────│
└────────────────────────────────────────────┘

音色构成:
- 基底: 低频共鸣 (80-120Hz)
- 主体: 合成器扫描音 (中频滑动)
- 装饰: 高频泛音 (科技感)
```

#### 深度介入音效设计

```
介入音效 (sfx_depth_intervention):
┌────────────────────────────────────────────┐
│  0ms     300ms    600ms    900ms    1200ms │
│  │        │        │        │        │     │
│  ├──张力蓄积────│                          │
│  │        ├──撕裂主体音──│                 │
│  │        │        ├──结构碎裂声──│        │
│  │        │        │        ├──余韵回响──│ │
└────────────────────────────────────────────┘

音色构成:
- 张力: 上升音调 (tension build)
- 主体: 撕裂/改变音 (冲击感)
- 碎裂: 碎片化音效 (细节)
- 余韵: 空间回响 (后果感)
```

## 6. 音频技术规范

### 6.1 文件格式

| 用途 | 格式 | 采样率 | 比特率 |
|------|------|--------|--------|
| BGM | MP3 | 44.1kHz | 192kbps |
| 环境音 | MP3 | 44.1kHz | 128kbps |
| 音效 | MP3 | 44.1kHz | 128kbps |

### 6.2 音量标准

| 类型 | 基准音量 | 范围 |
|------|----------|------|
| BGM | -12dB | -18 ~ -8dB |
| 环境音 | -18dB | -24 ~ -12dB |
| UI音效 | -10dB | -15 ~ -6dB |
| 游戏音效 | -8dB | -12 ~ -4dB |
| 重要提示 | -6dB | -10 ~ -3dB |

### 6.3 音频管理器接口

```typescript
interface IAudioManager {
  // BGM控制
  playBGM(id: string, options?: { fade?: number }): void;
  stopBGM(fade?: number): void;
  pauseBGM(): void;
  resumeBGM(): void;
  
  // 环境音控制
  playAmbience(id: string): void;
  stopAmbience(fade?: number): void;
  setAmbienceVolume(volume: number): void;
  
  // 音效控制
  playSFX(id: string, options?: { volume?: number }): void;
  stopSFX(id: string): void;
  
  // 全局控制
  setMasterVolume(volume: number): void;
  setBGMVolume(volume: number): void;
  setSFXVolume(volume: number): void;
  mute(): void;
  unmute(): void;
}
```
