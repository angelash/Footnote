# 剧情不对齐：完整分析报告与解决计划（以小说为最高参照）

> 本报告目标：以 `story/1.md` ~ `story/5.md` 为**唯一权威剧情源**，对仓库内所有“涉及剧情的文档/数据/漫画产物”做一次对齐审计，定位偏差并给出可执行修复计划与自动化防回归方案。

## 1. 结论摘要（先说结论）

### 1.1 根因（Root Cause）

当前的“剧情不对齐”不是单点错误，而是**源头级的章节识别错误 + 缺少对齐验收**导致的系统性偏差：

- **章节识别错误**：把 `story/{n}.md` 误当作 “第 n 章”，导致 EP01/EP02 在“章节范围/事件顺序”上出现错位与混用。
- **缺少权威索引**：没有把小说章节结构固化为机器可读的索引，后续所有衍生产物都在“猜”章节位置。
- **角色设定漂移**：漫画提示词/场景分析里存在与小说不一致的角色设定（已确认：**宋岚性别**在漫画产物中被写成男性，但小说明确使用“她”指代）。

### 1.2 影响范围（Blast Radius）

- **漫画产物**：
  - `comics/scripts/ep01/`：章节范围声明与小说不一致；并引入了明显属于后期章节的锚点短语（例如“身份：核对中”）。
  - `comics/scripts/ep02/`：主线事件（第3-5章）整体对齐，但**宋岚性别设定错误**会影响对应页面画面与角色一致性。
- **工作流规范**：
  - `.cursor/rules/07-novel-to-comic.mdc` 中的“章节拆分策略/分部范围/关键场景清单”与小说实际 5 部 65 章结构存在偏差（需要以小说索引回填）。

## 4. 现状对齐分析（已确认的不对齐点）

### 4.1 自动化锚点扫描结果（EP01/EP02）

自动检查输出：

- `docs/alignment/alignment_check.json`
- `docs/alignment/剧情对齐分析报告.md`（自动生成简版）

核心报警（已确认高概率不对齐）：

1) **EP01 引用了“身份：核对中”**  
   - 小说落点：第31章《对账口》  
   - 但 EP01 声明章节：`[1,2,3,4,5]`

2) **EP01 引用了“空椅”**  
   - 小说落点：第20/21/25/…/65章多处（作为贯穿线）  
   - 但 EP01 声明章节：`[1,2,3,4,5]`

> 结论：**EP01 当前分镜/提示词存在“后期事件提前”的错位**，属于必须修复的严重问题。

### 4.2 角色设定不对齐（已确认：宋岚性别）

小说第17章《底层抽屉》明确使用“她”指代宋岚（见 `story/2.md` 对应章节内容）。  
但 EP02 场景分析与提示词中把宋岚写成“中年亚洲男性”（见 `comics/scripts/ep02/ep02-scene-analysis.yaml`、`comics/scripts/ep02/ep02-prompts-full.md`）。

> 影响：涉及宋岚出场的页面（尤其EP02中“摊位/版本库”相关镜头）需要重写提示词并评估是否重出图。

### 4.3 EP01 章节范围与事件编排不对齐（结构性问题）

当前 EP01 场景分析文件声明覆盖第1-5章，但其场景与小说章节的锚点并不一致：

- 小说第1-5章核心顺序：既定路线 → 薄墙巷口 → 错门（17-06）→ 市政更正 → 稳定结论（许澄/阿棠）
- EP01 目前含有“身份：核对中”等明显更靠后章节出现的系统提示语法，导致“强世界观语句提前”。

## 5. 修复目标（Definition of Done）

### 5.1 对齐定义（强制）

对任意剧情承载物 X（Zone脚本/对白/卡片/漫画分镜/提示词）：

- **章节对齐**：X 所声明章节范围，必须能在 `docs/alignment/story_index.json` 中定位，且不出现明显“跨部提前”锚点。
- **人物对齐**：角色性别/年龄段/出场顺序必须与小说一致（最少满足：小说明确写出的事实）。
- **事件对齐**：每个关键事件（如“错门17-06”“以最新更正为准”“稳定结论”“两份小票/互斥双日期”“空椅线”“对账口”）不得被提前到小说未发生的位置。

### 5.2 验收产物

- `docs/alignment/story_index.json` 与 `story_index.md`（已完成）
- `docs/alignment/剧情对齐分析与修复计划.md`（本文件）
- 运行 `python comics/scripts/alignment/check_story_alignment.py` 不再对 EP01/EP02 输出“跨部明显提前”的报警项（或报警项均有人工豁免说明）

## 6. 解决计划（分阶段、可落地）

### Phase 0：冻结“权威章节索引”（已完成）

- 运行：`python comics/scripts/alignment/extract_story_index.py`
- 输出：`docs/alignment/story_index.json` / `story_index.md`

### Phase 1：对齐审计（本次要完成）

1. **对齐矩阵**（章节 → 设计 → 实现 → 漫画）
   - 以小说章节为行（至少先覆盖 1-20 章，用于修复EP01/EP02/EP03）
   - 列：Zone脚本包位置、`src/data/scenes`、`src/data/dialogues`、漫画页（EPxx-Pyy）
2. **差异分类**（每条差异必须归类到一种类型）：
   - 章节错位（事件提前/挪后）
   - 角色设定错（性别/年龄/出场顺序/关系）
   - 术语提前（模型/结算/对账等语汇提前导致观感跳级）
   - 文字引用错误（对白/判词与小说不一致）

### Phase 2：修复 EP01/EP02（优先级最高）

1. **修复 EP01 的章节范围与分镜**
   - 建议新范围：**第1-2章**（既定路线、薄墙巷口）
   - EP02 保持：**第3-5章**（错门/更正/稳定结论）
   - 处理策略：EP01 当前已生成图像可作为“试制稿”归档，但不作为正片展示。
2. **修复 EP02 的宋岚角色设定**
   - 修改提示词与场景分析：宋岚=女性（并补齐小说中的“纸/阴影/版本库底层”质感）
   - 对涉及宋岚明显出镜的页面进行“是否重出图”评估：
     - 若画面已明显男性化：重出图
     - 若画面中性且不影响理解：可不重出图，但后续必须统一

### Phase 3：建立强制对齐工作流（防止复发）

1. **硬规则**：任何“生成分镜/提示词”的流程必须先跑 `story_index`，禁止从文件名推章节。
2. **最小自动化**：保留并扩展 `check_story_alignment.py`：
   - 新增：从 `comics/scripts/epXX/*` 自动抓取“锚点短语”候选
   - 输出：每个锚点在小说中出现的章节清单 + 与EP声明的冲突报警
3. **人审入口**：对齐报告中每条差异必须能点击回到小说原文行号（索引已具备定位信息）。
