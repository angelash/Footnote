## 一、核心工作流

### 1.1 四张锚定图系统

在生成任何资产前，必须准备并引用以下锚定图：

| 锚定图 | 用途 | 路径 |
|--------|------|------|
| Style Anchor | 定义像素风格、细节程度 | `assets/anchors/style_anchor_v1.webp` |
| Palette Anchor | 定义区域/角色配色 | `assets/anchors/palette_{region}.webp` |
| Camera Grid Anchor | 定义透视和网格 | `assets/anchors/camera_grid_ortho.webp` |
| Lighting Anchor | 定义光照方向和强度 | `assets/anchors/lighting_topleft.webp` |

### 1.2 生成 vs 编辑规则

```yaml
生成(Generate)适用场景:
  - 全新资产首次创建
  - 没有现有参考的情况
  - 独立的单帧资产

编辑(Edit)适用场景:
  - 基于现有资产创建变体
  - 表情变化（基于中性表情）
  - 动画帧（基于主帧）
  - 状态变体（基于默认状态）

关键原则:
  - 序列帧必须使用Edit模式
  - 表情变体必须使用Edit模式
  - 物件状态变体必须使用Edit模式
```

## 九、质量检查清单

### 9.1 生成前检查

- [ ] 已准备四张锚定图
- [ ] 确定生成/编辑模式
- [ ] 确认尺寸规格
- [ ] 确认配色方案

### 9.2 生成后检查

- [ ] **风格一致**: 像素风 + 赛博朋克
- [ ] **朝向正确**: 角色正面/3/4侧面
- [ ] **背景处理**: 透明或深色（按需求）
- [ ] **无文字**: 图片中没有文字
- [ ] **无水印**: 没有AI工具水印
- [ ] **光照一致**: 左上方光源
- [ ] **像素大小**: 2px统一
- [ ] **尺寸正确**: 符合规格要求
- [ ] **色调统一**: 符合区域/角色配色

### 9.3 序列帧额外检查

- [ ] 帧数正确
- [ ] 基线稳定（角色）
- [ ] 循环无跳帧
- [ ] 首尾帧可衔接（循环动画）

## 十、常见问题与解决

### Q1: 生成的风格不一致
**解决**: 增加锚定图权重，在提示词中明确引用style anchor

### Q2: 角色表情变化时整体风格改变
**解决**: 使用Edit模式而非Generate，只修改脸部区域

### Q3: Tileset边缘不无缝
**解决**: 在提示词中强调"seamless edges"，生成后手动检查接缝

### Q4: 特效透明度问题
**解决**: 明确指定"transparent background, no colored background"

### Q5: 光照方向不一致
**解决**: 每次都包含"consistent top-left lighting"，并引用lighting anchor
