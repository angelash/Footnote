## 一、角色资产提示词

### 1.1 角色立绘模板（全身）

#### 通用结构
```
[风格] + [主体] + [外观] + [服装] + [表情] + [姿态] + [背景] + [技术]
```

#### 强制约束词
| 需求 | 约束词 |
|------|--------|
| 纯正面 | `facing camera directly, front view, perfectly symmetrical, looking at viewer` |
| 纯侧面 | `side profile view, facing left/right, 90 degree angle` |
| 三分之一侧 | `3/4 view, slight turn, asymmetrical pose` |
| 站立姿态 | `standing pose, full body, feet visible, upright posture` |
| 透明背景 | `transparent background, PNG with alpha, isolated character` |
