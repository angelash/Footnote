## 📌 核心概念

本规范定义了游戏中所有资产的尺寸标准和拼装规则，确保资产可以像乐高一样自由组合。

## 1. 世界单位系统 (Tile Unit System)

### 1.1 TU 定义

```yaml
tile_unit:
  name: "TU (Tile Unit)"
  definition: "1 TU = 1 地块占地"
  
  # 运行时像素映射
  runtime_mapping:
    1_TU: 64px          # 基础映射
    half_TU: 32px       # 小物件
    2_TU: 128px         # 大物件
  
  # 生成时画布（AI生成用）
  authoring_canvas:
    1x1_tile: 1024×1024px   # 缩放到64×64
    2x2_tile: 1024×1024px   # 缩放到128×128
    scene_16x9: "16:9比例"   # 缩放到1024×576
```

### 1.2 屏幕块定义

```yaml
screen_block:
  # 竖屏游戏设计
  orientation: "portrait"
  
  # 基于TU的屏幕尺寸
  grid_size:
    width: 12 TU        # 横向12格
    height: 21 TU       # 纵向21格（竖屏）
  
  # 运行时分辨率
  runtime_resolution:
    width: 750px        # 12 TU × 62.5px ≈ 750px
    height: 1334px      # 21 TU × 63.5px ≈ 1334px
  
  # 安全区域
  safe_area:
    top: 2 TU           # 状态栏区域
    bottom: 2 TU        # 操作区域
    sides: 0.5 TU       # 边距
```

## 2. 资产占格规则 (Footprint System)

### 2.1 占格类型定义

所有物件必须归类到以下占格类型，**禁止自由尺寸**：

| 类型 | 占格 | 运行时尺寸 | 适用物件 | 示例 |
|------|------|------------|----------|------|
| **S (小件)** | 0.5×0.5 TU | 32×32px | 装饰 | 蘑菇、小石子、花 |
| **M (标准)** | 1×1 TU | 64×64px | 常规物件 | 箱子、路牌、灌木 |
| **L (大件)** | 2×2 TU | 128×128px | 大型物件 | 大树底座、小屋、池塘 |
| **XL (建筑)** | 4×4 TU | 256×256px | 建筑模块 | 房屋、大型结构 |
| **Custom** | 1×2/2×1 TU | 64×128px | 特殊物件 | 床、长椅、书架 |

### 2.2 禁止项

```yaml
forbidden_sizes:
  - "1.3×1.7 TU"     # 不规则尺寸
  - "0.8×0.8 TU"     # 非标准尺寸
  - "任何小数占格"    # AI容易生成的"差不多"尺寸
```

### 2.3 占格类型图示

```
S (0.5×0.5)    M (1×1)        L (2×2)        XL (4×4)
┌───┐          ┌─────┐        ┌─────────┐    ┌─────────────────┐
│ S │          │     │        │         │    │                 │
└───┘          │  M  │        │    L    │    │                 │
32px           │     │        │         │    │       XL        │

               64px           128px          │                 │
                                             └─────────────────┘
                                             256px
```

## 3. 锚点系统 (Pivot System)

### 3.1 锚点规则

**锚点是对齐用的参考点，必须统一**

```yaml
pivot_rules:
  # 可摆放物件
  props:
    position: "占地footprint的底边中心点"
    example: "1×1物件的pivot在(0.5, 1.0)归一化坐标"
  
  # 角色
  characters:
    position: "双脚中点"
    grid_placement: "落在TU网格中心"
  
  # 墙体/栅栏
  walls:
    position: "占地边线中点"
    usage: "贴边摆放"
  
  # 树木
  trees:
    base_pivot: "树干底座的底边中心"
    canopy_pivot: "与底座相同（分层但对齐）"
```

### 3.2 锚点位置示意

```
物件锚点位置（底边中心）：

     ┌─────────────┐
     │             │
     │   可视区域   │
     │             │
     │             │
     └──────●──────┘
            ↑
         Pivot点
    (占地底边中心)

角色锚点位置（双脚中点）：

         ┌───┐
         │头 │
         ├───┤
         │身 │
         │体 │
         ├───┤
        /│   │\
       / └───┘ \
      ●─────────●
         ↑
      Pivot点
    (双脚中点)
```

### 3.3 锚点在帧动画中的作用

```yaml
animation_pivot_rules:
  # 基线固定
  baseline:
    y_position: "固定值（如256×256画布中y=208）"
    tolerance: "±1px"
  
  # 头顶限制
  top_bound:
    max_y: "固定值（如y=48）"
    purpose: "防止角色'长高'"
  
  # 横向限制
  side_bounds:
    max_width: "不超过指定宽度"
    purpose: "防止角色'变胖'"
```

## 4. 地块语法系统 (Tileset Grammar)

### 4.1 地块三层结构

```yaml
ground_layers:
  layer_1_base:
    name: "Ground Base（基底）"
    content: "草、土、石路、木地板、沙..."
    rule: "完全平铺，不含过渡边"
    examples:
      - "t_grass_base__1x1__top__a.png"
      - "t_dirt_base__1x1__top__a.png"
  
  layer_2_transition:
    name: "Transition（过渡）"
    content: "草→土，土→石路..."
    rule: "只画边缘形状，中间透明"
    examples:
      - "t_grass_to_dirt_edge__1x1__top__n.png"
      - "t_dirt_to_stone_corner__1x1__top__ne.png"
  
  layer_3_overlay:
    name: "Overlay（覆盖）"
    content: "落叶、裂纹、苔藓、积雪边、湿痕"
    rule: "透明贴花，打破重复感"
    examples:
      - "t_leaves_overlay__1x1__top__a.png"
      - "t_crack_overlay__1x1__top__a.png"
```

## 5. 物件尺寸规格

### 5.1 各类物件标准尺寸

| 物件类型 | 占格 | 生成画布 | 运行时 | 备注 |
|----------|------|----------|--------|------|
| 小装饰 | S (0.5×0.5) | 512×512 | 32×32 | 花、蘑菇 |
| 标准物件 | M (1×1) | 1024×1024 | 64×64 | 箱子、桶 |
| 大型物件 | L (2×2) | 1024×1024 | 128×128 | 树、小屋基座 |
| 建筑模块 | XL (4×4) | 2048×2048 | 256×256 | 需拆分 |
| 角色精灵 | - | 256×256 | 64×128 | 竖向 |
| 角色头像 | - | 512×512 | 200×200 | 对话用 |
| 背景场景 | - | 1500×2668 | 750×1334 | 竖屏全景 |

### 5.2 建筑模块化规则

**XL及以上必须拆分成模块**

```yaml
building_modules:
  # 必须拆分的组件
  components:
    - "底座 (base)"
    - "墙体 (wall)"
    - "屋顶 (roof)"
    - "檐前遮挡 (occluder)"
  
  # 组装示意
  assembly: |
    ┌──────────────┐
    │    屋顶      │  ← roof (可能遮挡角色)
    ├──────────────┤
    │              │
    │    墙体      │  ← wall
    │              │
    ├──────────────┤
    │    底座      │  ← base (角色可站在上面)
    └──────────────┘
  
  # 好处
  benefits:
    - "可以单独替换组件"
    - "可以正确处理遮挡"
    - "可以复用基础模块"
```

## 6. 角色尺寸规格

### 6.1 角色帧画布标准

```yaml
character_frame:
  # 标准帧画布
  canvas:
    size: "256×256px"
    format: "PNG with alpha"
  
  # 基线定义
  baseline:
    y: 208              # 脚底基线
    tolerance: "±1px"
  
  # 边界盒
  bounds:
    top: 48             # 头顶最高
    bottom: 208         # 脚底最低
    left: 64            # 左边最宽
    right: 192          # 右边最宽
  
  # Pivot位置
  pivot:
    x: 128              # 画布水平中心
    y: 208              # 脚底基线
```

## 8. 高度与层级

### 8.1 高度单位定义

```yaml
height_system:
  unit: "Level"
  visual_height: "0.5 TU per Level"
  
  # 高地组件
  components:
    top: "顶面（按Ground Base）"
    cliff_face: "立面（单独边缘件）"
    shadow_under: "阴影（贴花或引擎阴影）"
```

### 8.2 层级渲染顺序

```yaml
render_layers:
  # 从后到前（z-index从小到大）
  order:
    0: "Ground Base（地面基底）"
    1: "Ground Transition（地面过渡）"
    2: "Ground Overlay/Decal（地面覆盖）"
    3: "Shadow（阴影层）"
    4: "Object Base（物件底座）"
    5: "Character（角色）"
    6: "Foreground Occluder（前景遮挡）"
    7: "Screen FX（屏幕特效）"
  
  # 遮挡规则
  occlusion:
    - "Layer 6 会遮挡 Layer 5"
    - "树冠、屋檐属于Layer 6"
    - "树冠必须与树干分开（树干在Layer 4）"
```
