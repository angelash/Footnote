## 📌 核心原则

序列帧的一致性问题来自"每帧重新设计角色"。解决方案是把角色拆成**不可变集合**和**可变部分**。

## 1. Character Lock Pack（角色锁定包）

### 1.1 概念说明

**Lock Pack = 角色的不可变约束集合**

在开始任何帧生成之前，必须先产出Lock Pack，作为所有后续工作的基准。

### 1.2 Lock Pack 六要素

| 序号 | 锁定项 | 内容 | 形式 |
|------|--------|------|------|
| 1 | **比例锁** | 头身比、手脚长度、肩宽、腰线高度 | 数值+示意图 |
| 2 | **配色锁** | 主色/辅色/点缀色（最多6色） | 色板图 |
| 3 | **五官布局锁** | 眼睛间距、眼睛高度、嘴的位置 | 基准线标注图 |
| 4 | **轮廓锁** | 角色剪影（黑色silhouette） | 剪影图 |
| 5 | **材质锁** | 布/皮/金属的高光逻辑 | 材质示例 |
| 6 | **线边规则** | 线宽范围、是否随光变粗细 | 文字+示例 |

### 1.3 Lock Pack 示例结构

```yaml
# 文件名: specs/characters/lock_pack_cenhui.yaml

character_id: cenhui
name: "岑回"
version: 1

# 1. 比例锁
proportions:
  head_body_ratio: "1:6"      # 头身比
  shoulder_width: "2头宽"
  waist_height: "0.45身高"
  arm_length: "0.4身高"
  leg_length: "0.55身高"
  
  # 画布内像素值（256×256帧）
  head_height_px: 48
  body_height_px: 160
  total_height_px: 160        # 脚到头顶

# 2. 配色锁
color_palette:
  primary: "#5A5A5A"          # 深灰（外套）
  secondary: "#3A3A3A"        # 更深灰（裤子）
  accent: "#00FFAA"           # 荧光绿（权限标识）
  skin: "#E8D4C4"             # 肤色
  hair: "#2A2A2A"             # 黑发
  max_colors: 6

# 3. 五官布局锁
facial_layout:
  # 归一化坐标（0-1，头部范围内）
  eye_center_y: 0.4           # 眼睛垂直位置
  eye_spacing: 0.3            # 眼间距（占头宽比例）
  nose_y: 0.55
  mouth_y: 0.7
  # 像素值（基于48px头高）
  eye_width_px: 8
  eye_height_px: 4

# 4. 轮廓锁
silhouette:
  file: "references/silhouette_cenhui.png"
  key_features:
    - "齐肩短发轮廓"
    - "连帽衫轮廓（带帽）"
    - "工具包腰间凸起"

# 5. 材质锁
materials:
  fabric:
    highlight: "单条高光带"
    shadow: "2层阴影"
    texture: "无纹理"
  hair:
    highlight: "1-2条发丝高光"
    shadow: "单色块"
  skin:
    highlight: "柔和过渡"
    shadow: "暖色阴影"

# 6. 线边规则
line_rules:
  outline_width: "2px（运行时）"
  internal_lines: "1px"
  line_color: "#1A1A1A"
  light_variation: false      # 线宽不随光变化
```

## 2. 序列帧工业化流程

### 2.1 正确的生产顺序

**先"骨架帧"，再"贴皮"**

```yaml
animation_workflow:
  step_1_skeleton:
    name: "骨架帧制作"
    tool: "任意绘图软件"
    time: "5分钟/帧"
    output: "火柴人/简化块面"
    content:
      - "头部位置"
      - "躯干朝向"
      - "骨盆角度"
      - "手脚位置"
  
  step_2_skin:
    name: "AI贴皮"
    input:
      - "角色母版"
      - "本帧骨架图"
      - "Lock Pack圣经图"
    output: "完成的角色帧"
    prompt_key: "只允许'姿势变化'，禁止改造型"
```

### 2.2 母版生成流程（SOP-A）

```yaml
master_generation_sop:
  step_1:
    action: "生成正面标准站姿"
    output: "master_front.png"
    requirements:
      - "完全正面对称"
      - "符合Lock Pack所有约束"
      - "背景纯绿(#00FF00)"
  
  step_2:
    action: "生成侧面标准站姿"
    input: "master_front.png"
    method: "编辑（非重新生成）"
    output: "master_side.png"
    prompt: "保持角色完全一致，只改变视角为侧面"
  
  step_3:
    action: "生成背面标准站姿"
    input: "master_front.png"
    method: "编辑"
    output: "master_back.png"
  
  step_4:
    action: "验证一致性"
    method: "将三张图并排比较"
    checklist:
      - "比例是否一致"
      - "配色是否一致"
      - "细节密度是否一致"
  
  final:
    name: "Character Anchor Set"
    files:
      - "master_front.png"
      - "master_side.png"
      - "master_back.png"
```

### 2.3 逐帧编辑流程（SOP-B）

```yaml
frame_edit_sop:
  frame_0:
    action: "使用母版站姿"
    input: "master_down.png"
    output: "walk_down_f00.png"
  
  frame_1:
    action: "编辑腿部为迈步姿势"
    input: "walk_down_f00.png + skeleton_f01.png"
    edit_region: "仅腿部（骨盆以下）"
    locked_regions: "头、躯干、手臂"
    output: "walk_down_f01.png"
  
  frame_2:
    action: "编辑腿部为下一步"
    input: "walk_down_f01.png + skeleton_f02.png"
    edit_region: "仅腿部"
    output: "walk_down_f02.png"
  
  # 以此类推...
  
  key_principle: "每次编辑只允许改动一个'关节域'"
```

### 2.4 关节域编辑原则

**一次只改一个域，避免AI重画整个人**

```yaml
joint_domains:
  leg_domain:
    range: "骨盆以下"
    animations: ["walk", "run", "jump"]
    
  arm_domain:
    range: "肩膀以下"
    animations: ["interact", "wave", "attack"]
    
  torso_domain:
    range: "肩线到骨盆"
    animations: ["idle_breathe", "lean"]
    
  head_domain:
    range: "颈部以上"
    animations: ["look_around", "talk"]

forbidden:
  - "同时改腿、改手、改表情"
  - "一次让AI'走起来并挥手并眨眼'"
```

## 3. 帧画布标准

### 3.1 标准帧规格

```yaml
frame_canvas:
  size: [256, 256]           # 像素
  format: "PNG with alpha"
  
  baseline:
    y: 208                   # 脚底基线
    tolerance_px: 1          # 允许误差±1px
  
  bounds:
    top_limit: 48            # 头顶最高y
    bottom_limit: 208        # 脚底最低y
    left_limit: 64           # 左边最宽x
    right_limit: 192         # 右边最宽x
  
  pivot:
    x: 128                   # 画布水平中心
    y: 208                   # 脚底基线
    type: "双脚中点"
```

### 3.2 帧画布示意

```
     0    64        128        192  256
     ├────┼──────────┼──────────┼────┤
  0  │    │          │          │    │
     │    │   禁止区  │   禁止区  │    │
 48  ├────┼──────────┼──────────┼────┤ ← 头顶上限
     │    │    ┌─────┴─────┐    │    │
     │    │    │           │    │    │
     │    │    │   角色    │    │    │
     │    │    │   可用    │    │    │
     │    │    │   区域    │    │    │
     │    │    │           │    │    │
     │    │    └─────┬─────┘    │    │
208  ├────┼──────────●──────────┼────┤ ← 基线(Pivot)
     │    │          │          │    │
256  └────┴──────────┴──────────┴────┘
     
     禁止区：64px              禁止区：64px
            ↑                      ↑
         左边界                  右边界
```

### 3.3 抖动控制三件套

```yaml
anti_jitter_rules:
  # 1. 固定脚底基线
  baseline_lock:
    y_position: 208
    check: "每帧脚底必须在此线"
    tolerance: "±1px"
  
  # 2. 固定头顶盒
  top_bound_lock:
    max_y: 48
    check: "头顶不得超过此线"
    purpose: "防止'长高/缩矮'"
  
  # 3. 固定宽度盒
  width_bound_lock:
    left: 64
    right: 192
    max_width: 128
    purpose: "防止'变胖/变瘦'"
  
  validation:
    method: "每帧必须检查三个边界"
    fail_action: "超出边界 = 返工（不要'差不多'）"
```

## 5. 动作集标准

### 5.1 最小可用动作集（MVP）

```yaml
mvp_animation_set:
  idle:
    frames: 2
    fps: 4
    description: "A/B呼吸循环"
    change_domain: "torso (轻微)"
    loop: true
  
  walk:
    frames: 6
    fps: 8
    description: "完整行走循环"
    change_domain: "leg"
    loop: true
    directions: ["down", "up", "left", "right"]
  
  interact:
    frames: 3
    fps: 6
    description: "抬手→触碰→回位"
    change_domain: "arm"
    loop: false
  
  # 总帧数估算
  total_frames:
    idle: "2 × 4方向 = 8帧"
    walk: "6 × 4方向 = 24帧"
    interact: "3 × 4方向 = 12帧"
    sum: "44帧/角色"
```
