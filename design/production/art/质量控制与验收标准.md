# 《备注 / Footnote》质量控制与验收标准 v1.0

> **文档性质**：资产QC与验收的执行规范  
> **适用对象**：主美、执行美术、技术美术  
> **最后更新**：2025-12-25  
> **核心理念**：把"看起来差不多"变成"可验收"

---

## 📌 QC 核心原则

1. **规则化**：所有检查项都有明确标准
2. **可脚本化**：80%检查可自动化
3. **可追溯**：每个资产有验收记录
4. **快速反馈**：问题及早发现

## 1. 主美验收（每周/每批次）

### 1.1 体系一致性检查

```yaml
system_consistency_checklist:
  camera:
    check: "视角是否100%同一套"
    method: "地面网格能否完全对齐"
    pass_criteria: "所有资产网格对齐，无旋转"
  
  lighting:
    check: "光向是否一致"
    method: "检查阴影方向/长度"
    pass_criteria: "所有阴影朝右下，长度相近"
  
  detail_budget:
    check: "细节预算是否一致"
    method: "对比纹理复杂度"
    pass_criteria: "同类资产细节密度一致"
  
  color_range:
    check: "色相范围是否漂移"
    method: "对比色彩分布"
    pass_criteria: "在Palette Anchor范围内"
  
  footprint:
    check: "资产占格是否严格"
    method: "摆在网格上检查"
    pass_criteria: "无'偷半格'现象"
```

### 1.2 主美验收流程

```

│                                                          │
└──────────────────────────────────────────────────────────┘
```

### 2.2 质量评分标准

| 等级 | 分数 | 处理 | 说明 |
|------|------|------|------|
| **A** | 9.0+ | → approved/ | 完美，直接使用 |
| **B** | 8.0-8.9 | → approved/ | 优秀，可使用 |
| **C** | 7.0-7.9 | 视情况 | 需要评估是否返工 |
| **D** | <7.0 | → rejected/ | 不合格，必须重做 |

tile_seam_test:
  method: "把tile复制成3×3看接缝"
  
  pass_criteria:

    - "接缝处无断裂"

## 6. 自动化QC规则

### 6.1 可脚本化检查项

```yaml
automatable_checks:
  dimension:
    check: "尺寸是否符合规格"
    script: "读取图片尺寸，对比规格表"
    standards:
      tile_1x1: [1024, 1024]
      character_frame: [256, 256]
      portrait: [512, 512]
  
  background_color:
    check: "背景是否为键色"
    script: "检测四角和边缘像素是否为#00FF00"
    tolerance: "RGB各±2"
  
  stray_pixels:
    check: "轮廓外是否有杂点"
    script: "检测透明通道外的非键色像素"
  
  palette_compliance:
    check: "颜色是否在调色板范围"
    script: "提取图片颜色，与Palette对比"
    threshold: "色差ΔE≤10"
  
  pivot_position:
    check: "Pivot是否在正确位置"
    script: "检测底边最低点中心坐标"
```

### 6.2 QC脚本伪代码

```python
def qa_check_asset(image_path, spec):
    results = {}
    
    # 尺寸检查
    w, h = get_image_size(image_path)
    results['dimension'] = (w, h) == spec['size']
    
    # 背景检查
    corners = get_corner_pixels(image_path)
    results['background'] = all(is_key_color(p) for p in corners)
    
    # 杂点检查
    stray = count_stray_pixels(image_path)
    results['stray_pixels'] = stray == 0
    
    # 色域检查
    colors = extract_colors(image_path)
    results['palette'] = all(in_palette(c) for c in colors)
    
    # 计算得分
    score = calculate_score(results)
    grade = 'A' if score >= 9 else 'B' if score >= 8 else 'C' if score >= 7 else 'D'
    
    return {
        'results': results,
        'score': score,
        'grade': grade,
        'pass': grade in ['A', 'B']
    }
```

## 8. 问题分类与处理

### 8.1 常见问题分类

| 问题类型 | 严重度 | 处理方式 |
|----------|--------|----------|
| 视角偏差 | 高 | 返工 |
| 光向不一致 | 高 | 返工 |
| 背景不可抠 | 高 | 返工 |
| 有文字符号 | 高 | 返工 |
| 细节过多 | 中 | 评估/编辑修复 |
| 色相轻微漂移 | 中 | 评估/编辑修复 |
| 接缝轻微 | 中 | 评估/编辑修复 |
| 边缘杂点 | 低 | 脚本清理 |

### 8.2 返工标准

```yaml
rework_criteria:
  must_rework:
    - "视角明显偏差（>5°）"
    - "光向相反"
    - "背景有渐变无法抠"
    - "有文字或明显符号"
    - "尺寸不符合规格"
    - "动画帧基线差>3px"
  
  evaluate_first:
    - "细节密度不一致"
    - "色相漂移ΔE>5"
    - "接缝轻微可见"
    - "帧间轻微抖动"
  
  can_fix:
    - "边缘杂点（可脚本清理）"
    - "背景有少量脏色（可清理）"
    - "亮度轻微偏差（可调整）"
```
