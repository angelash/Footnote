# 资产生产流程图汇总

> 本文档包含所有资产类型的Mermaid流程图，可直接在支持Mermaid的编辑器/渲染器中查看。

---

## 1. 通用生产流程

```mermaid
flowchart TB
    subgraph Prepare["准备阶段"]
        A1["需求分析"] --> A2["查找或创建规格文件"]
        A2 --> A3["准备四张锚定图"]
        A3 --> A4{"确定模式"}
        A4 -->|"新资产"| A5["Generate模式"]
        A4 -->|"变体或序列"| A6["Edit模式"]
    end
    
    subgraph Generate["生成阶段"]
        B1["编写Prompt"] --> B2["输入锚定图和Prompt"]
        B2 --> B3["AI生成"]
        B3 --> B4{"满意?"}
        B4 -->|"否"| B5["调整Prompt或参数"]
        B5 --> B2
        B4 -->|"是"| B6["导出原始图"]
    end
    
    subgraph PostProcess["后处理阶段"]
        C1["抠图去背景"] --> C2["尺寸调整"]
        C2 --> C3["锚点对齐"]
        C3 --> C4["命名规范化"]
    end
    
    subgraph QC["QC验收"]
        D1["技术检查"] --> D2["视觉检查"]
        D2 --> D3{"通过?"}
        D3 -->|"否"| D4["返工"]
        D4 --> B1
        D3 -->|"是"| D5["归档入库"]
    end
    
    A5 --> B1
    A6 --> B1
    B6 --> C1
    C4 --> D1
    D5 --> E["更新规格文件状态"]
```

## 9. QC验收流程

```mermaid
flowchart TB
    subgraph TechCheck["技术检查-自动化"]
        T1["尺寸检查"] --> T2["格式检查"]
        T2 --> T3["透明度检查"]
        T3 --> T4["配色检查"]
        T4 --> T5["锚点检查"]
    end
    
    subgraph VisualCheck["视觉检查-人工"]
        V1["风格一致性"] --> V2["光照一致性"]
        V2 --> V3["无文字水印"]
        V3 --> V4["无AI伪影"]
    end
    
    subgraph AnimCheck["动画检查"]
        A1["基线稳定"] --> A2["头顶盒不越界"]
        A2 --> A3["循环衔接"]
        A3 --> A4["播放流畅"]
    end
    
    T5 --> V1
    V4 --> CHECK{"全部通过?"}
    A4 --> CHECK
    
    CHECK -->|"否"| REJECT["返工记录问题"]
    CHECK -->|"是"| APPROVE["验收通过"]
    
    APPROVE --> ARCHIVE["归档入库更新状态"]
    REJECT --> FIX["修复问题"] --> T1
```

## 使用说明

### 查看流程图

1. **VS Code**: 安装 "Markdown Preview Mermaid Support" 扩展
2. **GitHub**: 直接在仓库中查看，GitHub原生支持Mermaid
3. **在线工具**: 复制Mermaid代码到 [mermaid.live](https://mermaid.live)

### Mermaid语法注意

- 子图名称避免使用冒号，使用方括号包裹中文
- 节点文本使用双引号或方括号包裹
- 连线标签使用双引号包裹
