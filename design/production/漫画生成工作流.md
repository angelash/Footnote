## 一、流程总览

```
┌─────────────────────────────────────────────────────────────┐
│                     漫画生成闭环流程                          │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  Phase 1: 内容分析          Phase 2: 分镜设计                 │
│  ┌─────────┐               ┌─────────┐                       │
│  │ 章节拆分 │               │ 脚本编写 │                       │
│  │ 场景识别 │      →        │ 分镜规划 │                       │
│  │ 人物提取 │               │ 提示词生成│  ← 含对白/排版       │
│  └─────────┘               └─────────┘                       │
│                                  ↓                           │
│  Phase 4: 归档展示          Phase 3: 图像生成                 │
│  ┌─────────┐               ┌─────────┐                       │
│  │ 最佳筛选 │               │ 智绘生图 │  ← 一次出最终结果     │
│  │ 归档整理 │      ←        │ 质量审核 │                       │
│  │ 网页预览 │               │ 批量下载 │                       │
│  └─────────┘               └─────────┘                       │
│       ↓                                                       │
│  ┌─────────────────────────────────────────────────────┐     │
│  │              分章节循环，直到全部完成                  │     │
│  └─────────────────────────────────────────────────────┘     │
│                                                               │
└─────────────────────────────────────────────────────────────┘
```

### 核心要点

- **提示词给够**：对白、分镜、排版在提示词阶段全部确定
- **一次出图**：生成即最终结果，无需后期处理
- **4选1**：每页生成4张，AI筛选最佳1张归档
- **网页展示**：实时预览完成进度
- **闭环推进**：分章节循环直到全部完成

## 三、单话制作流程

### 3.1 Phase 1: 内容分析（约30分钟）

1. 阅读对应章节原文
2. 提取场景清单
3. 标注关键情节点
4. 输出：`ep{XX}-scene-analysis.yaml`

### 3.2 Phase 2: 分镜设计（约60分钟）

1. 规划页面数量和布局
2. 设计每页分格（含对白位置）
3. 编写完整提示词（含对白文字、排版要求）
4. 输出：`ep{XX}-prompts-full.md`

**提示词必须包含：**
- 画风锚定
- 主角描述
- 分格内容（逐格描述）
- 对白/旁白文字
- 排版要求

### 3.3 Phase 3: 图像生成（约120分钟）

1. 逐页提交提示词到智绘平台
2. 每页生成4张候选图
3. 截图确认完成
4. 提取URL并下载全部4张
5. 输出：`generated/ep{XX}/raw/`

**操作要点：**
- 串行提交，等完成再下一个
- 以截图为准，不看进度条
- 一次生成即最终结果（含对白排版）

### 3.4 Phase 4: 筛选归档（约30分钟）

1. 对每页的4张候选图进行评审
2. 选择最佳1张作为最终版
3. 移动到归档目录
4. 更新网页展示
5. 输出：`output/ep{XX}/`

**筛选标准：**
- 风格一致性
- 对白清晰度
- 构图完整性
- 人物准确性

## 四、网页展示系统

### 4.1 功能需求

- **章节导航**：按EP01、EP02...分章展示
- **页面预览**：每页最终选定的1张图
- **进度追踪**：显示完成/进行中/待开始状态
- **候选对比**：点击可查看该页4张候选图
- **阅读模式**：连续滚动阅读漫画

### 4.2 目录结构

```
comics/
├── output/
│   ├── ep01/
│   │   ├── page-01.webp    # 最终选定图
│   │   ├── page-02.webp
│   │   └── ...
│   └── ep02/
│       └── ...
├── viewer/
│   ├── index.html          # 主页面
│   ├── style.css           # 样式
│   └── data.json           # 进度数据
└── generated/              # 所有候选图（供对比查看）
```

## 八、提示词模板

### 8.1 基础结构

```
请生成一张[N]格漫画，[排列方式]排列，表现[主题]。

## 画风
赛博朋克科幻漫画风格，色彩深沉，霓虹蓝紫色点缀，
高质量数字绘画，线条清晰锐利。

## 主角
岑回：20多岁的亚洲男性，黑色短发整齐干练，
深邃疲倦的眼神，穿着灰色维修局制服，身材偏瘦。

## [N]格内容

格1（[镜头类型]）：[小标题]
- [具体画面描述]
- [人物动作/表情]

格2...

## 要求
- [N]格放在同一张图里
- 人物外形保持一致
```

### 8.2 布局选择

| 布局 | 适用场景 |
|------|----------|
| 全页单图 | 扉页、高潮、重要场景 |
| 四格横向 | 日常流程、对话 |
| 三格条状 | 戏剧张力、情感递进 |
| 六格 | 对话密集、快速推进 |

## 九、常见问题

### Q1: 生成卡住怎么办？
等待2分钟，以截图为准。有图就下载，没图标记重试。

### Q2: 部分图片失败？
下载成功的图片，继续下一任务。只有全部失败才重试。

### Q3: 风格不一致？
确保每次都包含完整的风格锚定词和主角描述。

### Q4: 如何下载图片？
使用 `browser_evaluate` 提取URL，然后用Python脚本批量下载。
禁止使用Windows MCP手动点击。
