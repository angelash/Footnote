# 第一部分：商业化设计

## 1. 商业化策略

### 1.1 定位分析

《备注》是一款**叙事驱动的单机H5游戏**，商业化设计需要平衡：
- 玩家体验完整性（不因付费割裂体验）
- 收入可持续性（支撑后续开发）
- 口碑传播需求（独立游戏依赖口碑）

### 1.2 推荐商业模式

```
┌─────────────────────────────────────────────────────────────┐
│                    混合变现模式                              │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│   免费体验区 (C0-C1)          付费解锁区 (C2-CF)             │
│   ┌─────────────────┐        ┌─────────────────┐           │
│   │  完整序章体验    │   →    │  完整版解锁      │           │
│   │  约2小时内容    │        │  ¥25-38 一次性   │           │
│   │  无任何限制     │        │                 │           │
```

## 2. 付费体验设计

### 2.1 免费版体验保证

| 承诺 | 说明 |
|------|------|
| **完整叙事** | C0-C1叙事完整，有意义的结束点 |
| **无广告** | 完全无广告打扰 |
| **无限时** | 无能量/次数限制 |
| **可存档** | 存档完整保留，付费后继承 |
| **无隐藏收费** | 付费点透明，一次解锁永久 |

### 2.2 付费后特权（无额外特权）

```
⚠️ 重要设计原则：

付费解锁≠付费特权

付费玩家和免费玩家（在解锁内容后）体验完全相同
不存在：
× 付费跳过
× 付费道具
× 付费皮肤
× 付费加速

这是叙事游戏的核心体验保证
```

### 2.3 退款政策

| 情况 | 政策 |
|------|------|
| 购买后未进入C2 | 全额退款 |
| 进入C2后24小时内 | 可退款（平台政策） |
| 超过24小时 | 不支持退款 |
| 赞助 | 不支持退款（明确告知） |

### 8.2 事件参数规范

```typescript
// 通用参数
interface IBaseEventParams {
  user_id: string;          // 用户ID
  session_id: string;       // 会话ID
  timestamp: number;        // 时间戳
  platform: string;         // 平台
  version: string;          // 游戏版本
  is_paid: boolean;         // 是否付费用户
}

// Zone事件参数
interface IZoneEventParams extends IBaseEventParams {
  zone_id: string;          // Zone ID
  chapter: string;          // 章节
  duration: number;         // 耗时（秒）
  r_value: number;          // R值
  p_value: number;          // P值
  w_value: number;          // W值
}

// 能力使用事件参数
interface IAbilityEventParams extends IBaseEventParams {
  ability_type: string;     // 能力类型
  zone_id: string;          // 使用Zone
  target_id?: string;       // 目标对象
  duration?: number;        // 使用时长（感知）
  result?: string;          // 结果
}

// 选择事件参数
interface IChoiceEventParams extends IBaseEventParams {
  dialogue_id: string;      // 对话ID
  choice_id: string;        // 选项ID
  choice_text: string;      // 选项文本
  r_change?: number;        // R值变化
  p_change?: number;        // P值变化
}

// 付费事件参数
interface IPurchaseEventParams extends IBaseEventParams {
  product_id: string;       // 商品ID
  price: number;            // 价格
  currency: string;         // 货币
  result: 'success' | 'cancel' | 'fail';
}
```

### 8.3 埋点实现

```typescript
// 数据上报服务
class AnalyticsService {
  private baseParams: IBaseEventParams;
  
  // 初始化
  init(userId: string): void {
    this.baseParams = {
      user_id: userId,
      session_id: this.generateSessionId(),
      timestamp: Date.now(),
      platform: this.detectPlatform(),
      version: __VERSION__,
      is_paid: this.checkPaidStatus(),
    };
  }
  
  // 通用上报
  track(event: string, params: Record<string, unknown>): void {
    const data = {
      ...this.baseParams,
      event,
      ...params,
      timestamp: Date.now(),
    };
    
    this.send(data);
  }
  
  // Zone进入
  trackZoneEnter(zoneId: string, chapter: string): void {
    this.track('zone_enter', { zone_id: zoneId, chapter });
  }
  
  // Zone完成
  trackZoneComplete(zoneId: string, duration: number, counters: ICounters): void {
    this.track('zone_complete', {
      zone_id: zoneId,
      duration,
      r_value: counters.R,
      p_value: counters.P,
      w_value: counters.W,
    });
  }
  
  // 能力使用
  trackAbilityUse(ability: string, zoneId: string, target?: string): void {
    this.track('ability_use', {
      ability_type: ability,
      zone_id: zoneId,
      target_id: target,
    });
  }
  
  // 选择追踪
  trackChoice(dialogueId: string, choiceId: string, rChange?: number): void {
    this.track('dialogue_choice', {
      dialogue_id: dialogueId,
      choice_id: choiceId,
      r_change: rChange,
    });
  }
  
  // 付费追踪
  trackPurchase(productId: string, price: number, result: string): void {
    this.track('purchase_complete', {
      product_id: productId,
      price,
      currency: 'CNY',
      result,
    });
  }
  
  // 结局追踪
  trackEnding(endingId: string, counters: ICounters, playtime: number): void {
    this.track('ending_reached', {
      ending_id: endingId,
      r_value: counters.R,
      p_value: counters.P,
      w_value: counters.W,
      total_playtime: playtime,
    });
  }
}
```

## 10. 隐私合规

### 10.1 数据收集原则

| 原则 | 说明 |
|------|------|
| **最小必要** | 只收集分析必需数据 |
| **匿名化** | 不收集可识别个人信息 |
| **透明告知** | 首次启动告知数据收集 |
| **可选退出** | 提供关闭数据收集选项 |

### 10.2 不收集的数据

```
× 真实姓名
× 手机号码
× 精确位置
× 通讯录
× 相册
× 设备唯一标识（使用可重置ID）
```
