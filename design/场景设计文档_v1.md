## 📌 场景设计总则

### 设计规格
| 参数 | 数值 | 说明 |
|------|------|------|
| **画布尺寸** | 750×1334px | 竖版基准 |
| **安全区域** | 690×1250px | 可交互区域 |
| **可滚动高度** | 最大2000px | 单场景最大纵向长度 |
| **格式** | SVG优先 | PNG像素风备选 |
| **图层数** | 3-5层 | 背景→中景→前景→装饰→UI |

### 视觉层级
```
Layer 5: UI层（对话框、HUD）
Layer 4: 前景装饰（近景物体、粒子）
Layer 3: 角色层（玩家、NPC）
Layer 2: 互动物体层（可交互物件）
Layer 1: 中景层（主要场景元素）
Layer 0: 背景层（天空、远景）
```

### 六大区域风格速查
| 区域 | 主色调 | 氛围词 | 特征元素 |
|------|--------|--------|----------|
| **居住环** | 暖橙+米白 | 日常、温暖、人味 | 灯光、植物、生活物品 |
| **市政环** | 冷蓝+金属灰 | 秩序、冷硬、流程 | 办公设备、表格、数据屏 |
| **档案巷** | 褐色+米黄 | 旧纸、尘封、密集 | 书架、地图、旧文件 |
| **诊疗台** | 白+淡绿 | 无菌、边界、压抑 | 医疗设备、白墙、绷带 |
| **礼堂街** | 紫+金 | 仪式、神秘、古旧 | 蜡烛、符号、祭坛 |
| **边缘断口** | 不定+强调色 | 异常、压力、扭曲 | 裂隙、畸变、深度格 |

#### 美术要点
```

2. 细节处理

   - 地板：几何纹理，整洁但单调
   - 身份卡：发光提示（可交互标记）

3. 伏笔埋点
   - 门牌101和103清晰，102号略模糊（F03前奏）
   - 公告日期与身份卡日期不一致
   - 走廊尽头有极淡的深度阴影
```
