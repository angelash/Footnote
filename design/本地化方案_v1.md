## 3. 本地化系统实现

### 3.1 I18n Manager

```typescript
// src/systems/i18n/I18nManager.ts
export class I18nManager {
  private _locale: string = 'zh-CN';
  private _texts: Record<string, unknown> = {};
  
  // 设置语言
  async setLocale(locale: string): Promise<void> {
    this._locale = locale;
    await this._loadLocaleData(locale);
    eventBus.emit('locale:changed', locale);
  }
  
  // 获取文本
  t(key: string, params?: Record<string, string>): string {
    const value = this._getNestedValue(this._texts, key);
    
    if (typeof value !== 'string') {
      console.warn(`Missing translation: ${key}`);
      return key;
    }
    
    // 替换参数
    if (params) {
      return value.replace(/\{(\w+)\}/g, (_, k) => params[k] || `{${k}}`);
    }
    
    return value;
  }
  
  // 获取当前语言
  getLocale(): string {
    return this._locale;
  }
  
  // 获取支持的语言
  getSupportedLocales(): string[] {
    return ['zh-CN', 'en', 'zh-TW'];
  }
  
  // 加载语言数据
  private async _loadLocaleData(locale: string): Promise<void> {
    const [ui, cards, system] = await Promise.all([
      import(`@/data/locales/${locale}/ui.yaml`),
      import(`@/data/locales/${locale}/cards.yaml`),
      import(`@/data/locales/${locale}/system.yaml`),
    ]);
    
    this._texts = {
      ui: ui.default,
      cards: cards.default,
      system: system.default,
    };
  }
  
  // 获取嵌套值
  private _getNestedValue(obj: unknown, path: string): unknown {
    return path.split('.').reduce((o, k) => (o as Record<string, unknown>)?.[k], obj);
  }
}

export const i18n = new I18nManager();
```

### 3.2 使用示例

```typescript
// 在代码中使用
import { i18n } from '@/systems/i18n';

// 简单文本
```

### 4.3 风格指南

#### 中文风格
- 简洁、克制
- 避免网络流行语
- 保持神秘感
- 系统语气冷静、不带情感

#### 英文风格
- Concise, restrained
- Avoid colloquialisms
- Maintain mystery
- System voice is cold, emotionless

#### 翻译原则

1. **意译优先**：传达意思比字面翻译重要
2. **保持语气**：每个角色有独特说话风格
3. **一致性**：同一术语始终使用同一翻译
4. **文化适应**：必要时调整文化特定表达

## 5. 翻译流程

### 5.1 工作流程

```
1. 提取文本
   └── 使用脚本提取所有待翻译文本
   
2. 翻译
   └── 翻译人员按照术语表和风格指南翻译
   
3. 校对
   └── 不同人进行校对，检查准确性和一致性
   
4. 测试
   └── 在游戏中测试，检查显示和上下文
   
5. 修正
   └── 根据测试反馈修正翻译
   
6. 发布
   └── 合并到主分支
```

## 附录：语言配置

### 语言检测

```typescript
// 自动检测用户语言
function detectLocale(): string {
  const browserLang = navigator.language;
  
  if (browserLang.startsWith('zh')) {
    return browserLang.includes('TW') || browserLang.includes('HK') 
      ? 'zh-TW' 
      : 'zh-CN';
  }
  
  if (browserLang.startsWith('ja')) {
    return 'ja';
  }
  
  return 'en';
}
```
