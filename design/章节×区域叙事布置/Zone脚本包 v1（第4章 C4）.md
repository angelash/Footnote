# Zone脚本包 v1（第4章 C4）

## 本章新增交互与UI约定（竖版H5可实现）

### A) 时间堆栈按钮（右侧小按钮）

* 位置：屏幕右侧中部（竖版单手拇指可点）
* 图标：小“卡片叠层”+ 轻微波纹
* 点击展开：出现  **3–5 张节点卡片** （竖向滑动浏览）

### B) 节点卡片（Time Node Card）

每张卡包含：

* 缩略截图（当前Zone的静帧即可）
* 节点标题（地点+事件短名）
* 节点标识（不写数字，用“刻度点”表示层级；后期再与病例编号呼应）
* 回溯提示（例如：`回溯将增加应力`）

### C) 回溯确认（防误触）

* 点击某节点 → 弹确认浮层：
  * 标题：`时间干预（回溯）`
  * 警告1：`回溯不会抹去深度伤痕。`
  * 警告2：`将增加解释成本。`
  * 按钮：`按住确认 1 秒 / 取消`

### D) “时间应力”表现（不显示数值）

* UI表现：时间堆栈按钮周围波纹加重、卡片边缘轻微错位、偶尔出现极短空白字段闪（别频繁）
* 隐藏变量：仍用 `P` 代表总观察者压力（含时间与深度）

## C4-Z1｜坍塌后的生活区（重访）｜生活→灾后漂移

 **目标时长** ：8–12分钟

 **类型** ：生活 / 重访反馈（低压但不安）

 **出场** ：住户NPC 2–3名（无名即可），（可选：栖蓝远景）

### 1）玩家目标

* 抵达指定巡查点（流程）
* 可选：安抚/帮助一位住户（无收益R机会点）

### 2）场景与交互点

* 同一片生活区地图（C0/C1曾路过的局部），但加入灾后变化：
  1. **封锁胶带** （可长按查看“日期”）
  2. **半塌的墙角** （深度视野下能看见“骨架缺口”）
  3. **争执的住户A/B** （对话）
  4. **临时公告板** （可收集）

### 3）流程脚本

1. 玩家进入区域 → 看到封锁线与修补痕迹
2. A说：“昨天你来过。”

   B说：“他昨天根本没出现。”

   （不需要解释，让矛盾自己刺）
3. 玩家可选择：

   * 直接走（推进主线）
   * 帮A把散落的东西归整（无奖励、R+1）
4. 深度视野提示：塌墙内部出现“被折过的骨架线”（为后续时间补丁一致性铺垫）

### 4）短对话（住户）

* 住户A：“你昨天在这儿站了很久。”
* 住户B：“别胡说，昨天封锁线都没拉。”
* 岑回内心（短）：
  * “他们说的是同一天吗？”

### 5）可收集物

**卡片AB：临时公告（灾后版）**

* 内容：
  * “封锁范围：已更新。”
  * “请以最新更正为准。”（F03余波）
* 长按细节：封锁日期存在轻微涂改痕迹（不用写明“对齐”，只让玩家看到不干净）

### 6）伏笔投放

* 强化“记忆漂移/叙述互斥”
* 深度视野下“骨架缺口”形态与后续回溯补丁一致（F13前奏）

### 7）结算

* 玩家可见结算卡：
  * “区域：可通行（暂时）”
* 隐藏结算：
  * 若帮助住户归整：`R += 1`，`FLAG_HELPED_RESIDENT = true`

## C4-Z2｜维修局：时间节点界面上线｜系统授信（解锁时间干预）

 **目标时长** ：10–14分钟

 **类型** ：生活/教学（时间堆栈UI）

 **出场** ：顾临、校准员（可选）

### 1）玩家目标

* 解锁【时间干预：回溯节点】
* 学会打开时间堆栈、浏览节点卡、进行一次“安全演示回溯”

### 2）场景与交互点

* 校准室（与C2-Z1类似但更冷）
* 交互点：
  1. **时间堆栈按钮（新UI）**
  2. **演示台：掉落的螺丝** （用于演示回溯）
  3. **授权终端**

### 3）流程脚本（必须可控、低风险）

1. 顾临对话：给“最后权限”但强调代价
2. 系统弹教学浮层（一次就够）：
   * “点击右侧【时间堆栈】查看节点。”
   * “回溯将增加解释成本。深度伤痕不会抹去。”
3. 演示：玩家点击桌面让一枚螺丝滚落桌下（自动事件）
4. 玩家需要打开时间堆栈，选择“刚才·螺丝未掉落”节点 → 按住确认回溯
5. 螺丝回到桌面，但桌角会留下极淡“擦痕”（补丁痕迹雏形）
6. 授权终端亮起 → 完成

### 4）对话脚本（顾临）

* “你会想用它纠正错误。”
* “别。”
* “你能做的，只是把错误搬到别处。”

玩家选项：

1. “那给我它有什么意义？”
2. “如果我救得了人呢？”
3. “我只会在必要时用。”

顾临回应：

* 对1：“意义不是系统给的。”（这句为方案三埋根）
* 对2：“救援优先，但账会变厚。”
* 对3：“希望你说到做到。”

### 5）可收集物

**卡片AC：授权记录（时间干预）**

* 内容：
  * 权限：回溯至稳定节点
  * 警告：`回溯不会抹去深度伤痕`
  * 备注：`解释成本：上升（已更正）`

**卡片AD：演示回执**

* 内容：
  * “回溯已执行。”
  * “遗留：擦痕（不可归因）”  ← 这句很关键：补丁痕迹不是“事件原因”，是“自洽代价”。

### 6）伏笔投放

* **F13（补丁一致性）**开始有“统一语言”：遗留/擦痕/不可归因
* 方案三语句：顾临说“意义不是系统给的”（后期回收炸裂）

### 7）结算

* 玩家可见结算卡：
  * “能力：时间干预 已上线。”
* 隐藏结算：
  * `FLAG_TIME_INTERVENTION_UNLOCKED = true`
  * `P += 0`（演示回溯不加P，避免玩家一上来就负担过大）

## C4-Z3｜边缘断口：第一次必须回溯的事件｜因果失稳（强教学）

 **目标时长** ：14–20分钟（本章核心）

 **类型** ：因果失稳 / 强制回溯 / 补丁一致性（F13）

 **出场** ：岑回、顾临远程（可选）、现场NPC 1名（可选）

### 1）玩家目标

* 首次遭遇“当前时间线必失败”事件
* 使用时间堆栈回溯一个节点并成功完成目标
* 明确体验：**回溯≠清空后果，世界会“带脏”**

### 2）场景与交互点

* 断口通道（三段）
* 交互点：
  1. **阈值门（必须通过）**
  2. **警报线圈（触发事件）**
  3. **坍塌点（第一次尝试必封死）**
  4. **回溯节点触发点** （系统自动生成）
  5. **补丁痕迹点（回溯后出现）**

### 3）事件结构（确保玩家理解“必回溯”）

**第一次尝试（必失败但不GameOver）**

1. 玩家触发警报线圈 → 倒计时开始（UI不要数字，用“红色脉冲条”）
2. 玩家跑到坍塌点 → 路被封死
3. 系统提示：
   * “路径不可达。”
   * “建议：选择稳定节点。”

此时强制引导玩家打开时间堆栈。

**回溯后（成功但带补丁）**

1. 玩家回溯到“警报未触发”的节点
2. 同一路径仍然存在  **之前深度写入留下的裂纹/擦痕** （若玩家在C3-Z2或C3-Z7有介入，这里必须可见）
3. 玩家用“未来知识”绕开警报线圈（例如先关闭一个小开关）
4. 成功通过阈值门

### 4）“补丁一致性”（F13）的呈现方式

回溯后，在通道墙面出现一条小小的“补丁标记”（比如一小块不同材质/纹理），而且它的形状与C4-Z2演示的“擦痕”类似。

玩家不用理解，只会觉得：“每次回溯都会留下这种东西。”

### 5）短文本/提示

* 系统提示（回溯前）：
  * “路径不可达。”
  * “建议：稳定节点。”
* 系统提示（回溯后）：
  * “已执行回溯。”
  * “遗留：补丁痕迹。”
* 岑回内心：
  * “我回来了……但墙没有恢复。”

### 6）可收集物

**卡片AE：节点卡片回执-01**

* 内容：
  * 节点：`断口·警报前`
  * 回溯：已执行
  * 遗留：`补丁痕迹`（统一词汇，后续反复出现）

**卡片AF：断口记录-02（回溯后版本）**

* 内容：
  * “同一路径在不同尝试中表现不同。”
  * “自洽修补：已发生（不可归因）”

### 7）伏笔投放

* **F13 正式建立** ：补丁痕迹“统一语言”出现
* 强化“深度伤痕不可回滚”体验（方案三与v2世界观的硬基础）

### 8）结算

* 玩家可见结算卡：
  * “你通过了阈值门。”
  * “代价：解释成本上升。”（不写数值）
* 隐藏结算：
  * `P += 3`（首次真实回溯）
  * `FLAG_TIME_PATCH_MARK_SEEN = true`

## C4-Z4｜诊疗台：病例卡2（对账序列暴露）｜因果失稳

 **目标时长** ：10–12分钟

 **类型** ：生活/信息/对账线索（F14强化）

 **出场** ：许澄

### 1）玩家目标

* 获得病例卡-02
* 让玩家第一次意识到：**病例编号与节点卡的标识存在呼应**

### 2）场景与交互点

1. **问诊台**
2. **“回溯后症状”选择** （新选项出现）
3. **病例卡领取点**
4. **（可选）展示节点卡片给许澄** （触发隐藏台词）

### 3）流程脚本

* 玩家选择症状时会出现新项：
  * “事件重复感增强”
  * “解释变得费力”
  * “对某些‘补丁痕迹’敏感”
* 许澄给出比以前更“系统化”的提醒（但仍温柔）
* 领取病例卡-02：编号结构更像对账序列（但仍保留空块）

### 4）许澄对话（关键）

* “你开始把‘修补’看见了。”
* “看见它，会让它变得更难隐藏。”
* “你可以不说，但别骗自己：你确实回去了。”

若玩家选择“展示节点卡片回执-01（AE）”给她看：

* 她会停顿一下（用省略号或空白气泡表现），然后说：
  * “这不是给人看的格式。”
  * “你从哪里拿到的？”

> 这句是第三层（高维格式）进入玩家世界的前奏，但仍不提“高维文明”。

### 5）可收集物

**卡片AG：病例卡-02**

* 编号示例：`MC-◦◦-断口`（用刻度点而不是数字）
* 内容：
  * 结论：`建议：减少回溯`
  * 注记：`补丁痕迹敏感性↑`
  * 末尾极淡：`对齐：待定`

### 6）伏笔投放

* **F14 强化** ：编号结构与节点“刻度点”呼应
* 为后续终局“格式覆盖/字段新增”做“这不是给人看的格式”预告

### 7）结算

* 玩家可见结算卡：
  * “你拿到第二张病例卡。”
* 隐藏：`FLAG_MED_CARD_02 = true`

## C4-Z5｜阿棠碎片日记2｜因果失稳（“你已经回去过”）

 **目标时长** ：8–12分钟

 **类型** ：生活/叙事/情绪推力

 **出场** ：阿棠（主）、（可选）许澄远景

### 1）玩家目标

* 获得碎片日记-02
* 引导玩家产生一种感觉：
  > “也许我还没解锁时间，就已经在别处回溯过。”
  >
  > （不是事实陈述，是情绪体验）
  >

### 2）场景与交互点

1. **走廊长椅** （坐下触发）
2. **阿棠的纸条** （可拾取）
3. **窗边的补丁痕迹** （长按可看，与C4-Z3一致）

### 3）对话脚本（阿棠）

* “你这次回来得更快。”
* “你每次回来，墙上都会多一条‘不属于任何原因’的痕。”
* “我以前以为只有我看得见。现在你也看得见了。”

玩家选项：

1. “你怎么知道我回去了？”
2. “你到底记得多少？”
3. “你害怕吗？”

阿棠回应（短）：

* “我不怕。我只是累。”
* “累的是他们一直把我更正成同一个答案。”

> 这句会和第5章许澄“疗程抹平差异”形成闭环。

### 4）可选无收益任务（R机会点，强烈建议）

阿棠请求一件完全没奖励的事：

* “帮我把这张纸条塞回墙缝里。”

  理由：
* “如果我不这么做，我会怀疑它从没存在过。”

完成后结算只有一句：

* “无可用收益。”（这是为C4-Z6的强判词做前奏）

### 5）可收集物

**卡片AH：碎片日记-02**

* 内容：
  * “补丁痕迹不是错误，是对账。”
  * “对账的人不在这里。”

（“对账的人不在这里”是第三层存在的强暗示，但仍不落俗）

### 6）伏笔投放

* 强化F13（补丁一致性）与方案三的“格式不是给人看的”方向
* 无收益判词开始频繁出现（但仍分散）

### 7）结算

* 玩家可见结算卡：
  * “你得到了一段更难承受的确定。”
* 隐藏结算：
  * 若完成塞回纸条：`R += 2`，`FLAG_HELPED_ATANG_PAPER = true`

## C4-Z6｜栖蓝：无人需要的地图｜生活（强无收益 + F21前奏）

 **目标时长** ：10–14分钟

 **类型** ：生活/无收益（核芯推进）

 **出场** ：栖蓝

### 1）玩家目标

* 帮栖蓝把一张“没人会看的地图”贴回墙上
* 系统第一次用更冷的方式评价：**“无可用收益”**并带“结算口吻”

### 2）场景与交互点

1. **破墙面（贴图位置）**
2. **地图卷（可展开滑动）**
3. **糨糊/胶水**
4. **压平工具**
5. **完成确认点**

### 3）流程脚本

1. 栖蓝把地图递给你
2. 玩家可展开地图：上面标了许多“已不存在的巷子/房间”
3. 玩家完成三步：抹胶 → 贴上 → 压平
4. 系统弹出结算卡（关键句）

### 4）栖蓝对话（方案三核心台词之一）

* “这张地图没用。”
* “可我不想让它消失得那么轻松。”
* “你贴上去，它就得费点力气才能被抹掉。”

玩家选项：

1. “你在跟谁较劲？”
2. “我帮你。”
3. “它会被撕掉的。”

栖蓝回应：

* 对3：“那就让撕掉变成一个动作，而不是一句更正。”

> 这句非常重要：它把“意义 vs 计算”落到“动作成本”上，玩家会懂。

### 5）系统判词（F21前奏，注意力度）

完成后结算卡不要写太长，只要一句冷的：

* “结算：无可用收益。”

  然后 **补一行极短的小字** （0.5秒后淡出）：
* “该行为无法纳入当前模型。”

这行小字就是方案三的“模型”词第一次登场，但用一次就够，别滥用。

### 6）可收集物

**卡片AI：无人需要的地图（贴墙版）**

* 内容：地图缩略图 + 一行注记：
  * “已贴回。”
  * “结算：无可用收益。”
* 长按细节：角落有“版本号”但被涂抹（呼应宋岚版本库）

### 7）伏笔投放

* **F21 前奏** （“模型/无意义”方向第一次明确露面）
* 为终局“无收益残差阈值触发”做硬铺垫
* 为C5“系统无法收敛”抬压

### 8）结算

* 玩家可见结算卡：如上
* 隐藏结算：
  * `R += 2`
  * `FLAG_MAP_PASTED = true`

## C4-Z8｜市政环：顾临的限制｜冲突（权限收紧）

 **目标时长** ：10–14分钟

 **类型** ：冲突/制度压力/角色转折

 **出场** ：顾临（主）、市政职员（可选）

### 1）玩家目标

* 接收新的限制：深度介入权限被“暂挂审核”（不彻底禁用，但在部分区域禁用）
* 让玩家感到：系统压力在上升，你的选择空间在被收敛

### 2）场景与交互点

1. **市政走廊（严肃氛围）**
2. **顾临对话点**
3. **权限面板（展示：介入在部分场景会变灰）**
4. **离开点**

### 3）流程脚本

1. 顾临开场先安抚，再宣布限制
2. UI演示：深度视野下【介入】按钮在一处测试点变灰，并提示：
   * “写入权限：待审”
3. 玩家可选回应（影响后续顾临态度与台词，但不阻塞流程）

### 4）顾临对话（本章角色推进重点）

* “你用得太频繁了。”（若玩家C3介入多则触发，否则换成“你碰过它。”）
* “解释成本上升得太快。”
* “我不是在惩罚你。”
* “我是让这座城还能继续被读下去。”

玩家选项：

1. “你怕什么？”
2. “我救了人。”
3. “你是在替谁说话？”

顾临回应（务必克制，不揭底）

* 对2：“我知道。所以我才更怕。”
* 对3：“我只替记录说话。”（这句回收会很爽：他是收敛主义者）

> 如果 `P` 已经很高（玩家介入+回溯用得多），让顾临出现一次轻微“卡顿”表现：
>
> 他的一句台词中间插入一个短空白气泡“……”然后继续。不要解释。

### 5）可收集物

**卡片AK：权限变更通知**

* 内容：
  * “写入权限：暂挂审核”
  * “原因：解释成本超阈值”
  * “建议：减少干预”

### 6）伏笔投放

* 第二层“收敛机制”压强明显
* “还能继续被读下去”直接把 v2 的“表示/可读性”核心推到台前（但仍不揭终局）

### 7）结算

* 玩家可见结算卡：
  * “权限收紧。”
  * “你仍然能选择，但会更难。”
* 隐藏结算：
  * `FLAG_INTERVENTION_RESTRICTED = true`
  * `W`（世界可读性）可根据玩家行为微调（内部用）
