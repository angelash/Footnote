下面是《断层平面》 **章节×区域（Zone）叙事布置表 v1（方案三整合版）** 。

它的目标是： **把 10–12 小时内容拆成竖版 H5 能承载的“短回合区域”，并把浅伏笔/深伏笔/终局回收点逐格标上** 。

> 阅读方式：

* **每个 Zone** 设计成竖版 H5 单次 5–10 分钟可完成的小地图（可滚动/分屏切换）。
* 主线约  **45 个 Zone** （≈7–9 小时），再加  **12 个重返变体** （≈3–4 小时）组成 10–12 小时体验。
* 你会看到每章都在推进：

  **理解 → 决策 → 后果** ，并逐步抬升到方案三的“无收益行为残差 → 模型无法收敛 → 对视/降阶”。

## 0) 全局“区域骨架”（便于后续扩写）

城市分 6 个大区（每区可反复重访，状态变化很明显）：

1. **居住环** ：日常/喘息/人味（栖蓝支线主要在这里发芽）
2. **市政环** ：秩序与流程（顾临主场，“收敛语法”最强）
3. **档案巷** ：版本差异与地图（宋岚主场，“表示”线索密集）
4. **诊疗台** ：对齐与症状（许澄/阿棠主场，“账本”线索密集）
5. **礼堂街** ：平面信仰与隐喻（牧平主场，“神话保存技术残响”）
6. **边缘断口** ：结构异常与高维压力（深度/时间系统教学与升级）

## 1) 隐藏进度条（作者用，不直给玩家）

为承载方案三，建议暗中记录三个全局量（不在 UI 明示，仅通过反馈体现）：

* **R：无收益残差** （完成“无奖励/不为效率”的选择增长）
* **P：观察者压力** （使用深度介入/时间干预增长）
* **W：世界可读性** （综合稳定度，影响结局走向）

阈值建议（可调）：

* **R ≥ 3** ：系统语气开始出现轻微“无法归类”的停顿（埋 F11/F21 的前奏）
* **R ≥ 6** ：首次出现系统判定句（弱版 F21）
* **R ≥ 10** ：终局“模型改写”路径开启（强版 F21→F23链条）

## 序章（C0）｜0.5h｜“一切都正常”

 **目标** ：让玩家先把它当成普通 2D 叙事冒险来玩；埋“现实不可靠”的浅伏笔。

1. **C0-Z1｜宿舍走廊｜生活**

* 焦点：2D移动/交互
* 角色：岑回（自述）
* 内容：取工具包→出门巡检；墙上公告的日期与个人证件细节略冲突（不解释）
* 伏笔：F03（提示自我更正的第一次极轻闪）、浅层身份缝线
* R/P：无

2. **C0-Z2｜早餐小店｜生活**

* 角色：栖蓝（路过不点名）、店主
* 内容：玩家可选择点“固定菜单”(效率)或点“没人点的菜”(无收益)
* 伏笔：埋“无收益选择”体验但不提示（R+1 若选无收益）
* R/P：R机会点①

3. **C0-Z3｜薄墙巷口｜生活→异常微光**

* 内容：长按墙体听回声；但系统提示说“结构正常”
* 伏笔：F01（薄墙回声）、F03（系统纠偏口吻雏形）
* R/P：无

4. **C0-Z4｜维修局前台｜生活**

* 角色：顾临首次登场
* 内容：他用“流程式温柔”派任务；强调“能用流程解决就别用例外”
* 伏笔：顾临的“结算/阈值”口癖极轻埋点（未来回收）
* R/P：无

## 第5章（C5）｜2h｜“无法收敛的世界”（系统冲突升级）

 **目标** ：第二层（收敛引擎）露出马脚；第三层通过“格式变化/字段新增/冗余信息”显影。

1. **C5-Z1｜档案巷：版本冲突现场｜冲突**

* 角色：宋岚
* 内容：同一区域出现两个互斥版本；玩家必须选择保留哪个（无完美）
* 伏笔：F11强化、F12回收（自相似结构更明显）
* R/P：选择“保留更有人味但更不稳定”的版本可给R+1

2. **C5-Z2｜市政环：纠偏中心外围｜冲突**

* 角色：顾临
* 内容：系统提示开始像“对账引擎”而非人类 UI
* 伏笔：F13回收（补丁一致性）、F11持续出现
* R/P：P+（若玩家强行回溯/介入）

3. **C5-Z3｜诊疗台：许澄的抉择｜冲突（道德系统化）**

* 内容：许澄给你“稳定疗程”（降低异常但抹掉差异）或拒绝
* 伏笔：方案三核心伦理：意义是否需要被“治疗掉”
* R/P：拒绝疗程（无收益、变难）R+2

4. **C5-Z4｜礼堂街：牧平的“页背风暴”｜生活→预言回收**

* 内容：牧平说“纸背的风在变大”，并指出你带来的“多余墨量”
* 伏笔：F15回收触感增强；终局句型前置高潮
* R/P：无

5. **C5-Z5｜栖蓝：空椅子的消失与归来｜生活→系统显影**

* 内容：某次纠偏后椅子被抹去；若R足够高，玩家可通过坚持把它“留回来”
* 伏笔：F23前奏（非最优开始争取被保存）
* R/P：R+2（强）

6. **C5-Z6｜边缘断口：审计样式的界面覆盖（不出现高维角色）｜冲突（第三层显影）**

* 内容：界面短暂出现“非人类字段表/空字段/缺字字段名”
* 伏笔：F11/F21进入主舞台
* R/P：P+（回溯/介入都加）

7. **C5-Z7｜“此行为无意义”第一次明确出现｜过渡节点**

* 触发：R≥6 或完成指定无收益链
* 内容：系统结算卡直接判定
  > “此行为在当前模型中无意义。”
  >
* 伏笔：F21正式出现
* R/P：无（这是判定点）

## 终章（CF）｜1–2h｜“对视与模型改写”

 **目标** ：不是揭露阴谋，而是 **尺度失配事件** ：系统被迫降阶，世界出现永久“多余字段”。

1. **CF-Z1｜模型边界：冗余字段区（UI无法关闭）｜冲突**

* 内容：UI出现无法关闭的空白字段块（玩家会焦躁）
* 伏笔：F22
* R/P：无

2. **CF-Z2｜最后的无收益选择（主动证明）｜生活→终局机制**

* 内容：给玩家一个彻底“不利于通关”的选择（救一个“记录里不存在的人/保留一个注定被抹的细节”）
* 触发：若玩家做了 → 进入模型改写线
* 伏笔：F21强化
* R/P：R+2

3. **CF-Z3｜尺度失配：格式覆盖（对视）｜终局事件**

* 内容：不出现“高维文明角色”；只通过“格式/字段/结算结构”变化让玩家感到“被观察/对视”
* 伏笔：第三层显影完成
* R/P：无

4. **CF-Z4｜世界首次保存非最优解｜终局后果**

* 内容：栖蓝的椅子/路标/地图中至少一个“原本会被纠偏抹掉”的物件被永久保留
* 伏笔：F23回收
* R/P：无

5. **CF-Z5｜三结局选择（A/B/C）｜结算**

* A：平面稳定（收敛继续，但多余字段已存在）
* B：真实释放（表示松动，涌现回归）
* C：成为系统（你成为“新字段承载者/运行时桥接”）
* 伏笔回收：F11/F12/F13/F14/F15 都能在结算中各自对齐一条“原来如此”

6. **CF-Z6｜尾声重访：每个阵营一句话变化｜余韵**

* 顾临：第一次承认“稳定之外仍存在”
* 宋岚：版本差异不再被完全删改
