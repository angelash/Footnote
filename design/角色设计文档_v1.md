## 📌 角色设计总则

### 设计原则
```
1. 性格可视化 - 外观即性格的延伸
2. 世界观一致 - 符合"收敛运行时"美学
3. 可辨识性 - 剪影独特，一眼可认
4. 状态表达 - 支持多种情绪/压力状态变体
5. 像素适配 - 高清立绘与像素精灵风格统一
```

### 通用规格
| 资产类型 | 尺寸 | 格式 | 说明 |
|----------|------|------|------|
| 全身立绘 | 400×800 | SVG/PNG | 用于对话、详情 |
| 头像 | 200×200 | SVG/PNG | 用于对话框 |
| 像素精灵 | 32×48 (×4=128×192) | PNG | 用于场景 |
| 特写 | 600×800 | SVG/PNG | 用于CG/关键时刻 |

### 色彩规范
```
每角色定义:
- 主色: 代表角色核心特质
- 辅色: 衬托/对比
- 强调色: 高光、能力、情绪

全局约束:
- 饱和度: 中等偏低（符合整体美学）
- 明度: 深色为主，强调色亮
- 禁止: 大面积纯白、荧光色过多
```

### 1.5 状态变体

#### 常态
```
整体: 标准、克制
服装: 整洁工作服
表情: 平静
特效: 无
```

#### 压力态（P值高）
```
整体: 略显紧张
服装: 衣角有皱褶
表情: 眉头微皱，有汗
特效: 身体边缘有微弱抖动线
强调色: 边缘有淡淡红光
```

#### 觉醒态（使用能力时）
```
整体: 锋芒显现
服装: 不变
表情: 目光锐利
特效: 眼睛发出#00F5D4青光
      身体周围有深度波纹
```

#### 终局态（CF章节）
```
变体A (承载字段):
- 身体部分呈现数据化
- 边缘有格式符号流动
- 眼睛变为#A855F7紫色

变体B (释放表示):
- 轮廓略微模糊
- 周围有涌现粒子
- 表情更放松但带困惑

变体C (继续收敛):
- 更加标准化
- 颜色更统一
- 表情完全平静
```

### 2.5 特殊状态

#### 卡顿态（C5）
```
表现:
- 表情突然静止
- 身体姿势僵硬
- 眼睛出现微弱的数据闪烁
- 动作有0.2秒延迟
- 说话时偶尔"跳帧"

视觉特效:
- 身体边缘有轻微数字噪点
- 背景出现"加载中"的隐晦暗示
```

#### 系统化变体（重返场景）
```
如果玩家选择特定路线:
- 顾临外观更加"数据化"
- 衣服图案变成格式符号
- 眼睛变为#4A90A4恒定发光
- 说话方式完全变成系统语气
```

### 5.4 动画特殊处理
```
idle动画:
- 不是简单的呼吸，而是"漂移"

- 轮廓边缘抖动
- 偶尔出现"对不齐"效果

walk动画:
- 移动时身体略微拉伸/压缩
- 留下半透明残影
- 脚步不完全接触地面

消散效果:
- 从边缘开始像素化散开
- 颜色变淡
- 最后只剩轮廓，然后消失
```
