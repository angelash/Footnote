# 场景设计规范

## 整体风格
- **风格**: 像素风竖版场景
- **尺寸**: 750×1334px
- **比例**: 9:16 竖屏
- **美学**: 赛博朋克 + 系统化世界观

---

## 六大区域风格

### 1. 居住环
```
氛围: 日常/喘息/人味
色调: 暖灰色系，偶有暖光
元素: 宿舍、小店、走廊、修补痕迹
光源: 室内暖光、窗外冷光
特殊: 栖蓝的修补痕迹
```

### 2. 市政环
```
氛围: 秩序/流程/机械
色调: 冷灰 + 科技蓝
元素: 办事厅、表格、公告屏、排队栏
光源: 荧光灯、显示器光
特殊: "已更正"标记随处可见
```

### 3. 档案巷
```
氛围: 版本差异/历史痕迹
色调: 棕色/米色/旧纸
元素: 地图摊、版本库、折叠楼梯、旧书架
光源: 油灯、透过窗的光
特殊: 同一地点的多版本叠影
```

### 4. 诊疗台
```
氛围: 对齐/症状/不安
色调: 白色 + 淡蓝 + 警示红
元素: 候诊区、问卷、病例卡、医疗设备
光源: 医疗灯、显示器
特殊: 被覆盖的答案痕迹
```

### 5. 礼堂街
```
氛围: 神话/隐喻/仪式
色调: 深色 + 金色点缀
元素: 讲堂、祷文、蜡烛、祭坛
光源: 烛光、神秘光源
特殊: 首字链暗示
```

### 6. 边缘断口
```
氛围: 异常/高维压力/危险
色调: 深空黑 + 荧光绿/红
元素: 封锁线、裂纹、断裂结构、警告标识
光源: 荧光、裂缝光
特殊: 深度线框可见、维度裂痕
```
