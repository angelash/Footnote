# AI生图提示词模板库

## 核心风格约束

所有提示词必须包含以下核心元素：

```
【必选约束】
pixel art style              # 像素风格
cyberpunk aesthetic          # 赛博朋克美学
no text, no watermark        # 无文字无水印

【可选约束】
transparent background       # 透明背景（角色/物件/特效）
dark background              # 深色背景（场景）
vertical composition         # 竖版构图（场景）
front facing                 # 正面朝向（角色）
```

## 质量检查清单

生成后必须验证：

- [ ] **风格一致**: 像素风 + 赛博朋克
- [ ] **朝向正确**: 角色正面/3/4侧面
- [ ] **背景处理**: 透明或深色（按需求）
- [ ] **无文字**: 图片中没有文字
- [ ] **无水印**: 没有AI工具水印
- [ ] **表情匹配**: 实际表情与命名一致
- [ ] **尺寸正确**: 符合规格要求
- [ ] **色调统一**: 符合区域/角色配色
