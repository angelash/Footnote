# 特效设计规范

## 整体风格
- **风格**: 像素风特效
- **背景**: 透明
- **色调**: 荧光色为主（青/红/金）
- **形式**: 单帧或序列帧

---

## 三大能力特效

### 1. 深度感知（Depth Perception）
```
触发: C2解锁，长按激活
视觉效果:
  - 青色发光圆环
  - 同心圆波纹扩散
  - 线框轮廓叠加
  - 空腔区域高亮
持续: 激活期间保持
色彩: 荧光青 (#00FFAA)
```

### 2. 深度介入（Depth Intervention）
```
触发: C3解锁，确认写入
视觉效果:
  - 写入点发光爆发
  - 结构裂纹生成
  - 粒子飘散
  - 伤痕纹理
持续: 0.5-1秒
色彩: 青色 → 渐变白色
```

### 3. 时间干预（Time Intervention）
```
触发: C4解锁，选择节点回溯
视觉效果:
  - 时钟齿轮旋转
  - 画面倒带效果
  - 色彩红移
  - 时间线闪烁
持续: 1-2秒
色彩: 警告红 (#FF4444)
```

---

## 系统特效

### 伤痕（Scar）
```
描述: 深度介入后留下的永久痕迹
视觉: 裂纹纹理，微弱发光
色彩: 暗青色 (#006666)
```

### 漂移（Drift）
```
描述: 阿棠等漂移者的视觉效果
视觉: 残影、色差、边缘模糊
色彩: 暖色调带色差
```

### 判决（Verdict）
```
描述: 系统判定效果
视觉: 光柱、数据流、符文
色彩: 金色 (#FFD700)
```

### 污染（Contamination）
```
描述: 时间污染视觉
视觉: 红色脉动、噪点
色彩: 警告红 (#FF4444)
```

### 数据波纹（Data Ripple）
```
描述: 系统交互反馈
视觉: 同心方波扩散
色彩: 科技蓝 (#4A9EFF)
```

## 环境特效

### 裂缝震颤
```
用于: 边缘断口区域
视觉: 空间裂纹、震动
色彩: 深紫/青色混合
```

### 蜡烛闪烁
```
用于: 礼堂街、祭坛
视觉: 火焰摇曳
色彩: 暖黄/橙色
帧数: 4-6帧循环
```

### 显示器闪烁
```
用于: 市政环、诊疗台
视觉: 屏幕扫描线
色彩: 青色/蓝色
帧数: 2-4帧循环
```
