# 特效设计规范 v2.0

> **版本**: 2.0 | **更新日期**: 2025-12-25  
> **对齐文档**: 美术工作流总纲 v2、质量控制与验收标准

---

## 一、整体风格

- **风格**: 像素风特效
- **背景**: 透明（PNG/WebP序列）
- **色调**: 荧光色为主（青/红/金/紫）
- **形式**: 精灵图序列帧
- **像素大小**: 2px（与其他资产一致）

---

## 二、VFX技术规格

### 2.1 帧率标准

| 类型 | 帧率(fps) | 说明 |
|------|-----------|------|
| 快速特效 | 24 | 爆发、闪烁 |
| 标准特效 | 12 | 大部分循环特效 |
| 缓慢特效 | 8 | 环境氛围 |

### 2.2 循环规则

```yaml
循环特效:
  - 首尾帧必须可无缝衔接
  - 避免明显的"跳帧"感
  - 建议使用ping-pong播放

单次特效:
  - 有明确的起始和结束
  - 结束帧可为空白或残留
```

### 2.3 画布规格

| 特效类型 | 画布尺寸 | 说明 |
|----------|----------|------|
| 小型(粒子) | 64×64 | 单个粒子/小图标 |
| 中型(技能) | 128×128 | 角色周围效果 |
| 大型(全屏) | 256×256+ | 场景级效果 |
| 超大(过场) | 512×512 | CG级特效 |

## 三、三大能力特效

### 3.1 深度感知（Depth Perception）

```yaml
触发: C2解锁，长按激活
色彩: 荧光青 (#00FFF0)

子特效:
  activate: # 激活瞬间
    帧数: 12
    循环: 否
    描述: 青色圆环从中心扩散
    
  持续: # 激活期间
    帧数: 8
    循环: 是
    描述: 边缘深度格呼吸脉动
    
  deactivate: # 关闭
    帧数: 8
    循环: 否
    描述: 深度层收拢消失

视觉元素:
  - 同心圆波纹扩散
  - 线框轮廓叠加
  - 空腔区域高亮显示
  - 边缘微弱发光
```

### 3.2 深度介入（Depth Intervention）

```yaml
触发: C3解锁，确认写入
色彩: 青色 (#00FFF0) → 渐变白色

子特效:
  touch: # 触碰瞬间
    帧数: 6
    循环: 否
    描述: 接触点发光
    
  penetrate: # 穿透
    帧数: 12
    循环: 否
    描述: 手/工具穿透效果
    
  scar_create: # 伤痕生成
    帧数: 16
    循环: 否
    描述: 裂纹从接触点扩散

视觉元素:
  - 接触点光芒爆发
  - 结构裂纹生成动画
  - 粒子飘散
  - 伤痕纹理渐现
```

### 3.3 时间干预（Time Intervention）

```yaml
触发: C4解锁，选择节点回溯
色彩: 警告红 (#FF3366)

子特效:
  select: # 选择节点
    帧数: 8
    循环: 是
    描述: 时间线节点脉动
    
  rewind: # 回溯执行
    帧数: 24
    循环: 否
    描述: 画面倒带效果
    
  contamination: # 污染产生
    帧数: 16
    循环: 否
    描述: 红色扭曲涟漪扩散

视觉元素:
  - 时钟齿轮倒转
  - 画面倒带残影
  - 色彩红移/畸变
  - 时间线闪烁断裂
```

## 四、系统特效

### 4.1 伤痕（Scar）

```yaml
描述: 深度介入后留下的永久痕迹
色彩: 暗青色 (#006666)
帧数: 4帧循环（微弱脉动）

视觉:
  - 不规则裂纹纹理
  - 微弱发光呼吸
  - 边缘模糊
  
触发: 深度介入后永久显示
```

### 4.2 漂移（Drift）

```yaml
描述: 阿棠等漂移者的视觉效果
色彩: 暖色调 + 色差
帧数: 8帧循环

视觉:
  - 角色残影拖尾
  - RGB色差分离
  - 边缘模糊溶解
  - 不稳定闪烁

触发: 漂移者角色常驻
```

### 4.3 判决（Verdict）

```yaml
描述: 系统判定效果
色彩: 金色 (#FFD93D)
帧数: 24帧（单次）

视觉:
  - 光柱从上方降下
  - 数据流粒子
  - 符文/字段闪现
  - 角色被光芒笼罩

触发: R≥6时系统判定
```

### 4.4 污染（Contamination）

```yaml
描述: 时间污染视觉
色彩: 警告红 (#FF3366)
帧数: 16帧循环

视觉:
  - 红色脉动波纹
  - 噪点/杂色
  - 边缘撕裂感
  - 时间线区域标记

触发: 时间干预副作用
```

### 4.5 系统更正（System Correct）

```yaml
描述: 系统自动更正效果
色彩: 科技蓝 (#4A9EFF)
帧数: 12帧（单次）

视觉:
  - 文字被覆盖重写
  - 数据流覆盖原内容
  - 短暂闪烁

触发: 系统自动纠正玩家行为
```

### 4.6 数据波纹（Data Ripple）

```yaml
描述: 系统交互反馈
色彩: 科技蓝 (#4A9EFF)
帧数: 8帧（单次）

视觉:
  - 同心方波扩散
  - 网格线波动
  - 渐淡消失

触发: 与系统界面交互
```

## 七、叙事VFX约束

### 7.1 叙事关联规则

```yaml
F12-伤痕相关:
  - 伤痕首次出现必须有scar_create动画
  - 伤痕不可被清除，只能叠加
  - 回溯后伤痕保留（视觉强化）

F21-判决相关:
  - R≥6首次触发完整verdict动画
  - 后续判决可简化
  - 判决文字使用字段闪现效果

R值相关:
  - R增加时显示fx_r_increment
  - R≥3时UI边缘微弱红光
  - R≥10时常驻噪点overlay
```

### 7.2 章节特效演化

| 章节 | 特效变化 |
|------|----------|
| C0-C1 | 基础特效，无异常 |
| C2 | 深度感知特效解锁 |
| C3 | 深度介入+伤痕特效 |
| C4 | 时间干预+污染特效 |
| C5 | 所有特效强度增加 |
| CF | 高维显影+结局特效 |

## 九、精灵图规格

### 9.1 布局标准

```yaml
布局: 水平排列（horizontal strip）
单帧间距: 0px
背景: 透明

命名: fx_{category}_{name}_{variant}.webp
示例: fx_ability_depth_activate.webp
```

### 9.2 Phaser加载示例

```typescript
// 加载精灵图
this.load.spritesheet('fx_depth_activate', 
  'assets/images/effects/fx_ability_depth_activate.webp',
  { frameWidth: 128, frameHeight: 128 }
);

// 创建动画
this.anims.create({
  key: 'depth_activate',
  frames: this.anims.generateFrameNumbers('fx_depth_activate', { start: 0, end: 11 }),
  frameRate: 24,
  repeat: 0
});
```

## 十、QC验收清单

### 10.1 技术检查

- [ ] 帧数符合规格
- [ ] 背景完全透明
- [ ] 精灵图布局正确
- [ ] 文件大小合理（单张<500KB）

### 10.2 视觉检查

- [ ] 配色符合规格
- [ ] 像素大小一致(2px)
- [ ] 光照方向一致
- [ ] 无文字/水印

### 10.3 动画检查

- [ ] 循环特效首尾无缝
- [ ] 帧率播放流畅
- [ ] 无抖动/跳帧
- [ ] 叠加模式正确

### 10.4 叙事检查

- [ ] 符合章节解锁顺序
- [ ] 伏笔关联特效正确
- [ ] R/P值变化有视觉反馈
