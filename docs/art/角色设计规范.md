# 角色设计规范

## 整体风格
- **风格**: 像素风半身像
- **尺寸**: 512×512px
- **背景**: 透明
- **朝向**: 正面或3/4侧面

---

## 主角：岑回（Cenhui）

### 基础设定
- **身份**: 例外处理器/玩家角色
- **年龄**: 25-28岁
- **性别**: 女
- **风格**: 简洁外勤制服，沉默克制

### 视觉特征
- 短发（齐肩黑发）
- 深灰色连帽衫/工装外套
- 工具包/通行卡
- 克制的表情

### 配色
- 主色: 灰色系 (#3A3A3A, #5A5A5A)
- 强调: 荧光绿点缀 (#00FFAA) - 代表例外权限

### 表情列表
| 表情ID | 描述 |
|--------|------|
| neutral | 中性/平静 |
| thinking | 思考/沉思 |
| surprised | 惊讶 |
| sad | 悲伤/沉重 |
| stressed | 紧张/压力 |
| angry | 愤怒/不满 |
| smiling | 微笑/释然 |

## AI生图提示词模板

### 角色头像通用模板
```
pixel art portrait of [角色描述],
[表情描述],
cyberpunk aesthetic,
dark tones with [强调色] accent lighting,
transparent background,
front facing or 3/4 view,
512x512,
detailed pixel art style,
no text, no watermark
```

### 示例：岑回 neutral
```
pixel art portrait of a young woman in her mid-20s,
short black hair, gray hoodie,
neutral calm expression,
cyberpunk aesthetic,
dark tones with subtle cyan accent lighting,
transparent background,
front facing,
512x512,
detailed pixel art style,
no text, no watermark
```
