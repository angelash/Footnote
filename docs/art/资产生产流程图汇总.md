# 资产生产流程图汇总

> 本文档包含所有资产类型的Mermaid流程图，可直接在支持Mermaid的编辑器/渲染器中查看。

---

## 1. 通用生产流程

```mermaid
flowchart TB
    subgraph 准备阶段["🎯 准备阶段"]
        A1["📋 需求分析"] --> A2["📄 查找/创建规格文件"]
        A2 --> A3["🖼️ 准备四张锚定图<br/>Style/Palette/Camera/Lighting"]
        A3 --> A4{"🔀 确定模式"}
        A4 -->|"新资产"| A5["Generate模式"]
        A4 -->|"变体/序列"| A6["Edit模式"]
    end
    
    subgraph 生成阶段["🎨 生成阶段"]
        B1["✍️ 编写Prompt"] --> B2["📥 输入锚定图+Prompt"]
        B2 --> B3["🤖 AI生成"]
        B3 --> B4{"✅ 满意?"}
        B4 -->|"❌ 否"| B5["🔧 调整Prompt/参数"]
        B5 --> B2
        B4 -->|"✅ 是"| B6["💾 导出原始图"]
    end
    
    subgraph 后处理阶段["🔄 后处理阶段"]
        C1["✂️ 抠图/去背景"] --> C2["📐 尺寸调整"]
        C2 --> C3["📍 锚点对齐"]
        C3 --> C4["🏷️ 命名规范化"]
    end
    
    subgraph QC验收["🔍 QC验收"]
        D1["🔧 技术检查<br/>尺寸/格式/透明度"] --> D2["👁️ 视觉检查<br/>风格/光照/配色"]
        D2 --> D3{"🎯 通过?"}
        D3 -->|"❌ 否"| D4["↩️ 返工"]
        D4 --> B1
        D3 -->|"✅ 是"| D5["📦 归档入库"]
    end
    
    A5 --> B1
    A6 --> B1
    B6 --> C1
    C4 --> D1
    D5 --> E["📝 更新规格文件状态"]
    
    style 准备阶段 fill:#e1f5fe
    style 生成阶段 fill:#fff3e0
    style 后处理阶段 fill:#e8f5e9
    style QC验收 fill:#fce4ec
```

## 10. QC验收流程

```mermaid
flowchart TB
    subgraph 技术检查["🔧 技术检查（自动化）"]
        T1["📐 尺寸检查<br/>是否符合规格"] --> T2["🎨 格式检查<br/>WebP/PNG"]
        T2 --> T3["👻 透明度检查<br/>背景是否干净"]
        T3 --> T4["🎨 配色检查<br/>是否在调色板范围"]
        T4 --> T5["📍 锚点检查<br/>位置是否正确"]
    end
    
    subgraph 视觉检查["👁️ 视觉检查（人工）"]
        V1["🎨 风格一致性<br/>与锚定图对比"] --> V2["💡 光照一致性<br/>左上光源"]
        V2 --> V3["📝 无文字水印"]
        V3 --> V4["🔍 无AI伪影"]
    end
    
    subgraph 动画检查["🎬 动画检查（如适用）"]
        A1["📏 基线稳定<br/>±1px"] --> A2["📐 头顶盒<br/>不越界"]
        A2 --> A3["🔄 循环衔接<br/>首尾平滑"]
        A3 --> A4["▶️ 播放流畅<br/>无跳帧"]
    end
    
    T5 --> V1
    V4 --> CHECK{"🎯 全部通过?"}
    A4 --> CHECK
    
    CHECK -->|"❌"| REJECT["↩️ 返工<br/>记录问题"]
    CHECK -->|"✅"| APPROVE["✅ 验收通过"]
    
    APPROVE --> ARCHIVE["📦 归档入库<br/>更新状态"]
    REJECT --> FIX["🔧 修复问题"] --> T1
    
    style 技术检查 fill:#e3f2fd
    style 视觉检查 fill:#fff3e0
    style 动画检查 fill:#f3e5f5
```

## 使用说明

### 查看流程图

1. **VS Code**: 安装 "Markdown Preview Mermaid Support" 扩展
2. **GitHub**: 直接在仓库中查看，GitHub原生支持Mermaid
3. **在线工具**: 复制Mermaid代码到 [mermaid.live](https://mermaid.live)

### 流程图符号说明

| 符号 | 含义 |
|------|------|
| 📋 | 规划/准备 |
| 🆕 | Generate生成 |
| ✏️ | Edit编辑 |
| 💾 | 保存 |
| 🔍 | 检查 |
| ✅ | 通过/完成 |
| ❌ | 失败/返工 |
| 🔧 | 调整/修复 |
