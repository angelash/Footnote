## 一、项目概述

### 1.1 背景痛点

传统AI生图流程存在的问题：

| 问题 | 影响 |
|------|------|
| 🔄 重复操作 | 每张图都需要手动输入提示词、等待、下载 |
| ⏰ 效率低下 | 生成100张图需要数小时人工操作 |
| 📝 质量不稳定 | 人工检查容易遗漏，标准不一致 |
| 📁 管理混乱 | 文件命名、分类全靠人工记忆 |

### 1.2 解决方案

**智绘AI生图自动化系统** = Cursor AI + Browser MCP + 智绘平台

```
┌─────────────────────────────────────────────────────────┐
│                      Cursor AI                          │
│  ┌─────────────┐   ┌─────────────┐   ┌─────────────┐   │
│  │ 理解需求    │ → │ 生成提示词  │ → │ 质量检查    │   │
│  └─────────────┘   └─────────────┘   └─────────────┘   │
└─────────────────────────┬───────────────────────────────┘
                          │ MCP协议
┌─────────────────────────▼───────────────────────────────┐
│                   Browser Extension                     │
│  点击、输入、等待、截图、提取URL、下载                   │
└─────────────────────────┬───────────────────────────────┘
                          │ 自动操作
┌─────────────────────────▼───────────────────────────────┐
│                      智绘AI平台                         │
│  https://artflow.gz4399.com                            │
└─────────────────────────────────────────────────────────┘
```

### 1.3 适用场景

- ✅ 游戏角色头像批量生成
- ✅ 场景背景批量生成
- ✅ UI图标批量生成
- ✅ 特效素材批量生成
- ✅ 任何需要风格一致的批量图片生成

## 二、核心价值

### 2.1 效率提升

| 指标 | 人工操作 | 自动化操作 | 提升 |
|------|----------|------------|------|
| 单张生成 | 3-5分钟 | 1-2分钟 | **60%** |
| 10张批量 | 30-50分钟 | 10-15分钟 | **70%** |
| 质量检查 | 人工判断 | AI自动审核 | **100%** |
| 文件管理 | 手动命名 | 自动分类 | **100%** |

### 2.2 质量保障

```
自动化质量检查项：
✅ 朝向一致性 - 正面必须对称
✅ 背景透明度 - 角色/物件必须透明背景
✅ 角色完整性 - 无截断、无缺失
✅ 风格匹配度 - 必须符合像素风格
✅ 构图居中度 - 主体必须居中
```

- **人力成本**：减少80%重复操作时间

### 3.2 MCP协议说明

**MCP (Model Context Protocol)** 是Anthropic推出的开放协议，允许AI模型安全地与外部工具交互。

```
传统方式：AI只能生成文本 → 人工执行
MCP方式：AI生成指令 → 工具自动执行 → AI获取结果
```

### 3.3 Browser MCP能力

| 能力 | 函数 | 说明 |
|------|------|------|
| 导航 | `browser_navigate` | 打开指定URL |
| 快照 | `browser_snapshot` | 获取页面元素结构 |
| 点击 | `browser_click` | 点击指定元素 |
| 输入 | `browser_type` | 在输入框输入文字 |
| 等待 | `browser_wait_for` | 等待元素/时间 |
| 截图 | `browser_take_screenshot` | 截取页面图片 |
| 执行JS | `browser_evaluate` | 执行JavaScript代码 |
| 按键 | `browser_press_key` | 模拟键盘按键 |

## 四、工作流程

### 4.1 完整自动化流程

```
┌─────────────────────────────────────────────────────────────┐
│ Step 1: 导航到智绘平台                                       │
│ browser_navigate("https://artflow.gz4399.com/ai")           │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 2: 等待页面加载                                         │
│ browser_wait_for(time: 3)                                   │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 3: 获取页面状态                                         │
│ browser_snapshot() → 识别输入框、按钮位置                    │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 4: 点击输入框                                           │
│ browser_click(element: "输入框", ref: "textarea#prompt")    │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 5: 输入提示词                                           │
│ browser_type(text: "pixel art style, 2D game character...") │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 6: 点击发送按钮                                         │
│ browser_click(element: "发送按钮", ref: "button#send")      │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 7: 等待生成完成（60-90秒）                              │
│ browser_wait_for(time: 60)                                  │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 8: 提取图片URL                                          │
│ browser_evaluate(() => {                                    │
│   return Array.from(document.querySelectorAll('img'))       │
│     .filter(img => img.src.includes('_small.webp'))         │
│     .map(img => img.src);                                   │
│ })                                                          │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 9: 下载图片到本地                                       │
│ Python requests.get(url) → save to assets/                  │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 10: AI质量检查                                          │
│ 检查: 朝向、背景、完整性、风格、构图                         │
└─────────────────────────────┬───────────────────────────────┘
                              ▼
┌─────────────────────────────────────────────────────────────┐
│ Step 11: 分类存储                                            │
│ 通过 → assets/approved/                                     │
│ 未通过 → assets/rejected/                                   │
└─────────────────────────────────────────────────────────────┘
```

## 五、部署教程

### 5.1 环境要求

| 组件 | 版本要求 | 说明 |
|------|----------|------|
| Chrome浏览器 | 最新版 | 主浏览器 |
| Cursor编辑器 | 最新版 | AI开发环境 |
| Python | 3.8+ | 下载脚本 |
| Node.js | 18+ | MCP服务 |

### 5.2 Chrome MCP扩展安装

#### 方式一：Chrome商店安装（推荐）

```
1. 打开Chrome浏览器
2. 访问 Chrome Web Store
3. 搜索 "Browser MCP" 或 "Cursor Browser Extension"
4. 点击 "添加至Chrome"
5. 确认安装
```

#### 方式二：开发者模式安装

```bash
# 1. 下载扩展源码
git clone https://github.com/anthropics/browser-mcp.git

# 2. 打开Chrome扩展管理
chrome://extensions/

# 3. 开启"开发者模式"（右上角开关）

# 4. 点击"加载已解压的扩展程序"

# 5. 选择下载的扩展目录
```

#### 扩展配置

```
安装后配置:
1. 点击扩展图标 → 设置
2. 允许访问所有网站（或指定智绘平台域名）
3. 确认MCP服务端口（默认: 3000）
```

### 5.3 Cursor设置教程

#### Step 1: 安装Cursor

```
1. 访问 https://cursor.sh
2. 下载对应系统版本
3. 安装并启动
```

#### Step 2: 配置MCP服务

打开Cursor设置文件 `~/.cursor/mcp.json`：

```json
{
  "mcpServers": {
    "cursor-browser-extension": {
      "url": "http://localhost:3000/mcp"
    }
  }
}
```

#### Step 3: 验证连接

```
1. 启动Chrome浏览器（确保扩展已启用）
2. 打开Cursor
3. 在对话中输入: "打开百度首页"
4. 如果Chrome自动打开百度，说明配置成功
```

#### Step 4: 添加项目规则

在项目根目录创建 `.cursor/rules/` 目录，添加规范文件：

```
.cursor/rules/
├── 05-assets.mdc          # 美术资源规范
└── 06-ai-art-generation.mdc  # 生图操作指南
```

### 5.4 完整配置检查清单

```
□ Chrome浏览器已安装
□ Browser MCP扩展已安装
□ 扩展已启用且有访问权限
□ Cursor已安装
□ mcp.json已配置
□ Python 3.8+已安装
□ requests库已安装 (pip install requests)
□ 项目规则文件已添加
□ 智绘平台账号已登录
```

## 七、最佳实践

### 7.1 提示词优化技巧

```
✅ 好的提示词结构:
[风格] + [主体] + [外观] + [姿态] + [背景] + [技术约束]

示例:
"pixel art style, 2D game character,
young woman with short black hair,
calm neutral expression, gray hoodie,
standing pose, facing camera directly,
transparent background, centered composition,
clean lines, no text, no watermark"
```

### 7.2 批量生成策略

```
推荐流程:
1. 先生成1个角色的所有表情 → 验证风格一致性
2. 确认风格后，批量生成其他角色
3. 每批次不超过10张，便于质量控制
4. 保留所有生成记录，便于追溯
```

### 7.3 常见问题解决

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 浏览器无响应 | MCP连接断开 | 重启Chrome和Cursor |
| 生成超时 | 平台负载高 | 增加等待时间到90秒 |
| 朝向不正 | 约束词不够强 | 添加 `perfectly symmetrical` |
| 风格不一致 | 缺少风格锚定 | 开头必须有 `pixel art style` |
| 下载失败 | URL过期 | 生成后立即下载 |
