## 七、风险与应对

| 风险 | 应对措施 |
|---|---|
| 智绘平台不可用 | 保存所有提示词，换时段重试 |
| 风格不一致 | 强化风格锚定词，必要时重生成 |
| 角色不像 | 统一主角描述段落，每次包含 |
| 生成卡住 | 2分钟超时标记，单独重试 |
| 对白乱码 | 简化对白，避免复杂标点 |
