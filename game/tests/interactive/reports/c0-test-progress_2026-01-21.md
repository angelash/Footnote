## 发现的问题

### P0 - 阻断性问题

#### 1. 对话 onComplete 效果未执行
- **现象**: 对话完成后，onComplete 中定义的 flag 设置和 rDelta 效果不生效
- **影响**: R值无法累积，FLAG无法设置，条件跳转失败
- **文件**: `NarrativeEngine.ts` 的 `_endDialogue` 或 `_applyChoiceEffects` 方法

#### 2. 条件出口检查失败
- **现象**: 即使手动设置 FLAG，条件出口仍无法正常触发跳转
- **影响**: 正常游戏流程被阻断
- **临时方案**: 使用 scene.restart 强制跳转

### P1 - 重要问题

#### 3. 打字机效果自动完成问题
- **现象**: 打字机效果播放完毕后，`isTyping` 仍为 true
- **影响**: 需要手动调用 `_completeTypewriter()` 才能显示选项
- **文件**: `DialogueUI.ts` 的打字机定时器逻辑

### 已修复问题

#### 4. NarrativeEngine.selectChoice 无限递归 ✅
- **原因**: `selectChoice` 发送 `DIALOGUE_CHOICE` 事件，导致循环调用
- **修复**: 移除 `NarrativeEngine.selectChoice` 中的事件发送
