## 发现的问题及修复

### 已修复问题

#### 1. 对话系统 dialogueId 未处理 (P0 - 已修复)

**问题描述**: 
- 场景配置使用 `dialogueId` 引用对话，但 `_handleSceneAction` 未处理该字段
- 导致对话框显示但内容为空

**根因**:
`GameScene._handleSceneAction()` 方法只使用了 `action.speaker` 和 `action.text`，没有处理 `action.dialogueId`

**修复方案**:
```typescript
case 'dialogue': {
  // 优先使用 dialogueId 从 NarrativeEngine 加载完整对话
  if (action.dialogueId) {
    this.showDialogueById(action.dialogueId);
  } else {
    // 回退：直接使用 speaker/text
    this._showDialogue({
      speaker: action.speaker ?? '系统',
      text: action.text ?? '',
    });
  }
  return;
}
```

**修复文件**: `game/src/scenes/GameScene.ts`
