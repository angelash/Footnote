# 回滚记录

> 记录项目回滚操作，确保问题可追溯

## 格式说明

| 字段 | 说明 |
|------|------|
| 日期 | YYYY-MM-DD |
| 回滚ID | R-XXX（递增编号） |
| 回滚原因 | 触发回滚的原因 |
| 影响文件 | 涉及的文件/模块 |
| 操作人 | 执行回滚的角色 |
| 状态 | 已完成/进行中 |

## 回滚触发条件

根据 AI-Native 工作流规范，以下情况触发回滚：

1. 修改了冻结目录（00_charter, 01_bibles）
2. 引入了未经 CR 审批的新系统/Schema
3. 输出未落到指定路径
4. 超过粒度上限
5. 越权改动其他模块
