# 任务记录

> 记录项目任务执行情况，跟踪进度

## 格式说明

| 字段 | 说明 |
|------|------|
| 日期 | YYYY-MM-DD |
| 任务ID | T-XXX 或 TaskPack编号 |
| 任务内容 | 简述任务要点 |
| 执行人 | 角色层级 |
| 状态 | 待开始/进行中/已完成/已取消 |
| 备注 | 补充说明 |

## 任务状态定义

- **待开始**: 任务已分配，尚未执行
- **进行中**: 任务正在执行
- **已完成**: 任务已通过验收
- **已取消**: 任务因故取消
