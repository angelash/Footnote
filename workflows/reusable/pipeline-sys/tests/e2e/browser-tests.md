# Pipeline-Sys E2E Browser 测试用例

## 测试环境要求

- Console 服务运行在 http://localhost:3230
- UI 服务运行在 http://localhost:5173
- 测试数据已准备（运行 `setup-test-data.ps1`）

## 测试用例列表

### TC-001: 运行列表页面加载

**步骤:**
1. 打开 http://localhost:5173
2. 等待页面加载完成

**预期结果:**
- 页面标题显示 "Pipeline-Sys"
- 显示运行列表
- 列表中包含至少 2 个运行项
- 每个运行项显示 run_id、task_id、状态

### TC-002: 运行列表状态显示

**步骤:**
1. 在运行列表页面
2. 检查每个运行项的状态徽章

**预期结果:**
- RUN-20260105-100000-done 显示绿色 SUCCESS 徽章
- RUN-20260105-120000-test 显示蓝色 RUNNING 徽章

### TC-003: 点击进入运行详情

**步骤:**
1. 在运行列表页面
2. 点击 RUN-20260105-100000-done

**预期结果:**
- 导航到详情页面
- URL 变为 /runs/RUN-20260105-100000-done
- 显示行为树图
- 显示节点详情面板
- 显示事件时间线

### TC-004: 行为树节点状态

**步骤:**
1. 在运行详情页面（已完成的运行）
2. 检查行为树中的节点

**预期结果:**
- 所有节点显示绿色（SUCCESS 状态）
- 节点之间的连线正确连接
- execute 组节点包含 5 个子节点

### TC-005: 节点点击交互

**步骤:**
1. 在运行详情页面
2. 点击 stage.intake 节点

**预期结果:**
- 右侧面板更新为 stage.intake 的详情
- 显示节点 ID、状态、尝试次数
- 显示开始时间、结束时间、耗时
- 显示输出文件列表

### TC-006: 事件时间线

**步骤:**
1. 在运行详情页面
2. 查看底部事件时间线

**预期结果:**
- 显示 RUN_STARTED 事件
- 显示各个 NODE_STARTED 和 NODE_FINISHED 事件
- 显示 LOCK_ACQUIRED 和 LOCK_RELEASED 事件
- 显示 RUN_FINISHED 事件
- 事件按时间顺序排列

### TC-007: 正在运行的任务详情

**步骤:**
1. 返回列表页面
2. 点击 RUN-20260105-120000-test

**预期结果:**
- 显示部分节点为 SUCCESS（绿色）
- execute.edit 节点显示为 RUNNING（蓝色）
- 后续节点显示为 PENDING（灰色）

### TC-008: 取消按钮显示

**步骤:**
1. 在正在运行的任务详情页面
2. 检查控制按钮

**预期结果:**
- 显示 "Cancel" 按钮
- 按钮为启用状态

### TC-009: 返回列表导航

**步骤:**
1. 在运行详情页面
2. 点击返回按钮或导航到列表

**预期结果:**
- 成功返回运行列表页面
- 运行列表正常显示

### TC-010: 页面刷新保持状态

**步骤:**
1. 在运行详情页面
2. 刷新页面

**预期结果:**
- 页面正确重新加载
- 显示相同运行的详情
- 行为树和面板正确渲染
